# Main Story + Character Bible Design

## Goal

把《灰潮鎮：第七封信》的主線從「事件謎題」提升成「人物人生彼此碰撞後產生的因果劇」

核心原則：

> 玩家不是讓世界開始運作的人，只是闖進一個早已運作很久的世界

---

# Narrative Pillars

## 1. 人物先於謎題

每個主要角色都必須有至少一個與主線解謎無關，但會影響今天行程、情緒與選擇的私人目標

- 許若晴正在準備攝影作品集，考慮離開灰潮鎮
- 周予安正在考慮是否出售父親留下的鐘錶店
- 陳柏勳面臨醫院縮編與調職
- 葉庭安本來就在追查五年前研究所事故
- 周志遠有職務與家庭壓力，不會永遠配合玩家

這些生活線必須真的影響 Schedule、Location、Trust 與 Event Variant

## 2. 世界線改變的是人生，不只是死者

```text
玩家幫若晴處理家裡的事
→ 若晴提早下班
→ 沒去舊車站
→ 柏勳改變交付對象
→ 庭安前往車站
→ 18:31 的死者改變
```

玩家不能只靠「阻止死亡」解題，而要理解每個人為什麼會在那個時間出現在那個地方

## 3. Invariant 比單一真相重要

前期讓玩家誤以為：

```text
18:31 = 死亡時間
```

中期揭示：

```text
18:31 = 世界線開始進入修正狀態的時間點
死亡 = 常見症狀，而不是原因
```

## 4. 林知夏不是完美受害者

知夏曾為了改變世界線而隱瞞、操控，甚至做過把危險轉移給別人的選擇

後期真正的問題不再是：

> 如何救姊姊？

而是：

> 如果救姊姊代表另一個人必須死，還要這樣做嗎？

---

# 灰潮鎮

## 20 年前

「灰潮時間環境研究中心」成立

研究所帶來大量工程、醫療與外地人口，車站、商店街、學校與醫院都因此擴張

## 10 年前

研究經費縮減

人口開始外流，灰潮鎮逐漸老化

## 5 年前

研究所發生未公開事故

同一天，林知夏在舊車站死亡

官方以意外結案

數月後研究所關閉，舊車站停用

## 現在

- 商店街出現大量空店
- 學校縮班
- 醫院人力不足
- 舊研究所封鎖
- 舊車站停用
- 鐘樓鐘體早已拆除，只剩塔體

因此「為什麼還留在灰潮鎮」是每個主要人物都必須回答的人生問題

# 核心人物

## 主角｜林知夏的妹妹

### 過去

小時候非常依賴姊姊

高中後開始討厭所有人都把自己叫成「知夏的妹妹」

知夏死亡前半年，兩人因主角決定離開灰潮鎮發生激烈爭執

最後一次真正對話並不愉快

### 現在

公開理由是回來整理老家並出售房子

真正驅動她的是一個一直沒有說出口的問題：

> 如果當時我沒有離開，她會不會沒有死？

### Character Arc

```text
查出姊姊怎麼死
→ 阻止死亡重演
→ 想救姊姊
→ 發現姊姊也曾犧牲別人
→ 不再只用「救姊姊」衡量所有人的命
```

---

## 林知夏｜死亡時 26 歲

### 生前

地方史研究者兼圖書館約聘人員

原本只研究灰潮鎮地方史，後來從舊檔案接觸到研究所資料

### 與主角

疼妹妹，但有很強的保護與控制傾向

發現輪迴後，她刻意讓妹妹離開灰潮鎮，因此死亡前半年突然變得冷淡

### 與若晴

若晴高中時常到圖書館躲避家庭衝突

知夏是第一個認真看她攝影作品、鼓勵她離開小鎮的人

兩人實際上接近非血緣姊妹

### 與予安

從小認識

知夏常請予安修老鐘、錄音設備與研究器材

五年前 17:58，她最後一次打電話給予安，但予安沒有接

### 與庭安

曾是研究所調查搭檔

兩人最後因「是否能犧牲少數人來終止輪迴」而決裂

### 與柏勳

知夏開始出現 Déjà vu、記得不存在事件後，曾找柏勳求助

柏勳是第一批相信她不是單純精神問題的人

### 真正秘密

知夏曾經也是「世界線記憶持有者」

她沒有找到停止輪迴的方法，只找到讓記憶殘留的方法

實體信件就是其中一種載體

---

## 周予安｜27｜鐘錶店店主

### 現在生活

父親兩年前過世後接下老街鐘錶店

生意不好，他其實已經找房仲談過出售店面

### 個性

- 可靠
- 實際
- 先幫忙再問原因
- 不擅長談沉重情緒
- 緊張時說話反而突然變正式

### 與主角

高中同學，也是主角離開後少數仍保持聯絡的人

重點不是單純戀愛線，而是他是唯一真正知道主角「離開灰潮鎮後變成什麼樣子」的人

### 五年前

17:58，知夏打電話給他

他當時正和父親吵架，因此沒有接

18:31，知夏死亡

他五年來沒有刪掉那筆未接來電

### 今天原本的人生

20:00 原本約好房仲來看店面

如果玩家讓他一路幫忙調查，就是真的在改變他自己的生活

### Character Arc

```text
幫主角調查
→ 出現 Déjà vu
→ 記得前一輪零碎片段
→ 發現五年前的未接電話可能屬於另一條世界線
→ 放下「如果我接電話她就不會死」的執念
```

## 許若晴｜23｜咖啡店員

### 家庭

父親早年離家，母親長期身體不好

高中畢業後沒有離開灰潮鎮，主要原因是照顧母親

### 真正想做的事

攝影

她一直偷偷準備作品集，最近收到外地學校重新申請的通知

她其實已經準備向咖啡店辭職

### 與知夏

知夏是第一個告訴她「妳可以離開這裡」的人

因此她對自己五年來一直沒有離開感到羞愧

### 與予安

若晴年少時對予安有好感

現在更接近把他視為永遠會在的安全感

予安則把若晴當妹妹

### 第一輪真正定位

她不是「第一死者」

她只是第一輪恰好走到 18:31 節點的人

### 今天原本的行程

```text
08:00 上班
11:30 偷偷整理作品集
14:00 收到外地學校回覆
16:10 遇見主角
17:20 準備去舊車站
18:31 世界線修正事件
20:30 原本預計向店長提出辭職
```

如果玩家救下她，20:30 的辭職事件仍然應該發生

這會是玩家第一次真正感覺：

> NPC 活下來之後還有人生

---

## 陳柏勳｜41｜醫師

### 現在生活

灰潮鎮醫院逐年縮編

他已經收到外地醫院調職邀請，但因五年前事件一直沒有離開

### 個性

克制、程序導向、不願把推測當作事實說出口

因此非常像有問題的人

### 五年前

知夏曾描述自己記得尚未發生的事件

柏勳最初判斷是睡眠與壓力問題

直到知夏準確說出一件之後才發生的事故，他才改變看法

### 與庭安

研究所事故後，他協助庭安隱瞞一部分醫療資料

並不是共謀，而是兩人都相信公開資料可能造成更多傷害

### 今天原本的目的

17:40 秘密離院，不是去殺人

而是要把知夏當年留下的一份封存醫療資料交給若晴

### Character Arc

```text
最可疑的人
→ 發現他其實一直保護資料
→ 發現「保護」同樣造成真相斷裂
→ 最後願意讓玩家自己決定如何使用真相
```

---

## 葉庭安｜30｜記者／前研究助理

### 現在生活

離開灰潮鎮後成為調查記者

對外說這次只是回來採訪地方新聞

實際上她已追查研究所舊案半年

### 與知夏

五年前是最接近知夏真相的人

也是最後與她決裂的人

知夏認為必須不停嘗試不同世界線

庭安則開始懷疑：

> 如果每次嘗試都會把死亡推給另一個人，還算是在救人嗎？

### 為什麼說不認識知夏

不是因為她怕被發現

而是知夏五年前曾要求她：

> 如果我妹妹回來，不要讓她知道我做過什麼

她仍然在履行一個死人留下的承諾

### 今天私人目標

她原本要在 19:50 獨自進入研究所，取回當年的實驗紀錄

玩家在 16:40 是否拆穿她，會改變她前往研究所的時間與方式

### Character Arc

```text
資訊控制者
→ 被迫重新面對知夏
→ 承認自己五年前也做過選擇
→ 從「替死人保守秘密」轉向「讓活著的人知道真相」
```

## 周志遠｜36｜刑警

### 五年前

是知夏死亡案第一批到場人員之一

當晚他發現一台停在 18:31 的錄音設備

但設備內的聲音包含不可能存在的內容

他沒有把設備登錄進正式證物清單

### 為什麼隱瞞

不是為了包庇兇手

而是因為錄音裡出現了「尚未到場的自己」的聲音

他無法向任何人解釋

### 現在

五年來一直保留那件證物

也因此從未真正相信知夏只是意外死亡

### 與柏勳

兩人互相不信任

志遠認為柏勳隱瞞醫療紀錄

柏勳則認為志遠隱藏關鍵證物

兩人其實做了同一件事，只是都認為自己比較有理由

# 人物關係網

```text
                    林知夏
                 /     |      \
                /      |       \
          保護妹妹   像姊妹    調查搭檔→決裂
              /        |          \
           主角      許若晴       葉庭安
             |          |            |
          舊同學     依賴／舊好感   隱瞞資料
             |          |            |
           周予安 ──────┘          陳柏勳
             |                       |
             └──── 五年前線索 ── 周志遠
```

關係不是靜態標籤，而是 Event Graph 的輸入條件

例如：

```text
若晴 trust protagonist >= 2
→ 17:20 願意說出自己要去舊車站

庭安 trust protagonist < 0
→ 19:50 提前獨自進研究所

予安 residue >= 3
→ 能記起上一輪 17:58 的電話
```

# 五年前真正發生的事

五年前，知夏已經經歷過多次「局部世界線殘留」

她發現 18:31 附近總會產生無法解釋的因果收束

不同世界線中，死亡者並不固定

她最初認為只要找到正確行動就可以讓所有人存活

庭安則逐漸發現一個殘酷現象：

```text
救 A
→ B 死亡

救 B
→ C 死亡

阻止所有已知死亡
→ 發生另一種事故
```

兩人因此決裂

知夏最後一次實驗試圖把「記憶」送到未來，而不是繼續改動當天

她成功讓訊息跨世界線殘留

但自己死在 18:31

# 第七封信

主角收到的不是第一封信

而是第七封

前六封存在於不同形式或不同世界線中：

```text
1. 未寄出的紙條
2. 圖書館借閱卡背面的字
3. 錄音帶中的一句話
4. 醫療資料上的手寫備註
5. 一封被庭安燒掉的信
6. 予安記憶殘留中的一句話
7. 主角收到的實體信
```

玩家直到 Chapter 6 才理解「第七封信」這個標題真正的意思

# 主線章節

## Chapter 0｜第七封信

主角收到死去五年的姊姊寄來的信，回到灰潮鎮

核心情緒：回鄉、陌生感、未完成的哀傷

## Chapter 1｜第一個今天

表面問題：

> 誰殺了許若晴？

玩家第一次建立錯誤因果：

```text
柏勳秘密離院
→ 與若晴碰面
→ 若晴 18:31 死亡
```

午夜第一次重置

## Chapter 2｜活下來的人

玩家成功阻止若晴前往車站

18:31，若晴存活

但柏勳死亡

玩家第一次真正理解：

> 改變死者，不等於改變事件

同時能在 20:30 看見若晴原本要辭職的人生線

## Chapter 3｜沒有死者的世界線

玩家經過多輪嘗試，成功讓已知角色都避開危險

18:31 無人死亡

但 23:59 鐘聲仍然響起

00:00 世界仍然重置

這一章推翻整個前期假設：

```text
死亡 ≠ 輪迴原因
```

## Chapter 4｜五年前

玩家開始重建知夏死亡當天

透過志遠未登錄的證物、柏勳醫療紀錄、庭安研究資料，發現五年前也曾存在多條世界線

## Chapter 5｜記得的人

予安開始真正保留前一輪片段

他第一次說出玩家上一輪才講過的話

玩家發現：

> 記憶殘留正在擴散

這同時帶來新的恐怖：如果所有人都開始記得，每次重置是否仍然算「重新開始」？

## Chapter 6｜前六封信

玩家發現知夏留下的訊息不是一封，而是一串跨世界線殘留

七份訊息拼起來後，揭露知夏最後真正做的實驗

## Chapter 7｜林知夏

玩家真正理解知夏曾經做過的事

她不是一直在找「大家都活下來」的世界線

後期她開始主動選擇哪些結果比較能接受

甚至曾故意把危險從主角身上轉移給別人

## Final｜18:31

最終真相：

18:31 不是死亡時間

它是研究所實驗造成的「因果收束點」

每天從這個時間開始，世界會逐步排除與既定歷史差距過大的狀態

午夜重置只是修正完成的結果

最終問題不是殺掉某個 Boss 或找到唯一兇手

而是玩家必須決定：

```text
A. 讓世界停止重置，但接受某些已發生的死亡
B. 繼續維持輪迴，尋找理論上可能不存在的完美世界線
C. 破壞知夏建立的記憶傳遞機制，讓所有人真正忘記並重新生活
```

具體 Ending 不在此階段鎖死，但所有結局都必須建立在「玩家如何理解拯救」上，而不是單純好／壞結局

# Event Graph 對應原則

Story Bible 與機器可讀資料分工：

```text
Character Bible
→ 定義角色人生、慾望、恐懼、秘密

Relationship Graph
→ 定義人物互動條件

Schedule
→ NPC 沒有玩家時原本會做什麼

Event Graph
→ 玩家介入後因果如何改寫

Worldline History
→ 玩家實際看過哪些版本
```

每個關鍵事件都應回答四個問題：

1. 這個角色原本為什麼會在這裡？
2. 如果玩家不存在，他原本會做什麼？
3. 玩家改變了哪個人的什麼動機？
4. 這個改變會沿哪條關係產生延遲後果？

---

# Success Criteria

完成後，玩家應有以下感受：

- 若晴死亡時，不只覺得「線索沒了」，而會想到她還沒交出去的攝影作品集
- 予安失蹤時，不只想到調查助手沒了，而會想到他今晚本來要決定是否賣掉父親的店
- 玩家救下一個人後，能真的看見那個人繼續過今天
- 同一 NPC 在不同 Loop 不是只換一句台詞，而是可能因為關係與生活狀態走向完全不同的地方
- 玩家逐漸理解：世界線不是關卡分支，而是一群人的人生被重新排列
