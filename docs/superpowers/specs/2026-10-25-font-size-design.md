# 可調整字體大小

使用者要求可以調整字體大小。設定選單提供小、標準、大、特大，倍率為 0.9、1、1.2、1.4。預設標準；即時套用並沿用既有設定存檔，舊存檔缺欄位時採標準。

對話、旁白、手機、選項、環境文字、音源標籤、記憶與選單文字一併縮放。保留既有相對大小、動畫及版面語言。倍率套用在各字級的響應式計算之外，確保 vw 字級也會變化。放大後重新測量環境文字位置，選項超過可用高度時允許捲動；手機選單允許換行。

採用四個預設，方便重設及選取；不採任意數字輸入或頁面 zoom，避免連按鈕、間距、畫面空間都一起放大。大小存入 settings.fontSize，不變更存檔版本。不改動目前工作區另行開發的時鐘邏輯。
