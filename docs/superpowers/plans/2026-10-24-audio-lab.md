# Audio Lab 整理與音訊檢查

目標：清楚區分錄音檔與合成配方、顯示版本數，讓每個錄音版本可獨立播放。保留現有遊戲播放行為及工作區中的其他變更。

- [x] 擴充實驗室診斷播放介面，支援指定錄音版本；測試越界及指定檔案。
- [x] 整理 lab.tsx：搜尋、來源篩選、數量摘要、錄音逐版按鈕、所有音效的合成按鈕，環境層標示錄音／合成／混合。
- [x] 掃描所有錄音檔的解碼、長度、峰值與音量，檢查合成配方與執行測試，輸出逐檔報告及改善建議。
- [x] 執行測試、建置及可用的網頁驗證。

限制：目前工具沒有可直接聆聽聲音的輸入介面；數值分析與程式檢查不宣稱為聽感評價。合成每個音效只有一套配方，隨機變化不計為固定版本。
