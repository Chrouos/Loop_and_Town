# Font Size Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 玩家可在設定選擇字體大小，即時套用且下次開啟保留。

**Architecture:** settings.fontSize 存四個預設名稱，對應 CSS --text-scale。各畫面以相同倍率包裝現有字級；Stage 在倍率改變時重排環境標籤並限制選項可捲動高度。

**Tech Stack:** React、TypeScript、CSS、Vitest、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-25-font-size-design.md`

## Global Constraints

- 不變更既有存檔版本；標準保持現有字級。
- 保留工作區中另行開發的時鐘變更。

## Review Focus

- 舊存檔缺字級或值無效時使用標準。
- 選取會即時更新並寫入儲存，重新開啟仍有效。
- 特大時手機選單無水平溢出，長選項能捲到底。
- 字級改變會重新測量周邊文字避讓。
- 標題、校正、結局亦沿用選定字級。
