# PR #16 Story / Architecture Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate PR #16's complete story foundation into the current anchored-timeline project while preserving the deterministic simulator and player runtime.

**Architecture:** Import PR #16 canon, narrative, DAG, worldline, and relationship assets behind typed loader boundaries. Keep the current anchored player runtime and simulator authoritative for real-time progression, and replace the author viewer's hard-coded multi-loop loading with a backward-compatible manifest-driven story bundle.

**Tech Stack:** TypeScript 5.6, React 18, Vite 5, Vitest 2, js-yaml, YAML, JSON Schema, localStorage.

**Spec:** `docs/superpowers/specs/2026-09-28-pr16-story-architecture-integration-design.md`

## Global Constraints

- Story YAML continues to express Simulation Time only; Real Time remains a runtime concern.
- Loop 1 onboarding remains anchored at Simulation Time `06:12`.
- Online and offline progression use the same event scheduler.
- Reset is triggered by Simulation Time `00:00`, occurs once, preserves meta-memory, and clears loop-local state.
- Relationship dimensions remain author/runtime state and are not exposed as player-facing numeric scores.
- The old single `narrative` manifest field remains valid while `narratives` is introduced.
- Current anchored-timeline, action-duration, simulator, dependency-lock, and build behavior take precedence over older PR #16 runtime copies.
- Generated `dist/` output is not a source of truth and is only regenerated by the build command.

## Review Focus

- Duplicate scene/node IDs across Loop 1–7 and Final must fail before rendering; test in Task 3.
- A DAG `narrative_ref` or worldline path reference to a missing document must name the source and target; test in Task 3.
- A timing migration must update all consumers of `14:20`, not only the opening scene; test in Task 5.
- Relationship state must reset with the loop while Character Insight/meta-memory survives; test in Task 6.
- Existing anchored-timeline behavior must remain stable when the author bundle is loaded; test in Task 7.
