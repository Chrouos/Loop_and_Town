# Story Canon｜跨 Loop 記憶與 Character Insight

本文件是目前《灰潮鎮：第七封信》的記憶規則 Canon。

若舊文件仍出現「NPC 逐漸記起上一輪」「Memory Residue 讓予安恢復其他 Loop 記憶」等描述，以本文件為準，並視為待移除的 Legacy 設定。

---

# 1. Hard Reset 後誰記得？

```text
主角
→ 保留跨 Loop 記憶
→ 保留案件資訊
→ 保留共同經歷
→ 保留對角色的理解

其他角色
→ 不保留上一輪記憶
→ 不知道自己曾經活過其他版本的今天
→ 人格、價值觀、喜好、習慣維持一致
```

輪迴不應傷害 NPC 人格。

情感代價集中在記憶持有者。

---

# 2. 關係是真的，但只剩主角承認它存在過

```text
Loop A
主角與予安一起調查
→ 一起吃飯
→ 談到父親
→ 建立信任

00:00 Reset

Loop B
予安：好久不見
主角：仍記得 Loop A 全部內容
```

予安不是「忘記一段友誼」。

對 Loop B 的予安而言，那段友誼從來沒有發生。

真正失去它的人是主角。

---

# 3. Character Insight

Character Insight 是主角跨 Loop 累積的「人物理解」。

它不是超能力，也不是客觀物證。

## Evidence

```text
照片
病歷
錄音
通話紀錄
實體物品
```

## Character Insight

```text
喜好
習慣
價值觀
恐懼
私人目標
說謊或緊張時的穩定行為
```

例如：

```text
[Insight]
周予安不會主動丟掉父親留下的東西。

用途：
如果父親遺物消失，優先調查「誰移動過」，
而不是直接接受「予安自己清掉了」。
```

---

# 4. Insight 不能直接證明真相

禁止：

```text
若晴拉相機背帶
→ UI 顯示「說謊 100%」
```

應該是：

```text
若晴拉相機背帶
+
主角曾在其他 Loop 認識她的壓力反應
↓
[Insight]
她可能不是忘記，而是在迴避。
↓
解鎖新的追問方式
```

人物理解用來改變調查方向，不取代證據。

---

# 5. 穩定人格不是固定劇本

角色人格穩定，不代表每次一定做完全相同的事。

角色行為仍然受到：

```text
當下資訊
位置
時間
關係
玩家介入
其他 NPC 行動
```

影響。

Character Insight 應描述「傾向」或「價值」，而不是把角色變成 deterministic function。

---

# 6. 主角與知夏的鏡像

真正危險的不是記憶污染，而是：

```text
認識所有人
→ 理解所有人的弱點與選擇
→ 預測所有人的路線
→ 覺得自己最了解他們
→ 開始替他們安排今天
```

知夏當年走偏的原因之一，就是把累積的理解逐漸轉化成控制。

主角必須學到：

> 我很了解你，不代表我有權替你做決定。

---

# 7. 第六封與第七封

第六種跨 Loop 資訊載體是 **記憶持有者本人**。

```text
Loop A 的資訊
→ 記憶持有者記住
→ Reset
→ Loop B 仍保留
```

第七封的特殊之處則是「交接」：

```text
五年前的知夏
→ 第七封機制
→ 五年後的主角
```

它不是讓 NPC 開始記得。

它是讓資訊從上一個記憶持有者，抵達下一個記憶持有者。
