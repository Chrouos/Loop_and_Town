# Final｜18:31

> Status：Final thematic direction confirmed；Hard Reset stop mechanism and exact physical shutdown path remain TBD。
>
> 本文件定義最終章「要解決什麼問題」，但不提前假裝尚未設計完成的 Anchor / Reference / Synchronization 細節已經有答案。

Final 的核心不是打倒某個幕後黑手，也不是找出哪一個人應該死亡。

真正的問題是：

> **如果你真的比其他人知道更多結果，你是否因此有資格不停替他們修正現實？**

---

# 18:31｜因果收束點

18:31 不是：

```text
世界要求一個人死亡
```

也不是：

```text
Anchor 必須死亡
```

目前 Canon：

```text
18:31 = Causal Convergence / Synchronization Point
```

五年前的研究系統原本用來做：

```text
Real-world Data
↓
Urban / Disaster Digital Twin
↓
Prediction
↓
Simulation
↓
Intervention Recommendation
```

事故後，系統越過原本邊界：

```text
Simulation
↓
Reality Write-back / Synchronization
↓
現實開始被當成可以重新修正的狀態
```

因此玩家前面看到的 Worldline / Reset 現象，本質不是時間旅行研究的原始目的。

而是：

> **一套用來比較更好結果的系統，開始真的修改結果。**

---

# 為什麼「救到所有人」仍不等於結束

Chapter 3 已經建立：

```text
18:31
主角沒有確認到任何已知死者
↓
時間繼續
↓
23:59 鐘聲
↓
00:00 Hard Reset
```

因此：

```text
死亡 ≠ Reset trigger
```

Final 不能再退回：

> 其實只要找到正確的犧牲者就好。

玩家真正要理解的是：

> **即使某一輪結果看起來很好，只要 Reality Correction / Write-back 還在運作，系統仍可能把現實視為尚未完成的 Optimization。**

「系統到底如何判定要 Reset」的完整演算法仍待後續 Mechanism Spec 鎖定。

---

# 研究系統、知夏、主角其實做了同一件事

最終章要把三條線疊在一起。

```text
研究系統
結果不好
→ 改變 Intervention
→ 再比較
→ 再最佳化
```

```text
知夏
有人受傷 / 死亡
→ 改變人的行程
→ 看新結果
→ 再試一次
```

```text
主角
上一輪不滿意
→ 用記憶改變人物與 Schedule
→ 看新 Worldline
→ 再試一次
```

三者的出發點都可以是：

> 想讓結果更好。

真正危險的是它逐漸變成：

> 只要還有一個我不滿意的結果，就有理由再修改一次所有人的今天。

---

# Final 不應變成「反科技」

Ending C 不是：

```text
摧毀所有研究資料
關掉所有預測模型
拒絕科技
```

研究本來真的可以幫助：

- 災害疏散
- 醫療調度
- 電網備援
- 交通規劃
- 警消資源配置

真正越界的是：

> **Prediction / Recommendation 取得了直接重寫 Reality 的權力。**

所以 Final 應區分：

```text
Prediction / Simulation
可以存在

Reality Write-back / autonomous Correction
必須被解除
```

---

# Ending C｜真正破環

目前已確認的高層方向：

> **主角不是找到一條最完美的 Worldline，而是讓系統停止把 Reality 當成可以反覆最佳化的 Simulation Output。**

概念上：

```text
Before

Digital Twin
→ Predict
→ Optimize
→ Reality Write-back
→ 不滿意結果
→ Rewrite / Reset
```

Ending C：

```text
Digital Twin
→ Predict
→ Explain risk / possible outcomes
→ Human decision

X Reality Write-back
X autonomous Correction
X automatic Rewrite
```

這個 Ending 的真正勝利不是：

> 電腦算出了 0 deaths。

而是：

> **系統不再擁有替所有人把現實改成「它認為比較好」的權力。**

---

各角色應提供不同種類的必要理解。

```text
若晴

→ 把不同輪次與不同人的資訊拼在一起
```

注意：

> 上述是 Final 所需的角色功能方向，不代表具體設備、斷線方法已定案。

真正的物理／軟體 shutdown chain 仍需後續 18:31 Mechanism Spec。

# 最終選擇的倫理

即使找到停止 Write-back 的方法，也不能變成：

> 主角一個人知道答案，所以再次替所有人決定。

否則她只是在最後一刻完整變成知夏。

Final 應讓當輪真正會承受風險的人知道：

- 目前知道什麼
- 不知道什麼
- 停止 Write-back 的風險
- 不停止會發生什麼
- 沒有人能保證最終結果完美

這不是「全員投票才能按按鈕」的遊戲 UI。

而是故事原則：

> **Informed Choice 比單一知道最多的人替所有人決定更重要。**
