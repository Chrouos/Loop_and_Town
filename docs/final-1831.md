# Final｜18:31

Final 的核心不是打倒某個人，也不是找出唯一正解。

它要收束整個故事一直在問的問題：

> 拯救一個人，是否有資格建立在替其他人做決定之上？

> Canon note：Ending A / C 目前仍描述「Hard Reset 最終停止」的結果，但**停止機制本身尚未在 `story-canon-time.md` 定案**。
> 在機制確認前，這兩個 Ending 可作為 Story intent，但不能直接當作 runtime requirement。

---

# 18:31｜因果收束點

Chapter 7 結尾，所有主要角色第一次在**同一輪**共同知道輪迴存在。

18:31 到來時，車站區域再次出現異常：

```text
局部停電
鐘聲
舊設備啟動
時間錯位
```

但沒有人死亡。

這證明死亡從來不是必要條件。

柏勳從研究所殘留資料中拼出最後一塊：

18:31 是五年前實驗事故後形成的「因果收束點」。

不是時間停止，也不是世界倒帶。

而是從這個時間開始，灰潮鎮會逐步排除與既定歷史差距過大的狀態。

目前 Story Canon 中，午夜 Hard Reset 是這個修正過程完成的結果。

---

# 為什麼鐘聲存在

鐘樓的鐘體早已拆除。

但研究所早期曾把鐘樓當成同步測試點。

鐘聲不是實體鐘發出的。

它是當年同步訊號殘留在環境中的一種異常現象。

因此每次世界進入修正狀態時，鎮上部分人都可能聽見鐘聲。

不是所有人都一定聽見。

誰能清楚感知鐘聲，可能受到：

- 當下位置
- 感知方向
- 對同步異常的 Exposure
- story-specific sensitivity

影響。

這裡的 Exposure / sensitivity **不是跨 Loop 記憶，也不是 `memory_residue`**。

一般 NPC 即使聽見鐘聲，Reset 後仍不會因此保留上一輪記憶。

---

# 為什麼第七封信能跨世界線

知夏最後的實驗沒有試圖讓身體跨世界線。

她改成測試「資訊是否能留下」。

紙張、錄音、病歷、記憶持有者，都是不同資訊載體。

前面的實驗只能留下不穩定或單向的資訊。

第七封信第一次形成能跨越五年斷層、把資訊從知夏交接給主角的介面。

真正原因不是信本身特殊。

而是主角已經成為新的穩定記憶持有者。

知夏留下的是一個介面。

主角才是讓它持續存在的人。

---

# 最後衝突｜不能再由一個人決定

主角原本已經很接近重複知夏的道路。

她知道每個人的行程。
知道誰要去哪裡。
知道什麼話可以讓誰改變決定。

如果她願意，她甚至可以繼續嘗試更多 Loop。

但這一次，在 Reset 發生以前，其他人也知道正在面對什麼。

所以主角第一次把選項攤開。

不是：

> 我要救誰？

而是：

> 我們要不要繼續？

這個「一起決定」只代表**當前 Loop 的共同知情與選擇**。

如果之後再次 Hard Reset，一般 NPC 仍會依 Canon 忘記上一輪。

---

# Ending A｜接受單一世界

所有人在這一輪同意：不再讓主角繼續使用第七封信與跨世界線資訊機制反覆重試。

Story intent：

```text
停止跨線干預
→ Hard Reset 最終解除
→ 10 月 4 日第一次真正到來
```

但「為什麼停止跨線干預能解除 Hard Reset」仍是待確認的世界觀機制。

在該機制定案前，這段不能直接轉成 Event Graph 的硬規則。

代價是：

- 知夏仍然死於五年前
- 某些已發生的傷害不能被修正
- 沒有人能保證這是「最好」的世界線

但每個人第一次重新擁有真正不可逆的明天。

尾聲：

若晴把攝影作品寄出去。
予安沒有立刻賣店，但也沒有承諾永遠留下。
柏勳接受外地醫院邀請。
庭安正式公開研究所舊案。
志遠把錄音器登錄成補充證物。

主角把老家門關上。

這次不是逃走。

只是離開。

最後畫面：

手機日期。

**10 月 4 日。**

# Ending B｜繼續尋找完美世界

主角選擇保留第七封信與記憶傳遞機制。

在這一輪做決定時：

- 部分角色反對
- 部分角色願意承擔再試一次的風險

午夜仍然 Reset。

重要：Reset 後一般 NPC 不會保留這次共同決定。

```text
00:00 Hard Reset
→ 06:12 主角醒來
→ 主角記得 Ending B 的共同決定
→ NPC previous-loop memory reset
```

因此後續 Loop 若要再次形成共同知情，主角仍必須重新讓其他人理解現在的情況。

問題是故事不提供「下一次一定更好」的保證。

尾聲只留下：

```text
Loop 47
10 月 3 日
06:12
```

主角醒來。

她保留自己前一輪的 Captured Memory 與主觀經歷。

其中一段 Memory 是自己昨晚寫下的話：

> 不要再說「最後一次」。

---

# Ending C｜切斷跨世界線記憶傳遞

主角選擇破壞第七封信所代表的跨世界線資訊交接機制。

Story intent：

```text
跨線資訊傳遞失效
→ 主角不再能依靠既有跨 Loop 記憶持續干預
→ Hard Reset 最終解除
```

和 Ending A 一樣，**Hard Reset 為什麼因此解除仍待 Story Canon 定案**。

這個 Ending 不再描述普通 NPC「忘記其他 Loop」，因為他們本來就不保留其他 Loop 記憶。

真正的代價集中在主角與跨線資訊：

- 主角逐漸失去只存在於其他 Worldline 的主觀記憶
- Captured Memory 的跨 Loop 持續性開始消失
- 第七封信不再形成跨線回應
- 一般 NPC 維持原本 Canon：只記得當前世界線真正經歷的事情

最後留下的只有這個最終世界裡真正存在的物件與紀錄。

其中包括第七封信。

但上面的跨線內容正在慢慢消失。

最後只剩第一行：

> 回來一趟。

主角看著這句話，卻已經不確定自己為什麼難過。

這個 Ending 的核心不是「讓 NPC 忘記」。

而是：

> 活下去，是否一定要保留所有曾經不存在於這個世界的記憶？
