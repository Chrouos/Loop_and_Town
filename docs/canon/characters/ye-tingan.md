# 一句話定位

> 一個曾經相信「只要把真相公開，事情就會變好」，後來卻開始替別人決定哪些真相可以知道的人。

---

# 出身與研究背景

庭安不是灰潮鎮人。

她在都市長大，大學／研究所階段接受資料分析、社會研究與公共議題相關訓練，之後進入研究計畫，第一次來灰潮鎮時是外地研究人員。

最初她看灰潮鎮的方式很研究者：

```text
人口
交通
醫療量能
高齡化
事故率
商業衰退
```

對她而言，這些首先都是 Dataset。

而灰潮鎮具備：

```text
人口規模較小
歷史資料相對完整
交通節點單純
公共系統可觀測
地方政府合作意願高
```

因此在研究者眼裡，它曾經是一個「很適合做城市／災害決策模擬的場域」。

這句話後來會變成庭安最不願意回想的判斷之一。

---

# 她真正參與過什麼

庭安不是事故後才發現研究所危險。

她曾經親手參與過「為什麼灰潮鎮適合作為測試場域」的評估與報告。

當年的文字完全合理，例如：

```text
人口規模適中
資料完整
公共系統可觀測
地方合作程度高
風險可控制
```

其中甚至可能出現：

> 預期對居民日常生活影響有限。

後來這句話成為她最大的罪惡感來源之一。

重要：

她不是故意把居民當實驗品。

問題恰恰在於，整套程序在當時可能都有合理的審查、文件、地方合作與善意目的，最後仍產生沒有人真正理解的風險。

---

# 社會議題｜誰有資格代表一個地方同意？

研究計畫可以同時存在：

- 地方政府同意
- 醫院與公共系統合作
- 研究倫理程序通過
- 居民普遍支持地方發展

但這仍留下問題：

> 一個地方同意參與研究，究竟代表誰真正理解並同意了風險？

故事不把它簡化成非法人體實驗。

真正的問題是：

> 每一張文件都可能合法，每一個人都可能有合理理由，最後仍然可能累積出沒有人能單獨承擔的結果。

---

# 與林知夏

兩人最開始並不合。

庭安偏向相信可驗證的 Data。

知夏則重視：

- 地方誌
- 舊報紙
- 車站紀錄
- 居民口述
- 沒被正式系統記錄的人類經驗

兩人的典型分歧可以是：

```text
庭安：沒有資料支持。
知夏：那是因為你們從來沒有記錄這種東西。
```

但她們後來成為非常強的搭檔。

庭安教知夏：

- 如何整理資料
- 如何驗證時間序列
- correlation 與 causality 的差異
- 如何避免只相信自己想相信的結果

知夏則逼庭安理解：

> Dataset 裡的一筆變化，背後可能是一個人的生活。

---

# 事故後的第一次轉變｜公開全部

異常開始出現後，庭安最初的反應偏向：

> 把資料公開。

她相信只要居民、媒體與外部研究者看到資料，就有機會阻止錯誤繼續被隱瞞。

但她後來也看見另一面：

```text
片段資料外流
→ 媒體簡化成「死亡小鎮／詛咒事故」
→ 居民被獵奇採訪
→ 地方形象惡化
→ 商業／房產／醫療招募受到影響
```

她第一次真正理解：

> 真相公開，不代表真相會被理解。

---

# 第二次轉變｜由我決定什麼能公開

經歷外流與傷害後，庭安開始走向另一個極端。

她不再相信「全部公開」必然正確，而開始自己決定：

```text
哪些資料現在能公開
哪些資訊居民承受不起
哪些異常沒有足夠證據
哪些名字應該被保護
```

這使她逐漸變成自己曾經反對的人。

```text
反對知夏替別人選擇
↓
自己開始替別人決定「哪些真相可以知道」
```

---

# 為什麼後來成為調查記者

事故後庭安離開研究圈，成為調查記者。

表面的理由是：

> 想把被組織藏起來的事情挖出來。

但她更深的動機包含：

> 想證明當年的自己不是共犯。

因此她對資料封鎖、官方說法與「保護」非常敏感。

諷刺的是，她自己至今仍保留著一些沒有公開的知夏資料。

---

# 與主角

知夏曾要求庭安：

> 如果妹妹回來，不要讓她知道我做過什麼。

所以庭安第一次重新看見主角時，真正的想法更接近：

> 最不應該被捲回來的人，還是回來了。

這也是她一開始淡化自己與知夏關係的原因。

她不是單純敵對，也不只是說謊。

她正在履行一個已死朋友留下的要求，同時又知道這個要求本身可能正在剝奪主角的選擇權。

---

# 庭安看見主角正在重複知夏

庭安會是最早真正察覺主角正在走向知夏的人之一：

```text
知道不同結果
→ 預測人物行動
→ 安排人物位置
→ 用「結果比較好」合理化干預
```

因此她可以直接警告主角：

> 我以前也看過一個人開始說「我只是想讓結果好一點」。

這句話不是告訴玩家正解。

而是庭安基於自己與知夏的真實經歷提出的警告。

---

# 與陳柏勳

兩人長期互相不滿。

庭安認為柏勳太常用：

```text
醫療隱私
程序
病患保護
```

當作不回答問題的理由。

柏勳則認為庭安太容易相信：

> 只要資訊公開，公眾自然會正確理解。

但五年前最後兩個人都做了類似的事：

> 藏資料。

因此他們很清楚彼此的矛盾。

這不是單純敵對，而是一種：

```text
我知道你為什麼這樣做
↓
因為我也做過
↓
所以我反而更不能接受你替自己找理由
```

---

# 與周志遠

庭安與志遠分別站在「媒體／公共利益」與「警察／個人與證據程序」的位置。

典型衝突：

庭安：

> 公眾有權知道。

志遠：

> 那死者家屬的地址也算公眾有權知道嗎？

庭安：

> 不要拿保護當作藏證據的理由。

兩個人的真正爭點不是誰比較支持真相，而是：

> 公共利益、個人傷害與證據責任的界線到底在哪裡？

---

# 性格缺點

庭安不是單純「太執著真相」。

她真正危險的地方是：

> 當她掌握的資訊比別人完整時，很容易相信自己有資格決定資訊應該怎麼流動。

這使她與知夏、主角形成同一主題的不同版本：

```text
知夏
→ 控制世界線

主角
→ 控制人的行動

庭安
→ 控制資訊
```

---

# Arc

```text
相信公開真相就能解決問題
→ 發現公開也可能傷害人
→ 開始自己決定哪些真相能公開
→ 成為自己曾經反對的人
→ 重新面對五年前自己參與的研究與評估報告
→ 承認自己不能替所有人決定他們承受得起什麼
→ 把資訊、風險與選擇權一起交還給當事人
```

她的終點不是「把全部資料一次爆料」。

真正的成長是理解：

> 透明不等於把所有東西丟出去。
> 保護也不等於替別人隱瞞。

---

# 與整體故事主題的關係

庭安把故事從個人的選擇拉到更大的層次：

- 研究倫理
- 地方知情同意
- 公共利益
- 媒體倫理
- 資訊公開
- 專業者是否有權替當事人決定

她和主角面對的是同一個問題：

> 知道得更多，是否就代表有資格替別人決定？
