# Chapter 5｜只有我記得

這一章不再讓任何 NPC 產生上一輪記憶。

核心規則：

```text
Reset
→ 主角保留跨 Loop 記憶
→ 其他所有人回到當日原始狀態
→ 人格、喜好、價值觀與習慣保持一致
→ 但他們不記得和主角在其他 Loop 建立過的關係
```

這一章真正要傷害的是主角。

不是「別人一次又一次忘記她」，而是：

> 對其他人而言，那些共同經歷根本沒有發生過。
> 真正失去那些關係的人只有主角。

---

# 06:12｜Reset

主角在返鄉列車醒來。

上一輪，她和予安查了一整天。
一起整理店裡。
一起吃晚餐。
予安甚至說：

> 「如果真的還有明天，再跟我講妳這五年到底跑去哪裡了。」

現在手機顯示 06:12。

一切重來。

只有主角記得。

---

# 08:10｜「好久不見」

主角提早去鐘錶店。

予安看到她，只說：

> 「好久不見。妳不是下午才會到嗎？」

這句話本身沒有任何問題。

但對主角而言非常殘酷。

因為昨晚他們才一起吃過飯。

予安沒有失去那頓飯。

對現在這個予安來說，那頓飯從來沒有發生。

---

# 08:40｜主角知道得太多

主角想找五年前留下的舊設備。

她直接蹲到工作桌旁，打開最下面的工具箱，從底板夾層摸出備用鑰匙。

上一輪，是予安自己告訴她鑰匙藏在哪。

予安看著她：

> 「……妳怎麼知道備用鑰匙在那？」

主角只能說：

> 「猜的。」

這是這一章第一個倫理問題：

```text
我知道你的秘密
≠
你在這條世界線允許我知道
```

---

# Character Insight

玩家跨 Loop 保留的不應只有事件資料。

還有對一個人的理解。

這類資訊正式稱為 **Character Insight**。

它和 Evidence 不同：

```text
Evidence
→ 客觀紀錄
→ 照片
→ 病歷
→ 錄音
→ 通話紀錄

Character Insight
→ 喜好
→ 習慣
→ 價值觀
→ 說謊方式
→ 恐懼
→ 私人目標
```

Character Insight 不能直接當成證明。

它的功能是：

> 幫玩家知道「哪個假設不像這個人會做的事」。

---

# 09:20｜予安與父親的東西

主角再次陪予安整理店裡。

她注意到：

- 壞掉的錶帶沒丟
- 沒指針的錶盤沒丟
- 十幾年前的收據沒丟
- 父親留下的舊工具一件一件重新分類

這和另一輪她看過的予安完全一致。

因此解鎖：

```text
[Character Insight]
周予安不會主動丟掉父親留下的東西。
```

來源不是超能力。

只是主角真的花過時間認識他。

---

# 10:10｜人物理解第一次成為線索

父親留下的一個舊錄音器外盒不見了。

予安說：

> 「可能以前整理時被我丟了。」

主角立刻知道不對。

但她不能說：

> 「因為我在另一個今天看過你整理你爸的東西。」

於是玩家得到新的調查方向：

```text
不是：
予安把東西丟掉

而是：
誰移動過它？
誰借過同型設備？
誰知道後門與工具櫃？
```

最後找到一張五年前維修單。

林知夏死亡前一天，曾借走同型錄音設備。

Character Insight 沒有直接證明知夏拿走它。

但它排除了一個錯誤假設。

---

# 12:30｜「妳到底怎麼知道？」

一天裡主角已經不小心暴露太多資訊。

- 備用鑰匙位置
- 予安不會丟父親遺物
- 咖啡不加糖
- 他緊張時會突然講得很正式

予安終於問：

> 「我們五年沒見。」
>
> 「妳到底從哪裡知道這些？」

這不是因為他想起來。

恰恰相反。

就是因為他什麼都不記得，所以主角的熟悉才顯得異常。

---

# 15:40｜若晴也可以被「認識」

Character Insight 不只用在予安。

主角再次問若晴：

> 「我姊是不是還留了別的東西給妳？」

若晴回答：

> 「沒有。」

但她一邊說，一邊反覆把相機背帶拉平。

主角在另一輪陪她整理作品集時看過這個動作。

她知道：

```text
若晴緊張 ≠ 一定拉背帶
若晴真正想把話藏起來 → 常會反覆整理背帶
```

系統不應顯示：

```text
若晴正在說謊 100%
```

而是：

```text
[Insight]
她不是忘記。
她可能在迴避。
```

玩家因此可以換一種問法，而不是直接拆穿她。

---

# 20:10｜只有一個人記得的友誼

晚上，予安問主角要不要一起吃東西。

同一家店。
同一個位置。
他仍然會把筷子袋折兩次。

有些細節每次都差不多。
有些對話完全不同。

予安說：

> 「妳今天很怪。」
>
> 「可是又好像比以前更認識我。」

主角只能回答：

> 「也許我只是記性很好。」

予安笑了一下：

> 「那妳記得就好。」

他只是隨口一句。

主角卻知道這句話真正的重量。

---

# 主角真正承受的東西

```text
Loop A
第一次一起吃飯

Loop B
第一次談父親

Loop C
第一次知道賣店計畫

Loop D
第一次真正吵架

Loop E
第一次互相信任

Reset
↓
對予安而言全部不存在
↓
只有主角仍然背著 A～E
```

所以輪迴的情感代價不是 NPC 人格損傷。

而是記憶持有者擁有越來越多「只有自己承認存在過」的關係。

---

# 這也是知夏真正走偏的原因之一

知夏當年並不是因為輪迴讓她精神或人格變質。

更危險的是：

她越來越了解所有人。

```text
知道 A 會去哪
知道 B 遇到什麼會改路線
知道 C 在什麼情況會說謊
知道 D 最怕失去什麼
```

這些理解一開始是同理心。

最後卻很容易變成：

```text
理解
→ 預測
→ 安排
→ 控制
```

因此 Chapter 5 的真正警告是：

> 記住一個人，不代表有權替他決定。

# 章末

23:59。

沒有鐘的鐘樓再次響起。

主角第一次沒有只想到死亡或 18:31。

她想到的是今天新建立的關係。

午夜之後，那些關係又只會剩她記得。

而她開始理解：

知夏真正累積的可能從來不只是死亡次數。

還有無數條已不存在世界線裡，曾經認識過的人。
