# Chapter 5｜只有我記得

這一章不讓任何普通 NPC 產生上一輪記憶。

核心規則：

```text
Reset
→ 主角記得跨 Loop 經歷
→ Captured Memory / Investigation Wall 保留
→ 其他所有人回到當輪 Relationship State 起點
→ 人格、喜好、價值觀、習慣仍保持一致
```

真正承受輪迴重量的是主角。

> 對其他人而言，那些共同經歷沒有發生過。
> 真正失去那些關係的人只有主角。

---

# 06:12｜Reset

主角在返鄉列車醒來。

上一輪，她和予安查了一整天。
一起整理東西。
一起吃晚餐。

予安甚至可能說過：

> 「如果真的還有明天，再跟我講妳這五年到底跑去哪裡了。」

現在手機顯示：

```text
10 月 3 日
06:12
```

一切回到 checkpoint。

只有主角記得。

如果玩家上一輪 Capture 過那句話，它仍存在於 Memory Library。

予安本人不記得。

---

# 07:40｜又一次「好久不見」

Canonical arrival 仍是 07:20～08:00。

如果這一輪予安照原本安排來接她，主角會再次看見同一個人站在車站出口。

對予安而言：

> 五年沒見。

對主角而言：

> 昨晚才剛分開。

予安說：

> 「好久不見。」

這句完全正常。

也因此最殘酷。

舊版：

> 「妳不是下午才會到嗎？」

已廢止；那是 `14:20` 舊時間軸殘留。

---

# 08:10｜主角知道得太多

到了鐘錶店或其他合理場景後，主角可能下意識使用上一輪才知道的資訊。

例如直接找到備用鑰匙。

予安停下來：

> 「……妳怎麼知道在那？」

主角只能說：

> 「猜的。」

這是本章的重要倫理問題：

```text
我知道你的秘密
≠
你在這一輪允許我知道
```

Memory Input 不是免費社交權限。

---

# 人物理解的新定位

Character Insight 不是一種可自動解鎖的特殊 clue。

目前設計：

> **人物理解來自主角真實 Perceive / Capture 過的互動，再由玩家自己形成 hypothesis。**

它不是：

```text
[Character Insight Unlocked]
這個人一定會怎樣
```

玩家可以：

1. Capture 一段人物互動
2. 放到 Investigation Wall
3. 自己寫 Note
4. 在特定 Narrative Node 使用該 Memory Input

例如：

```text
[予安把父親留下的壞零件重新收好]

玩家 Note：
「他是不是很難真的把父親的東西丟掉？」
```

Note 是 hypothesis，不是角色資料庫的客觀答案。

---

# 09:20｜予安與父親留下的東西

主角再次和予安相處時，可能注意到：

- 壞掉的錶帶沒丟
- 沒指針的錶盤沒丟
- 十幾年前的收據還在
- 父親留下的舊工具被重新分類

如果玩家 Focus 並 Capture，只保存實際看到的 Moment。

遊戲不能自動跳出：

```text
[Insight]
周予安絕對不會丟掉父親的東西
```

因為那已經是推論。

---

# 10:10｜人物理解改變的是「我想查什麼」

假設某個父親留下的舊設備外盒不見了。

予安說：

> 「可能以前整理時丟了。」

如果玩家過去 Capture 過他的習慣，可以自己懷疑：

> 「真的會是他丟的嗎？」

然後主動查：

- 誰動過它
- 誰借過同型設備
- 誰知道工具櫃位置

人物 Memory 沒有排除假設的系統權力。

它只讓玩家有理由採取另一種調查行動。

---

# 12:30｜「妳到底怎麼知道？」

一天裡，主角可能不小心暴露太多：

- 備用鑰匙位置
- 咖啡習慣
- 父親遺物的處理方式
- 予安緊張時的語氣

予安終於問：

> 「我們五年沒見。」
>
> 「妳到底從哪裡知道這些？」

這不是因為他開始想起其他 Loop。

正好相反。

就是因為他**完全不記得**，主角的熟悉才顯得異常。

---

# 15:40｜若晴也可以被「認識」

主角問若晴某個知夏相關問題。

若晴回答得很短，同時反覆整理相機背帶。

如果主角另一輪真的觀察過類似行為，可能產生很弱的 Memory Resonance：

> ……她上次緊張時，也一直碰背帶。

到這裡停止。

不要顯示：

```text
她正在說謊
Lie probability 100%
```

玩家可以自己選擇追問、換話題或忽略。

---

# Memory Resonance 的限制

Memory Resonance 只能引用：

- 主角實際 Perceive 過的經驗
- 合理可回想的 persistent Memory

它不能：

- 自動比對矛盾
- 指定正確追問
- 告知 clue importance
- 揭露主角沒有看過的 World Event

甚至可能只是無關緊要的人物細節。

---

# 20:10｜只有一個人記得的友誼

晚上，予安可能再次問主角要不要一起吃東西。

同一家店。
同一個位置。

有些細節相似。
有些完全不同。

予安可能說：

> 「妳今天很怪。」
>
> 「可是又好像比以前更認識我。」

主角：

> 「也許我只是記性很好。」

予安隨口回答：

> 「那妳記得就好。」

只有主角知道這句話真正的重量。

---

# 主角真正承受的東西

```text
Loop A
第一次一起吃飯

Loop B
第一次談父親

Loop C
第一次知道賣店計畫

Loop D
第一次真正吵架

Loop E
第一次互相信任

Reset
↓
對予安而言那些版本不存在
↓
只有主角背著它們
```

所以輪迴的情感代價不是 NPC 人格受傷。

而是記憶持有者擁有越來越多：

> 「只有自己承認存在過」的關係。

---

# 知夏真正走偏的原因之一

知夏的危險不是輪迴把人格污染掉。

而是她越來越了解所有人：

```text
知道 A 會去哪
知道 B 遇到什麼會改路線
知道 C 在什麼情況會退縮
知道 D 最怕失去什麼
```

理解最初是同理心。

後來很容易變成：

```text
理解
→ 預測
→ 安排
→ 控制
```

Chapter 5 的真正警告：

> **記住一個人，不代表有權替他決定。**

---

# Gameplay integration

本章強化：

```text
Dialogue / Scene
  ↓
Attention
  ↓
Perception
  ↓
optional Memory Capture
  ↓
Memory Library
  ↓
Investigation Wall
  ↓
玩家自己的理解
  ↓
different approach / Memory Input
```

不要建立另一套 `Character Insight Inventory` 自動替玩家整理人物答案。
