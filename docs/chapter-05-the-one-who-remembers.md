# Chapter 5｜只有我記得

這一章不讓任何普通 NPC 產生上一輪記憶。

核心規則：

```text
Reset
→ 主角記得跨 Loop 經歷
→ Captured Memory / Investigation Wall 保留
→ 其他所有人回到這一輪原始記憶與 Relationship State
→ 人格、喜好、價值觀、習慣仍保持一致
```

真正承受輪迴重量的是主角。

> 對其他人而言，那些共同經歷沒有發生過。
> 真正失去那些關係的人只有主角。

---

# 06:12｜Reset

主角在返鄉列車醒來。

上一輪，她和予安查了一整天。
一起整理店裡。
一起吃晚餐。

予安甚至說：

> 「如果真的還有明天，再跟我講妳這五年到底跑去哪裡了。」

現在手機顯示 06:12。

一切重來。

只有主角記得。

如果玩家上一輪 Capture 過那句話，它仍存在於 Memory Library。

予安本人不記得。

---

# 08:10｜「好久不見」

主角提早去鐘錶店。

予安看到她：

> 「好久不見。妳不是下午才會到嗎？」

對予安來說完全正常。

對主角卻非常殘酷。

昨晚他們才一起吃過飯。

但對現在這個予安而言，那頓飯從來沒有發生。

---

# 08:40｜主角知道得太多

主角想找五年前留下的設備。

她直接蹲到工作桌旁，從底板夾層摸出備用鑰匙。

上一輪，是予安自己告訴她鑰匙藏在哪。

予安看著她：

> 「……妳怎麼知道備用鑰匙在那？」

主角只能說：

> 「猜的。」

這是這一章的重要倫理問題：

```text
我知道你的秘密
≠
你在這一輪允許我知道
```

Memory Input 不是免費社交權限。

---

# 人物理解的新定位

舊版把 Character Insight 當成一種可「解鎖」的特殊 clue。

目前設計改成：

> **人物理解來自主角真實 Perceive / Capture 過的互動，再由玩家自己形成 hypothesis。**

它不是：

```text
[Character Insight Unlocked]
這個人一定會怎樣
```

也不是：

```text
系統認證的人格真相
```

玩家可以：

1. Capture 一段人物互動
2. 把它放到 Investigation Wall
3. 自己寫 Note
4. 在特定 Narrative Node 用該 Memory Input

例如：

```text
[予安保留父親的壞零件]

玩家 Note：
「他是不是很難丟掉父親的東西？」
```

這個 Note 是玩家的 hypothesis，不是角色資料庫的正確答案。

---

# 09:20｜予安與父親的東西

主角再次陪予安整理店裡。

她可能注意到：

- 壞掉的錶帶沒丟
- 沒指針的錶盤沒丟
- 十幾年前的收據沒丟
- 父親留下的舊工具重新分類

如果玩家 Focus 這些細節並 Capture，可以留下例如：

```text
Loop 05 · 鐘錶店
Visual / Composite Memory
「予安把父親留下的壞零件重新收好。」
```

遊戲不要跳出：

```text
[Insight]
周予安不會主動丟掉父親留下的東西。
```

因為那已經是推論。

---

# 10:10｜人物理解改變調查方向

父親留下的一個舊錄音器外盒不見了。

予安說：

> 「可能以前整理時被我丟了。」

如果玩家手上有前面 Capture 的 Memory，可以自己懷疑：

```text
[Memory：予安保留壞零件]
        │
        │ 玩家自己的 Note
        ▼
「真的會是他丟的嗎？」
```

玩家因此可能去查：

- 誰移動過它
- 誰借過同型設備
- 誰知道後門與工具櫃

最後可能找到五年前維修單：林知夏死亡前一天曾借走同型錄音設備。

重要：

> 人物 Memory 沒有「排除錯誤假設」的系統權力。

它只讓玩家有理由選擇另一條調查方向。

---

# 12:30｜「妳到底怎麼知道？」

一天裡主角不小心暴露太多資訊：

- 備用鑰匙位置
- 咖啡習慣
- 父親遺物的處理方式
- 予安緊張時的語氣

予安終於問：

> 「我們五年沒見。」
>
> 「妳到底從哪裡知道這些？」

這不是因為他想起來。

恰恰相反。

就是因為他完全不記得其他 Loop，主角的熟悉才顯得異常。

---

# 15:40｜若晴也可以被「認識」

主角問若晴：

> 「我姊是不是還留了別的東西給妳？」

若晴：

> 「沒有。」

她一邊說，一邊反覆整理相機背帶。

如果主角另一輪曾經真正看過類似動作，可能產生很弱的 Memory Resonance：

> ……她上次緊張時，也一直碰背帶。

到這裡停止。

不要顯示：

```text
她正在說謊
她不是忘記，而是在迴避
Lie probability 100%
```

玩家可以自己 Capture 當下 Moment，放到 Investigation Wall，或選擇換一種問法。

---

# Memory Resonance 的限制

Memory Resonance 只能引用：

- 主角實際 Perceive 過的經驗
- 合理可回想的 persistent Memory

它不能：

- 自動比對矛盾
- 指定正確追問
- 告知 clue importance
- 揭露主角沒看過的世界事件

甚至可能只是：

> ……她上次也說過最近很冷。

不保證有用。

---

# 20:10｜只有一個人記得的友誼

晚上，予安問主角要不要一起吃東西。

同一家店。
同一個位置。
他仍然會把筷子袋折兩次。

有些細節相似。
有些對話不同。

予安：

> 「妳今天很怪。」
>
> 「可是又好像比以前更認識我。」

主角：

> 「也許我只是記性很好。」

予安笑：

> 「那妳記得就好。」

他只是隨口一句。

只有主角知道這句話真正的重量。

---

# 主角真正承受的東西

```text
Loop A
第一次一起吃飯

Loop B
第一次談父親

Loop C
第一次知道賣店計畫

Loop D
第一次真正吵架

Loop E
第一次互相信任

Reset
↓
對予安而言全部不存在
↓
只有主角背著這些世界線
```

因此輪迴的情感代價不是 NPC 人格受傷，也不是 NPC residue 增長。

而是記憶持有者擁有越來越多「只有自己承認存在過」的關係。

---

# 知夏真正走偏的原因之一

知夏的危險不是輪迴把她的人格污染。

而是她越來越了解所有人：

```text
知道 A 會去哪
知道 B 遇到什麼會改路線
知道 C 在什麼情況會退縮
知道 D 最怕失去什麼
```

這些理解最初可能是同理心。

最後卻很容易變成：

```text
理解
→ 預測
→ 安排
→ 控制
```

因此 Chapter 5 的真正警告是：

> 記住一個人，不代表有權替他決定。

---

# Gameplay integration

本章要特別強化目前 Core Loop：

```text
Dialogue / Scene
  ↓
Attention
  ↓
Perception
  ↓
Memory Capture
  ↓
Memory Library
  ↓
Investigation Wall
  ↓
玩家自己的「我好像開始了解這個人」
  ↓
Memory Input / different approach
```

不要建立另一套獨立的 `Character Insight Inventory` 來自動替玩家整理人物。

Author 端可以保留 Character Insight metadata 來維持角色一致性，但 Player 端的理解應來自 Memory 與自己的推理。

# 章末

23:59。

沒有鐘的鐘樓再次響起。

主角第一次沒有只想到死亡或 18:31。

她想到今天重新建立的關係。

午夜之後，那些關係又只會剩她記得。

而她開始理解：

知夏真正累積的可能從來不只是死亡次數。

還有無數條已不存在世界線裡，曾經認識過的人。
