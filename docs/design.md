# 灰潮鎮：第七封信｜聽見的城（Listening Town）遊戲體驗設計 v1

> Status：Active。本文件定義「聲音優先、純黑舞台」的遊戲體驗。程式在 `game/`。
> 故事核心與各章時間線見 `docs/story.md`。

---

## 1. 一句話

> **主角看不見。玩家也看不見。世界只剩聲音、觸感、氣味和別人說出口的話。**

這不是一個「網頁上的文字冒險」，而是一個戴上耳機、在黑暗裡聽一座小鎮一天、再聽一次、再聽一次的視覺小說。

## 2. 為什麼是失明的主角

| 原本的問題 | 失明主角帶來的答案 |
| --- | --- |
| 畫面需要圖片，但沒有美術 | 主角看不到，所以舞台本來就是黑的 |
| Attention / Focus 很難在網頁上「感覺到」 | 盲人本來就靠轉向聲音來分配注意力，切換注意力就是轉頭去聽 |
| 18:31 停電只是一個事件 | 燈熄的那一刻，所有人都跟她一樣；只有她不慌 |
| 文件、信件、照片是「閱讀 UI」 | 文件只能被別人念出來，或被手機的讀屏聲念出來；照片只能被描述 |
| 跨輪迴記憶是抽象設定 | 她記得每個人的腳步聲、說話的停頓、身上的氣味 |
| 最終章需要「主角的獨特能力」 | 她聽得見那個在 18:31 跟著同步的嗡鳴 |

## 3. 舞台（World Layer）

```text
                 前方（front）
          左前 ·            · 右前
                     
   左方 ·        ［中央：正在聽的話］        · 右方
                     
          左後 ·            · 右後
                 後方（back）
```

- 背景永遠是 `#000`。沒有圖片、沒有插畫、沒有對話框。
- **中央**只放「目前注意力所在」的聲音：別人說的話、主角自己說的話、主角心裡的話、感官敘述。
- **周圍八個方位**放「聲音提示」：擬聲字（沙——、窸窸窣窣、喀、叮）出現在聲音實際來源的方位，同時用 HRTF 空間音效從同一方向播放。
- 擬聲字下方有一行很小的**聲音來源**（「報紙」「衣服」「枯葉」），是她聽出來的東西，讓同樣是「沙沙」的聲音分得出來。預設取自 `game/src/audio/catalog.ts` 的 `SFX_SOURCE`，劇本可用 `src:` 改寫；設定裡可以關掉。擬聲字本身也盡量分開：紙「沙沙」、衣服「窸窣」、寫字「唰唰」、翻頁「啪沙」、枯葉「喀沙」。
- 距離：`near` 字大、靠內圈；`mid` 一般；`far` 字小、淡、靠外圈。
- **背景生活**：每種環境（`ambience`）有一組路人與雜音（車廂的「喀噠、喀噠」、咖啡店的「兩杯熱拿鐵，好的。」、街上的「菜頭一斤多少？」），由引擎隨機從空著的方位冒出，不會壓在角色或支線聲音的位置上。等待時更密，有人正對主角說話時變稀；畫面空著超過約 3.5 秒就會補一下；18:31 的嗡鳴、停電、鐘聲之後安靜一段時間。背景生活不能點、不算知道，內容在 `game/src/engine/life.ts`。路人台詞整場遊戲不重複，整池都聽過才會重來；兩段路人對話之間至少隔 15 秒；`reply` 可以是好幾回合的小對話（一家人、兩個鄰居）。所以每個有人的環境要準備夠多句。
- 每個聲音出現時，在它的位置泛起一圈很淡的漣漪（回聲定位的視覺化）。這是本作唯一的「圖像」。
- 說話的人在哪個方位，中央那句話就會往那個方位偏一點點，而且那個方位會泛起漣漪。說話者標籤是「主角認得出的聲音」：認識的人顯示名字（予安），不認識就顯示「陌生的女聲」。

### 3.1 文字的四種聲音

| 種類 | 呈現 |
| --- | --- |
| 別人說的話 | 中央、暖白、上方有極小的說話者名字 |
| 主角說出口的話 | 中央偏下、帶「」 |
| 主角心裡的話 | 中央、較暗、略斜、字距較鬆 |
| 感官敘述 | 中央、較小、灰白 |
| 手機讀屏 | 中央、等寬字、冷灰藍色，像機器念出來 |

文字以「片語」為單位浮現（Rhythmic Text）：在「，。？！……—」處停頓，每一段從模糊聚焦成清楚。不使用每字固定速度的打字機。

上一句話會以 Text Echo 留在上方，數秒內淡去，不堆成聊天紀錄。

## 4. 注意力：只有一個

> 你一次只能聽清楚一件事。

- 場景中可以同時有好幾件事在發生（`thread`）。主線以外的事以擬聲字出現在它的方位。
- **點一下那個聲音** = 主角把頭轉過去聽。轉向需要時間（約 0.7 秒），中央的話會模糊退開。**再點一下同一個聲音** = 回到自己。
- 主線講完時，如果主角還轉向別處在聽，場景會等那邊說完（或玩家自己轉回來）才換。
- 轉過去之後，中央換成那邊的內容；**原本的對話不會等你**，它在原方位繼續變成模糊的耳語（只看得到開頭幾個字和「……」）。
- 那邊的事結束後，注意力自然回到原本的對話（Elastic Attention）。你錯過的話不會重播。
- 很大的聲音會**強制奪走注意力**（例如 18:31 的撞擊）。這就是「被切換」。
- 有人直接問你問題時（主線出現選擇），注意力會被叫回來。

只有在注意力中被聽見的話，才算主角「知道」。背景裡模糊經過的話不算。

## 5. 互動：最少的按鈕

| 操作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 讓這句話快一點 | 點畫面任一處 | `Space` / `Enter` |
| 轉向一個聲音 | 點那個擬聲字 | `Tab` 選到它再 `Enter` |
| 記住剛才那句話 | 長按中央文字 | 按住 `Space` 0.6 秒 |
| 選擇 | 點選項 | `1` `2` `3` 或方向鍵＋`Enter` |
| 記憶／設定 | 右下角的小圓點 | `Esc` |

- 預設自動前進；設定可改成「等我點」。
- 沒有 HUD、沒有任務欄、沒有地圖、沒有「發現重要線索」。
- 選項出現在主角下方，像她準備開口；有時間限制的選擇會慢慢變暗，**沉默也是一種回答**。

## 6. 記憶（Memory Layer）

- 任何一句被聽清楚的話都可以長按記住；系統不會告訴你哪句重要（「最近真的好冷」也可以記）。
- 最多帶著 7 段記憶過午夜。滿了要自己放下一段，或這次不記。
- 記住時那句話會停住、沉進右下角的小圓點，伴隨一聲很輕的音。不顯示「已收藏」。
- 某些時刻，選項會多一個「（想起一句話……）」：挑一句帶著的記憶說出口。挑對了，對方的反應不同，會打開更好的路；挑錯了沒有懲罰，可以再選。
- 主角本人自然記得自己親耳聽過的事（劇情知識，跨輪保留）；記憶欄是玩家自己保證得了的那一份。

## 7. 時間與等待（半放置）

- 一輪是一個 10 月 3 日：06:12 列車醒來 → 18:31 → 23:59 鐘聲 → 00:00 重來。
- 時間以場景推進。時間與地點常駐在右上角；只有換章、換一輪，或換到另一個區域（`place` 逗號前那段，例如「林家老屋」）時，才在畫面中央出現大字卡。同一區域內換房間或跳時間，只更新右上角。
- **大部分時間是專注遊玩**：對話、轉向、選擇。
- **少數場景真的要等**（`wait`）：列車上的半分鐘、18:20 到 18:31 站在空無一人的舊車站外、鐘錶店裡陪予安修錶、二十三點五十九分的十二聲鐘響、最終章等待午夜。等待不能跳過，只能聽。
- 等待時離開分頁，回來時那段時間已經過去（世界不等你）；其他場景離開分頁會暫停，回來從場景開頭接上。

### 7.1 輪迴：試錯，但不重播

重來是這個遊戲的核心，可是同一段劇情聽第三次就是懲罰。規則：

1. **選擇決定這一輪聽不聽得到。** 每章有幾個關口：講錯話，對方就把門關上，這一輪拿不到那條線索。午夜時過章條件還缺，這一章重來。關口要有道理，玩家回頭想得通為什麼錯（第四章：他們只為「她親耳聽過的事」開口；第五章：說了實話又替他安排行程，他就不講自己的事；第七章：任何一句「替別人決定」的話，十八點三十一分都會有人因此受傷）。
2. **失敗也要給東西。** 關口失敗的那條路，一定讓她聽到一個線頭（`cN_lead_*` 知識）：門外的抽屜聲、起身時對方問的一句話、對方差一點說出口的事。下一輪那個關口會多一個用線頭開門的選項。所以每一輪都比上一輪多知道一點，選對的話下一輪就過得去。上一輪的後果，在她下一次要開口之前會再想起一次。
3. **聽過的地方不再去。** 知識跨輪保留，旗標不保留。第二輪起，已經拿到線索的場景整段跳過（用 `goto` 在前一場的結尾分流），只留一兩句心聲交代；還要去的場景，聽過的段落用 `know.*` 包成短版。
4. **每輪都經過的骨架要短。** 列車、月台、晚餐這些每輪都會走到的場景，`chloop >= 2` 時只剩幾個 beat。列車上的心聲用來說「上一輪缺了什麼、線頭是什麼」，這是玩家唯一的方向提示，不做任務欄。
5. **失敗的那一輪要有自己的內容。** 選錯不是「同一段劇情少一句」，是聽到另一個版本：被請出門、別人在電話裡受傷、他把話吞回去。那一輪本身就值得聽。

| 章 | 過章條件 | 關口 | 失敗時聽到的線頭 |
| --- | --- | --- | --- |
| 4 | 錄音、病歷、研究目的、「她看過妳死」 | 周警官（拿家裡的東西或沉默就被請出門）、陳醫生（只問她怕什麼）、庭安（替知夏辯護） | `c4_lead_drawer` 門外的抽屜聲、`c4_lead_count`「妳是第幾次來這裡？」、`c4_lead_promise`「我答應過她一件事。……算了。」 |
| 5 | `k_tower_kit`、`k_yuan_1758` | 直接逼問工具箱、晚餐前沒說實話或說了又替他排行程 | `c5_lead_kit`、`c5_lead_unsaid`、`c5_lead_arranged` |
| 7 | 六封信、錄音、「不要讓她變成我」，而且 `!flag.c7_placed` | 傍晚四通話：任何命令句 | `c7_lead_tingan`／`ruoqing`／`boxun`／`zhiyuan`：那個人在 18:31 的下場 |

測試：`game/tests/loopGates.test.ts` 走過每章的失敗輪與下一輪。

## 8. 動畫風格

- 一切從黑暗淡入、淡出到黑暗。轉場 = 全部聲音與文字沉入靜默 →（換區域時）時間地點字卡 → 環境聲淡入。
- 文字：模糊 → 清楚，向上漂 4px；退場時散焦並下沉。
- 擬聲字：出現時輕微放大再穩定；`far` 的字更淡、更慢。
- 漣漪：細線圓環，0.9 秒擴散並淡出。
- 震動感：撞擊、停電時畫面顫動；劇本可以用 `shake` 指定輕重（見 §10.1）。
- 心跳：主角緊張時整個畫面跟著心跳一縮一放，四周邊緣隨每一下泛起很暗的紅，同時聽得到心跳聲。快慢分三級，見 §10.1。
- 恍惚：痛或受到衝擊時整個畫面糊開、慢慢飄，外面的聲音被悶住，只剩她自己的心跳清楚。見 §10.1。
- 設定裡的「畫面晃動」可以關掉晃動和脈動（邊緣的紅仍會亮）；`prefers-reduced-motion` 也一樣不晃。
- 輪迴重置：十二聲鐘響 → 驟然靜默 → 心跳 → 列車聲從遠處湧上 → 手機讀屏「六點十二分」。

## 9. 聲音設計

大部分聲音是真實錄音（Freesound 的 CC0 素材，清單在 `game/public/audio/CREDITS.md`），每個聲音用 HRTF Panner 擺在它的方位。

- 90 個事件聲裡 70 個用錄音，24 個環境層全部用錄音。其餘是程序合成：人聲類（悄悄話、嘆氣、呼吸、輕笑，避免錄到真的字）、電子音（通知、廣播提示音、耳鳴），以及找不到合適錄音的幾個。
- 錄音還沒載完時先播合成版，載好後換成錄音，所以第一次進場景不會沒有聲音。
- 想調音量或音高：改 `game/tools/audio/spec.py` 再跑 `build.py`，說明在 `game/tools/audio/README.md`。開發時 `/audio-lab.html` 可以把每個聲音的錄音版和合成版切換比較。

- 環境層（ambience）：列車、月台、早晨街道、老屋、鐘錶店（滿室滴答）、咖啡店、醫院、警局、舊車站大廳、維修通道、研究所、雨、遠海、夜蟲、餐館、鐘樓廣場夜晚。
- 事件聲（sfx）：腳步、手杖、門、鈴、鑰匙、紙、相機快門、背帶扣、杯盤、磨豆、蒸汽、手機震動、錄音機、磁帶沙沙聲、列車煞車、汽車、單車鈴、施工、狗、海鷗、雨、風、雷、嗡鳴升起、燈管滋滋、停電、金屬撞擊、心跳、鐘聲……
- 說話者：每個角色有一個極輕的「聲音存在感」從他的方位發出，讓你知道他在哪裡。
- 手機讀屏有自己的電子音色。
- 後方聲音略悶（低通），幫助分辨前後。

建議戴耳機。標題畫面會提示，第一次進入有左右聲音測試。

## 10. 震動

`navigator.vibrate`（支援的裝置）：手機震動 `buzz`、撞擊 `crash`、停電 `thud`、心跳 `heartbeat`、鐘聲 `bell`。可在設定關閉。

### 10.1 主角的身體：畫面震動與心跳

畫面是她的身體。她看不見，所以畫面晃動的不是「鏡頭」，是她自己：被撞到、手杖掉了、心臟跳到胸口發疼。

| 寫法 | 效果 | 用在 |
| --- | --- | --- |
| `- shake: light` | 畫面輕顫一下（約 0.4 秒），手機輕震 | 嚇一跳、門被甩上、自己喊出聲 |
| `- shake: hard` | 畫面重重晃一下再慢慢停（約 0.7 秒），手機重震 | 摔倒、東西砸下來、手杖掉下樓梯 |
| `{ sfx: thud, ..., shake: hard }` | 音效同時晃 | 晃動要跟著一個真的聲音時，優先這樣寫 |
| `{ me: 不要！, shake: light }` | 這句話開始時晃 | |
| `- heart: slow` | 心跳約每分鐘 65 下，很輕，畫面幾乎不動 | 不安、等待、聽到一個名字 |
| `- heart: fast` | 約 105 下，聽得清楚，手機跟著震 | 害怕、奔跑、快要來不及 |
| `- heart: pound` | 約 140 下，畫面每一下都明顯一縮，邊緣發紅 | 崩潰、親耳聽到死訊、撞擊之後 |
| `- heart: off` | 停下 | 冷靜下來 |
| `- daze: light` | 畫面微微糊開、慢慢晃，外面的聲音變悶變小 | 頭昏、耳鳴、腦子一片空白、別人的話飄過去進不來 |
| `- daze: heavy` | 糊得更重、晃得更大，外面的聲音像隔著一面牆 | 劇痛、撞到頭、親耳聽到死訊後整個人斷線；只維持幾句 |
| `- daze: off` | 慢慢清回來（聲音約一兩秒才回來） | 回過神 |

- 恍惚時她自己的心跳和耳鳴（`tinnitus`）不會被悶住，反而變成最清楚的聲音。
- 恍惚和心跳一樣，換場景自動解除。`heavy` 時字幾乎看不清，只放在不需要讀清楚的幾句上；重要的線索台詞不要壓在 `heavy` 底下。

- 心跳會一直跳到改變或**換場景**為止。情緒延續到下一場，就在下一場開頭再寫一次。
- 音效帶 `vib: crash` 時自動 `shake: hard`，`vib: thud` 自動 `shake: light`，不用再寫。
- 寫在旁白裡的動作要具體（「我握著拳頭往胸口捶」「手杖順著石階一路敲下去」），效果是陪襯。不要只放效果不寫她做了什麼，也不要每場都用；一章挑幾個真正的高點。

## 11. 劇本格式（`story/*.yaml`）

每章一個檔案。Source of Truth 在 `story/`，遊戲在建置時直接讀取。

```yaml
chapter: 1                # 1–7, 或 final
title: 第一個今天
start: c1_prologue        # 本章每一輪的第一個場景
advance:                  # 午夜重置時依序判斷；都不成立就重玩本章
  - if: know.ruoqing_died
    to: 2
scenes:
  - id: c1_train
    time: "06:12"
    place: 返鄉列車
    ambience: [train_interior]
    cast: { yuan: front-right }      # 說話者預設方位
    life:                            # 選填：這個場景自己的背景聲，疊在環境的背景生活上；寫 off 則整場安靜
      - { text: 沙啦, sfx: page_turn, at: [front], dist: near }
      - { say: 借過一下。, voice: man, at: [left, right], dist: mid }
      - { text: 喀沙, src: 枯葉, at: [back], dist: mid }      # src：擬聲字下方的聲音來源
      - { say: 媽媽，還有幾站？, voice: child, reply: [{ say: 還早啦，再睡一下。, voice: woman }, { say: 我不睏。, voice: child }] }
    beats: [...]
    threads: { gossip: { beats: [...] } }
    next: c1_arrival                 # 主線跑完後進入的場景（也可用 goto / end）
```

### 11.1 Beat（每個 beat 是單一 key 的 map）

| Beat | 例子 | 說明 |
| --- | --- | --- |
| 感官敘述 | `- narr: 月台的風從背後推過來。` | |
| 主角說話 | `- me: 車沒誤點。` | UI 自動加「」 |
| 主角心聲 | `- think: 他的聲音比五年前低了一點。` | |
| 角色說話 | `- yuan: 比我想的早。` | key 是 cast id；方位取場景 `cast` |
| 角色說話（覆寫） | `- { yuan: 比我想的早。, at: left, as: 陌生的男聲, learn: k_x, mem: m_x }` | `at` 方位、`as` 標籤、`learn` 聽清楚才得到的知識、`mem` 記憶 id |
| 手機讀屏 | `- phone: 六點十二分。` | |
| 音效 | `- sfx: step@front-left` 或 `- { sfx: step, at: front-left, dist: far, text: 叩、叩, vib: tap }` | `text` 是畫面上的擬聲字；省略則只有聲音。`src: 報紙` 改寫擬聲字下方的聲音來源 |
| 換環境聲 | `- amb: [cafe, rain_on_window]` 或 `- { amb: [night_insects], fade: 0.1 }` | `fade` 是淡入淡出秒數，預設 2.4；停電這種瞬間斷掉的聲音用 0.1 |
| 移動 | `- move: { yuan: left }` | |
| 停頓 | `- pause: 1.5` | 秒 |
| 真實等待 | `- { wait: 60, clock: "18:20", until: "18:31" }` | 不能跳過；只能放在主線最外層 |
| 震動 | `- vib: heartbeat` | 只有手機震動，畫面不動 |
| 畫面震動 | `- shake: hard` | `light`／`hard`；也可以寫在音效或台詞上，見 §10.1 |
| 心跳 | `- heart: fast` | `slow`／`fast`／`pound`／`off`；持續到換場景，見 §10.1 |
| 恍惚 | `- daze: heavy` | `light`／`heavy`／`off`；畫面糊、聲音悶，持續到換場景，見 §10.1 |
| 更新時鐘 | `- clock: "18:31"` | 場景中途更新畫面上的時間 |
| 支線 | `- { cue: gossip, at: back-left, text: 窸窸窣窣, sfx: whisper }` | 啟動 `threads.gossip`，平行進行；點擊擬聲字轉過去聽；`grab: true` 強制奪走注意力 |
| 選擇 | 見下 | 只能在主線 |
| 條件 | `- { if: know.k_photo, then: [...], else: [...] }` | |
| 設旗標 | `- set: ruoqing_safe` / `- set: [a, b]` | 本輪有效，午夜清空 |
| 學到知識 | `- learn: k_x` | 永久（主角記得）；寫在台詞上則只有聽清楚時才得到 |
| 跳場景 | `- goto: c1_station` | 只能在主線 |
| 結束本輪 | `- end: reset` | `reset`／`ending_a`／`ending_b`／`ending_c` |

```yaml
- choice:
    timeout: 8            # 秒；省略 = 等到選為止
    default: 2            # 逾時採用第幾個（0 起算）；省略 = 最後一個
    options:
      - text: 「妳在我姊的照片裡。」
        if: know.k_photo_tingan
        then:
          - tingan: ……我只見過她幾次。
          - set: tingan_pressed
      - text: 「謝謝妳。」
        then: [...]
      - text: （什麼都不說）
        goto: c1_ruoqing
```

### 11.1.2 手和耳朵的互動

三種互動都會讓主線停下來等玩家，但都有時間上限，世界不會一直等：

```yaml
# 摸讀：從左往右滑過去，太快會摸不清楚。style: braille（凸點）／groove（凹痕）／engrave（刻痕，摸不出字，每格顯示「？」）
- touch:
    cells: [不, 要, 回, 來]
    style: braille
    prompt: 指尖從左邊慢慢滑過去   # 可省略
    timeout: 45                     # 秒，時間到她自己慢慢讀完（預設 45）

# 聽聲辨位：聲音每 2.6 秒從 at 的方向再響一次，玩家點方向。
# 相鄰方位（45 度內）和前後鏡像都算對；點錯一次後，正確位置會有一圈很淡的漣漪。
- locate:
    sfx: hum_rise
    at: right
    decoys: [{ sfx: light_buzz, at: left }]   # 干擾聲，至少和正確方向差 90 度
    tries: 2
    timeout: 12                               # 可省略；時間到算失敗
    prompt: 哪一個在跟著時間變大？
    success: [...]
    fail: [...]

# 點字板：照讀的順序寫點號（1–3 左排由上到下，4–6 右排）；畫面會左右反過來、由右往左打。
- punch:
    cells: [[3, 4, 5, 6], [1, 4, 5]]   # 數字符號＋4
    label: 4
    timeout: 90
```

- 只能放在主線，不能放在支線（thread）裡。
- 鍵盤：摸讀按 → 或空白鍵；辨位用數字鍵盤方位（8 前、6 右、2 後、4 左，斜角 7 9 1 3）；點字板按 1–6。

### 11.1.1 想起一句話（Memory Input）

```yaml
- choice:
    options:
      - text: 「我不知道。」
      - recall:                    # 選項文字預設是「（想起一句話……）」
          accept:
            - mem: m_yuan_pickup   # 帶著這句記憶，選了就走這裡
              then:
                - me: 第一天晚上，你說過一句話。
                - me: 你說，你會去接我。
                - set: c5_truth
            - mem: m_c4_tomorrow
              goto: c5_noon_truth
          miss:                    # 選錯記憶：演完這段，回到同一個問題（可省略）
            - think: ……不是這句。
```

- 玩家身上有記憶時才會出現。點下去會列出她帶著的記憶，挑一句說出口。
- 挑對了走 `accept`；挑錯了演 `miss`，再回到同一個選擇，剛才那句不會再出現。可以按「算了」回到一般選項，選擇的倒數會暫停。
- `accept` 是加分路線：主線一定要有不靠記憶的走法。
- 接受的記憶 id 必須是前面章節（或同章前面）某句台詞標的 `mem:`，驗證器會檢查。

- `text` 用「」表示說出口，用（）表示動作或沉默。**整個選項是「……」時，引擎會自動讓主角說出那句話**（不要在 `then` 裡再寫一次同樣的 `me:`）；（）選項不會自動說話。
- 選項有 `if` 時，條件不成立就不出現。至少要有一個沒有 `if` 的選項。
- `then` 是選後立刻發生的 beats，結束後回到選擇之後繼續；`goto` 直接換場景。

### 11.2 條件語法

`know.X`（永久知識）、`flag.X`（本輪旗標）、`mem.X`（目前帶著的記憶）、`seen.SCENE`（本輪去過的場景）、`loop >= N`（第幾輪，全遊戲）、`chloop >= N`（本章第幾輪），用 `!`、`&&`、`||`、括號組合。

### 11.3 方位

`front` `front-right` `right` `back-right` `back` `back-left` `left` `front-left`；`dist: near | mid | far`。

### 11.4 文字

- 「|」強制停頓。「……」與「——」會自然停頓。
- 一句話不要超過約 40 字；長的拆成多個 beat。
- 不要在文字裡標示重要性。

### 11.5 音效與環境 id

見 `game/src/audio/catalog.ts`（驗證器會拒絕未知 id）。

## 12. 驗收方式

- `npm test`：劇本驗證（格式、id、場景可達、每章都能到下一章、結局可達）＋引擎測試。
- 自動遊玩：以 headless Chromium 搭配 `?fast=1` 跑完所有章節與三個結局。
- 人工驗收：戴耳機遊玩（`cd game && npm run dev`）。
