# 第一輪故事｜第一個今天

> 第一輪的目的不是讓玩家破案，而是讓玩家先相信一個非常合理、但其實錯誤的因果。
>
> 同時必須讓玩家在死亡發生以前，先看見這些人原本正在過什麼生活。

> Gameplay note：本篇描述的是 Author Canon 與可被玩家遭遇的場景。
> World Event 不等於 Player Knowledge；實際能帶進後續 Loop 的 persistent gameplay record 仍需遵守 `Attention → Perception → optional Memory Capture`。

> Time note：本篇使用目前 Story Canon：`06:12` 為 Hard Reset checkpoint，`07:20～08:00` 抵達灰潮鎮，`18:31` 為 Causal Convergence，`00:00` Hard Reset。
> Runtime 的 Real-time Entry Mode 可以讓玩家較晚進場，但不能因此改寫此前已發生的 Author Worldline。

---

# 第一輪核心

```text
06:12 返鄉列車醒來
→ 07:20～08:00 抵達灰潮鎮
→ 重新碰到以前的人
→ 發現每個人都對知夏隱瞞了一點事情
→ 若晴走進舊車站
→ 18:31 若晴死亡
→ 柏勳成為最合理的嫌疑人
→ 發現五年前知夏也死於 18:31
→ 玩家第一次意識到自己的行動會改變別人的行程
→ 23:59 沒有鐘的鐘樓響起
→ 00:00 Hard Reset
→ 06:12 第一個今天重新開始
```

第一輪真正留下的問題不是「誰殺了若晴」。

而是：

> 為什麼所有人的今天，都像早就和五年前連在一起？

---

# 06:12｜返鄉列車

主角在列車上醒來。

窗外天色剛亮。
手機顯示：

```text
10 月 3 日
06:12
```

五年沒回灰潮鎮。

她對外說，這次只是回去整理老家。
房子空太久了，仲介一直催著處理。

只有她自己知道，真正讓她上車的是外套口袋裡那封信。

寄件人：林知夏。

郵戳：昨天。

她姊姊已經死了五年。

信的最後一句是：

> 如果午夜鐘聲響起，就代表又失敗了。

玩家此時可以閱讀、收起信件、看向窗外或繼續休息。

不管玩家做什麼，列車與世界時間都持續前進。

---

# 07:40｜抵達灰潮鎮

火車停穩時，主角才發現灰潮鎮的月台比記憶裡窄了一點。

周予安站在出口旁。

他沒有像久別重逢的人那樣揮手，只伸手接過她其中一個行李箱。

「比我想的早。」

「車沒誤點。」

「灰潮鎮唯一還算準時的東西。」

主角笑了一下。

兩人走出車站。

經過鎮中央時，她抬頭看見鐘樓。

塔還在。
上半部卻空了一塊。

「鐘呢？」

予安也抬頭。

「拆了。」

「什麼時候？」

「妳姊出事那年。」

「為什麼拆？」

「說是結構有問題。後來也沒裝新的。」

予安看了她一眼。

「妳怎麼突然問這個？」

主角沒有回答。

她只是想起信上的那句話。

> 如果午夜鐘聲響起，就代表又失敗了。

---

# 08:05｜老家

門鎖比記憶裡更難開。

予安試了兩次，最後用肩膀頂了一下門才鬆開。

清晨的光把灰塵照得很清楚。

主角站在玄關，一時沒有進去。

予安沒有催。

他先去把窗戶一扇一扇打開。

這是他一貫處理沉重事情的方法。

能搬的先搬。
能修的先修。
能不談的事情就先不要談。

整理到一半，他的手機震了一下。

螢幕上是一則房仲訊息。

> 今晚 20:00 還方便看店面嗎？

主角瞥到一眼。

「你要賣店？」

予安把手機翻過去。

「還沒決定。」

「你爸的店？」

「嗯。」

他拿起下一個紙箱。

「先處理妳這邊。」

這句話聽起來像答案，也像迴避。

---

# 08:25｜知夏的房間

房間幾乎保持著五年前的樣子。

書桌抽屜裡有三樣東西特別突兀：

- 一張舊研究所前的合照
- 一只停走的手錶
- 一本被撕掉大量頁面的筆記本

手錶停在 **18:31**。

主角按了幾次錶冠。
沒有反應。

「壞了？」

予安接過來看了一眼。

「不像自然停的。」

「什麼意思？」

「我不知道。要拆才知道。」

主角沒有讓他拆。

照片裡有知夏。

旁邊還站著一個年輕女人和幾名研究人員。

主角不認得那個女人。

筆記本更奇怪。

不是重要內容被撕掉。

而是每隔幾頁就少一張。

留下來的頁面充滿日期、時間、地點。

其中「18:31」出現了很多次。

但沒有任何解釋。

---

# 08:50～15:30｜回鎮後的白天

這段不是「等待劇情開始」。

世界已經在運作。

```text
若晴     08:00 上班
          11:30 整理攝影作品
          14:00 收到外地學校通知

予安     鐘錶店 / 主角老家之間移動
          20:00 原本有房仲約

庭安     按自己的調查路線準備晚上的研究所行動

柏勳     正常醫院行程
          17:40 原定秘密離院
```

玩家可能整理老家、在鎮上移動、休息、觀察環境或錯過某些 Opportunity。

不能因為第一輪主要劇情在傍晚才收束，就讓上午變成凍結狀態。

---

# 15:30｜要不要去郵局

予安終於仔細看到那封信。

他第一反應不是鬼故事。

而是把郵戳翻過來看。

「這可以查。」

「怎麼查？」

「郵局至少能確認這個戳是不是這裡蓋的。」

主角可以讓他去，也可以叫他留下。

這是第一個看起來很普通、但會改變後續 Schedule 的分歧。

如果他去郵局，他接下來幾個小時不會照原本路線經過舊車站。

如果他留下，他傍晚回店途中會經過車站附近。

主角此時不會知道，這兩條路會讓她失去不同的情報。

這不是「派遣 NPC 領獎勵」系統。

它成立的原因是：予安本來就在現場、他認為郵戳可查，而且玩家與他的關係足以讓這個請求合理發生。

---

# 16:10｜許若晴

老街的咖啡店還在。

女孩叫許若晴。

她正在空檔把幾張照片塞進牛皮紙袋。

主角只瞥到一張。

是灰潮鎮清晨還沒開門的商店街。

「妳拍的？」

若晴明顯愣了一下。

「嗯。」

「很好看。」

她把紙袋收進櫃檯下面。

「只是隨便拍的。」

手機螢幕在桌面亮了一下。

是一封外地學校寄來的信。

若晴很快按掉。

這是一件和林知夏、研究所、18:31 都沒有關係的事。

但對若晴本人來說，可能才是今天最重要的事情之一。

主角提到自己剛回來整理林家的房子。

若晴手上的杯子停了一瞬。

「林家？」

「林知夏是我姊。」

若晴低頭把杯蓋壓緊。

「我知道。」

「妳認識她？」

「以前在圖書館見過。」

回答不算是假話。

只是少了很多東西。

如果主角拿出那封信，若晴會特別注意郵戳日期。

「昨天？」

主角第一次注意到，若晴不是在問。

她像是在確認。

玩家如果此時把 Attention 移去別處，可能只聽到部分內容。

重要對話也不會因為「劇情重要」而自動重播或加入 Memory Library。

---

# 16:40｜葉庭安

主角離開咖啡店不久，一個女人主動叫住她。

她自稱葉庭安，調查記者。

最近正在做灰潮鎮人口外流和舊研究設施的專題。

主角覺得她眼熟。

直到想起房間裡那張照片。

「妳以前在研究所？」

庭安停了半秒。

「待過一陣子。」

「妳認識林知夏？」

「工作上見過幾次。」

照片裡庭安就站在知夏旁邊。

玩家可以當場追問，也可以暫時接受。

如果主角當場拆穿她，庭安不會因此才決定去研究所。

她今晚本來就要去。

改變的是她之後採取的方法。

這個後果要幾個小時後才會出現。

---

# 17:20｜若晴原本就有今晚

如果主角在咖啡店沒有把若晴逼到關閉對話，她可能主動傳訊息：

> 妳還在鎮上嗎？
>
> 我晚點要去舊車站。
> 有人要把知夏姊留下的東西交給我。

若晴不是因為主角回來，才突然有一條「劇情任務」。

即使主角今天沒有回灰潮鎮，她原本也會去。

如果主角問是誰約她，若晴只回：

> 陳醫生。

---

# 17:40｜陳柏勳離院

主角如果剛好在醫院附近並把 Attention 放到側門，可能看到陳柏勳離開。

他沒有穿白袍。
手裡拿著一只牛皮紙信封。

Author Truth：

```text
17:40  柏勳離開醫院
17:58  抵達舊車站
18:05  若晴抵達
18:07  柏勳把信封交給若晴
```

Player Knowledge 不會因為 Author Graph 有這四個節點就自動完整取得。

如果玩家跟蹤，才可能實際 Perceive 到更多內容。

---

# 17:52｜「妳也過來」

如果主角此前沒有跟著若晴一起走，她可能收到若晴的訊息。

> 我想了一下。
> 妳還是過來比較好。
> 18:00 之後，舊車站。

過幾秒又補一則：

> 有些東西本來就不是我的。

---

# 18:18｜最後一次正常對話

玩家如果在月台舊候車室附近找到若晴，她手裡拿著那只牛皮紙信封。

柏勳已經離開視線。

「裡面是什麼？」

「我還沒看完。」

「為什麼陳醫生要給妳？」

若晴沉默了一會。

「不是給我的。」

「是知夏姊叫他留著。」

「她說，如果有一天妳真的回來，再決定要不要交出去。」

主角立刻抓到問題。

「五年前她就知道我會回來？」

若晴沒有回答。

她從信封裡抽出一小張摺過很多次的紙。

上面只有一句知夏的字：

> 18:31 不是死亡時間。

若晴知道警告。
不知道原因。
更不知道完整輪迴。

---

# 18:31｜第一個死亡事件

18:30。

舊車站的電子時鐘突然亮了一下。

數字跳成：

**18:31**

下一秒，整個車站區域停電。

黑暗裡先傳來一聲金屬撞擊。

然後是一聲很遠的鐘響。

主角第一個念頭是鐘樓。

但她早上才親眼看見——那裡根本沒有鐘。

備用電源恢復時，若晴已經倒在舊月台旁。

牛皮紙信封散在地上。

柏勳不在現場。

若晴沒有明顯的大量外傷。

現場有燒焦味，舊電箱也留下異常痕跡。

玩家如果完整留在現場並實際感知到相關資訊，可能自己形成：

```text
17:40  柏勳秘密離院
18:05  柏勳與若晴碰面
18:07  柏勳把不明資料交給若晴
18:31  若晴死亡
```

這是一條非常合理的 False Causality。

玩家可能第一次產生：

> 陳柏勳殺了她？

這仍然只是玩家 hypothesis，不是系統判定。

---

# 19:10｜郵局沒有這封信

如果 15:30 讓予安去郵局，他此時才帶著結果回來。

「郵戳是真的。」

「郵票也是真的。」

「但系統裡沒有寄件紀錄。」

這是玩家可以實際聽見的行政異常。

遊戲不自動建立 Truth Card，也不宣告它一定重要。

---

# 19:20｜另一條被錯過的情報

如果沒有讓予安去郵局，他原本會在 18:10 左右經過車站外圍。

他可能看見葉庭安站在舊公車站牌旁，看著車站方向。

等救護車聲音出現後，她才離開。

玩家第一次理解：

> 讓一個人去做一件事，同時代表他沒有出現在另一個地方。

這是 Schedule consequence，不是任務獎勵差異。

---

# 20:00｜予安自己的事

20:00 左右房仲會打電話。

如果玩家一直讓予安陪著調查，他可能看著來電幾秒，最後按掉。

「你不接？」

「晚點再說。」

這個 Moment 不需要被系統標示成線索。

它只是提醒玩家：

> 自己要求一個人留下來，也是在改變他原本的人生。

---

# 20:30｜五年前也是 18:31

周志遠主動聯絡主角。

他沒有把真正藏起來的證物交出來。

只給主角看一份正式案件摘要。

```text
姓名：林知夏
地點：舊車站周邊
死亡時間：18:31
```

如果玩家確實已經感知到今天的死亡時間，才有材料自己並排：

```text
五年前 18:31  林知夏死亡
今天   18:31  許若晴死亡
```

系統仍不自動生成「Invariant」結論。

---

# 21:14｜庭安走了另一條路

庭安今晚本來就打算進舊研究所。

如果 16:40 沒有被主角拆穿，她會按較安全的原計畫進出。

如果被主角當場拆穿，她會改走更隱蔽、風險更高的維修入口。

```text
16:40 玩家追問
→ 庭安 exposure / pressure 改變
→ 19:50 改走維修入口
→ 21:14 手機暫時失去訊號
```

玩家只能知道自己實際能確認的部分。

例如：

```text
葉庭安暫時失聯
最後已知位置：舊研究所周邊
原因：未知
```

不要把 downstream cause 直接顯示給 Player。

---

# 22:40｜手錶後蓋

主角回到老家。

她重新看早上找到的手錶。

如果實際拆開後蓋，可以看到一道很淡的刮痕：

> 如果你第二次看見 18:31，
> 不要先救第一個死者。

這句話早上就存在。

不是因為劇情推進才突然生成。

只是當時主角還沒有理由把一只舊錶拆開。

---

# 23:20｜一段真正安靜的時間

午夜前需要一段沒有新線索的時間。

主角和予安可能坐在老家的廚房。

予安問：

「妳這次真的只是回來賣房子？」

主角把那封信推到他面前。

予安看完。

「妳一個人拿著這個坐車回來？」

「不然呢？」

「至少可以先跟我說。」

「你會信？」

予安想了一下。

「不會。」

然後補一句：

「但我會去接妳。」

這段沒有提供新的案件答案。

但玩家一樣可以因為在意而 Capture。

---

# 23:59｜沒有鐘的鐘聲

第一聲響起時，主角以為自己聽錯。

很低。
很遠。

第二聲。
第三聲。

聲音的方向就是鎮中央。

她把姊姊的信拿出來。

> 如果午夜鐘聲響起，就代表又失敗了。

鐘樓明明沒有鐘。

世界仍然繼續走向午夜。

---

# 00:00｜Hard Reset

第十二聲落下。

00:00 到達。

畫面熄滅。

這不是「日期停在原地、主角仍站在午夜現場」。

Canonical transition：

```text
23:59 鐘聲
→ 00:00 Hard Reset
→ World State reset
→ NPC Relationship / previous-loop memory reset
→ 10 月 3 日 06:12
```

畫面再次亮起時：

```text
返鄉列車
手機：10 月 3 日 06:12
主角醒來
```

所有上一輪產生的普通手機照片、通話紀錄與訊息都依世界狀態 Reset。

但主角記得。

玩家主動 Captured 的 Memory / Investigation Wall 仍在。

而外套口袋裡，那封第七封信作為 Story-specific exception 仍然存在。

主角把信攤開。

原本的內容沒有改。

只有最下面，多出一行她確定上一輪不存在的字。

> 這是第幾次了？

主角盯著那句話。

列車仍在前往灰潮鎮的路上。

第一輪結束。

---

# Player-facing memory rule

本章所有重要或不重要的 Moment 都遵守同一規則：

```text
World Event
→ Attention
→ Perception
→ optional Memory Capture
→ Persistent Memory
```

作者可以知道哪些事件對主線重要，但 Player UI 不因作者重要度而自動建立 Truth / Event / Invariant Card。

玩家也不會因為進入下一輪，自動獲得上一輪沒看到的完整 Author Timeline。
