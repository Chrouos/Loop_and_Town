# 世界觀與核心設定

## 故事起點

玩家五年前離開故鄉。
原因是姊姊 **林知夏** 在舊車站附近死亡，案件以意外結案。

五年後，玩家收到一封實體信。

- 寄件人：林知夏
- 郵戳：昨天
- 寄件地：故鄉郵局
- 問題：寄件人明明已經死了五年

信中留下警告：

> 回來一趟。
> 這一次，不要來找我。
> 如果午夜鐘聲響起，就代表又失敗了。

玩家因此回到小鎮。

## 小鎮

暫定名稱：**灰潮鎮**。

```text
                舊研究所
                    │
山區 ── 水庫 ── 舊車站
                    │
學校 ── 商店街 ── 醫院
 │          │        │
住宅區 ── 鐘樓 ── 警察局
                    │
                   河岸
```

小鎮會按照現實時間持續運作。
玩家不在線時，NPC 也會依自己的 Schedule、目的與關係繼續行動。

## 輪迴規則

- 日期被困在同一天。
- 時間仍正常向前流動。
- 午夜 00:00 後世界重置。
- NPC 通常不保留記憶。
- 玩家保留記憶、卡片與世界線歷史。
- 少數人物可能逐漸產生記憶殘留。

## 核心人物

### 林知夏｜已故姊姊

- 死亡時 26 歲。
- 曾是地方史研究者／圖書館員。
- 五年前死於舊車站。
- 死亡前半年開始記錄大量時間與日期、預知尚未發生的事。
- 真正秘密：她可能曾經也是輪迴記憶的持有者。

### 許若晴｜第一死者

- 23 歲，咖啡店員。
- 第一輪於 18:31 在舊車站附近死亡。
- 最近找到姊姊留下的某樣東西。
- 她真正的功能不是單純受害者，而是把五年前的事件重新拉回現在。

### 陳柏勳｜醫生

- 41 歲，小鎮醫師。
- 第一章最大的紅鯡魚。
- 17:40 會秘密離院，18:05 出現在舊車站。
- 五年前姊姊死亡當日也是他值班。
- 知道部分「輪迴後記憶殘留」現象。

### 周志遠｜警察

- 36 歲，小鎮刑警。
- 五年前姊姊死亡案件第一個到場的人。
- 有一項證物沒有登錄進證物清單。
- Gameplay 上提供監視器、戶籍、車牌、舊案與官方資料。

### 葉庭安｜記者

- 30 歲，自稱地方記者。
- 五年前其實是舊研究所研究助理。
- 對玩家說自己不認識林知夏，但照片證明兩人認識。
- 擅長查舊聞、黑歷史、地方傳聞與非官方資料。

### 周予安｜青梅竹馬

- 27 歲，經營鐘錶店。
- 玩家最早可以指派的調查角色。
- 多次輪迴後會逐漸出現夢境、Déjà vu、短暫記憶等殘留。

## 主線 Mystery

故事表面從「誰殺了許若晴？」開始，但逐層轉變：

```text
誰殺了她？
→ 為什麼每天都有人死亡？
→ 為什麼 18:31 一直出現？
→ 為什麼世界會輪迴？
→ 姊姊五年前到底做了什麼？
→ 為什麼玩家能保留記憶？
→ 玩家是否才是世界線不斷偏移的原因？
```

核心反轉方向：案件解決，不代表輪迴結束。
