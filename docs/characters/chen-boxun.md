# 陳柏勳｜41｜灰潮鎮醫院醫師

> Status：Confirmed Character Canon。
>
> 本文件記錄陳柏勳已定案的人物背景、核心倫理、私人生活與主要人物關係。
> 後續可補事件細節與 Schedule，但不得把他簡化成「冷漠醫師」或單純案件嫌疑人。

---

# 一句話定位

> 一個相信「專業就是替別人承擔風險」，最後卻發現自己也在用專業剝奪別人選擇的人。

柏勳承接的核心議題包括：

- 偏鄉／地方醫療縮編
- 專業權威
- 醫療隱私
- Informed Consent（知情同意）
- 「保護」與「替別人決定」之間的界線

---

# 出身與來到灰潮鎮

柏勳不是灰潮鎮出生。

年輕時在都市大型醫院接受訓練，之後因偏鄉／地方醫療計畫來到灰潮鎮。

原本只預計待幾年。

但灰潮鎮和都市醫院的差異逐漸改變了他：

```text
都市大型醫院
→ 資源多
→ 分工細
→ 病患量大
→ 自己只是醫療系統中的其中一名醫師

灰潮鎮醫院
→ 人力少
→ 所有人彼此認識
→ 很多病患從年輕一路看到老
→ 一名醫師離開，真的可能讓某些居民失去原有照護
```

所以他慢慢產生：

> 我不能走。

但這個「不能」不完全來自外界。

他也逐漸習慣自己是不可替代的人。

這使他的留下和周予安形成不同鏡像：

```text
予安
→ 被家庭責任一次次留下

柏勳
→ 被「大家需要我」這件事一次次留下
```

柏勳後來必須面對一個不舒服的問題：

> 我是真的想留下，還是已經需要「被需要」來證明自己的價值？

---

# 灰潮鎮醫療縮編

灰潮鎮醫院這些年持續面臨地方醫療惡性循環：

```text
人口減少
→ 部分科別與設備縮減
→ 夜間／專科醫療能力下降
→ 居民需要轉送外地
→ 醫師工作量上升
→ 更難招募與留任
→ 再次縮編
```

可以具體表現在：

- 婦產科停止常態服務
- 外科夜間人力縮減
- 部分檢查必須轉送外地
- 值班與 on-call 壓力集中在少數醫師
- 年輕醫師不願長期留任

柏勳收到過外地醫院條件很好的邀請。

但多年來始終沒有真正離開。

居民很容易把這解讀成：

> 陳醫師很偉大，他願意一直留在這裡。

柏勳本人卻逐漸無法確定這是不是完整答案。

# 家庭

柏勳曾結婚，目前離婚，有一名和前妻生活的女兒。

前妻也是醫療工作者，因此兩人的婚姻不是「她不懂醫療工作的辛苦」。

正好相反，她太理解每一次柏勳留下的理由。

多年來反覆發生：

```text
女兒生日
→ 醫院臨時缺人

家庭旅行
→ 病患突然惡化

說好回都市
→ 灰潮鎮又少了一名醫師
```

每一次柏勳都有合理理由。

兩人不是因一次重大背叛或大吵離婚，而是生活長期被「這一次真的沒辦法」慢慢侵蝕。

前妻曾對他說：

> 我相信每一次你留下都有理由。
>
> 可是我們的人生不能永遠排在所有理由後面。

這句話是柏勳角色的重要私人傷口。

它也讓他的問題不只是「工作狂」，而是：

> 當所有犧牲都可以被合理化時，一個人要到什麼時候才承認自己也正在做選擇？

# 性格

柏勳表面特徵：

- 克制
- 程序導向
- 不輕易把推測說成事實
- 對風險非常敏感
- 習慣先確認資料再下結論
- 對病患隱私有強烈界線

他的優點同時也是缺點。

他真正危險的性格傾向是：

> 我比你更清楚風險，所以有時候我應該替你決定。

例如：

```text
病人不要知道全部
因為可能會焦慮

居民不要知道異常
因為可能造成恐慌

若晴不要看到完整資料
因為她可能承受不了

主角不要知道知夏做過什麼
因為可能重蹈覆轍
```

這些理由都可能具有善意。

真正的問題是：

> 誰有資格決定另一個人「承受得起多少真相」？

# 柏勳 × 林知夏

這是柏勳最重要的過去關係之一。

知夏曾向柏勳描述：

> 她記得某些尚未發生的事情。

柏勳最初沒有相信世界線或超自然解釋。

作為醫師，他合理地先排除：

- 睡眠問題
- 長期壓力
- 神經系統異常
- 藥物影響
- 精神症狀
- 記憶偏差與 confabulation

這不是冷漠，也不是不相信知夏本人。

而是他的專業訓練要求：

> 不把無法驗證的敘述直接當成客觀事實。

真正的轉折發生在知夏準確預測了一件她理論上不可能提前知道的事故後。

柏勳第一次被迫面對：

> 自己的專業框架可能不足以解釋現在發生的事。

問題因此從：

```text
這是不是症狀？
```

變成：

```text
如果不能證明，但錯過它真的可能死人，我該怎麼辦？
```

---

# 醫療資料與第一次倫理滑坡

知夏後來開始要求柏勳協助確認：

- 特定死亡時間
- 急診紀錄
- 異常生理事件
- 可能和 18:31 有關的醫療資料

柏勳一開始拒絕將完整資料直接交給她。

理由合理：

> 醫療資料不能因為某個人相信世界線存在，就失去原本的隱私與程序限制。

但隨著事件一次次吻合，柏勳開始後悔自己是否太依賴制度。

於是他逐漸走向另一個極端：

```text
嚴格遵守制度
↓
制度無法處理異常
↓
開始私下替知夏保留／隱藏部分資料
↓
由自己判斷哪些規則可以破
```

這是柏勳真正的倫理滑坡。

不是從「守規則」變成「壞人」。

而是從：

> 沒有人可以凌駕程序。

走向：

> 既然只有我知道風險，那就由我決定什麼時候可以破例。

# 柏勳 × 許若晴

若晴的母親是柏勳長期照護的病人之一。

因此若晴從高中時期就認識柏勳。

兩人不是特別親密的朋友，但有很長的生活關係。

私下若晴甚至可能習慣叫他：

> 柏勳叔。

正式場合仍會稱「陳醫師」。

因此第一輪：

```text
17:40 柏勳秘密離院
18:05 若晴與柏勳見面
18:31 若晴進入危險節點
```

對玩家來說會非常可疑。

但後續才能知道：

> 他們本來就認識很多年，這次見面不是憑空出現的密會。

柏勳秘密離院的真正目的仍可維持：

> 將知夏當年留下／封存的部分醫療資料交給若晴。

這使他成為第一輪合理的 Red Herring，但不是因劇情需要突然出現在若晴身邊。

---

# 柏勳 × 葉庭安

兩人價值觀長期衝突。

庭安會認為：

> 你們當年就是一直說「還不能公開」。

柏勳則會回答：

> 因為那時候我們根本不知道那是什麼。

庭安追問：

> 那什麼時候才算知道？

柏勳的問題則是：

> 當公開造成不可逆的傷害時，誰負責？

兩人都不是單純支持或反對公開。

真正衝突是：

```text
庭安
→ 害怕資訊被權力控制

柏勳
→ 害怕不完整資訊造成不可逆傷害
```

但五年前最後兩人都選擇藏過部分資料。

因此他們最理解彼此，也最清楚彼此的矛盾。

---

# 柏勳 × 周志遠

柏勳與志遠並非只因五年前案件才不合。

兩人的職業界線長期存在摩擦。

志遠會認為：

> 醫院總拿隱私當作不配合調查的理由。

柏勳則認為：

> 警察拿到法律授權，不代表就理解病人把什麼交給醫師。

兩人都覺得對方把自己的職業權力看得太大。

而五年前，他們卻分別做了：

```text
柏勳
→ 隱藏／封存部分醫療資料

志遠
→ 隱藏未登錄的異常證物
```

因此他們最後都變成自己曾經批評的人。

這是一條重要鏡像關係。

---

# 柏勳 × 主角

第一輪主角非常可能懷疑柏勳。

而柏勳也會很快對主角產生警戒。

原因不是單純覺得她精神異常。

而是他五年前已經看過：

```text
林知夏
→ 開始知道不可能提前知道的事情
→ 嘗試改變事件
→ 逐漸走向更深的世界線干預
```

當主角也開始說出：

> 若晴今天不能去車站。

或提前知道特定事件時，柏勳真正的第一反應可能是：

> 又開始了。

他害怕的不是「主角瘋了」。

而是：

> 知夏身上發生的事情，正在她妹妹身上重新發生。

因此他可能以保護主角為理由，再次嘗試限制資訊。

這正是他必須跨越的角色問題。

# 今天

保留已建立的主要節點：

```text
白天
→ 正常醫院工作／處理縮編下的日常醫療壓力

17:40
→ 秘密離院

18:05 前後
→ 與若晴接觸，處理知夏留下的封存資料

18:31
→ 被捲入世界線事件及後續嫌疑
```

他的 Schedule 不應只服務案件。

在玩家完全不介入時，他仍應有：

- 病患
- 醫院行政
- 人力調度
- 家庭聯絡
- 是否接受外地 offer

等自己的生活事件。

# Character Arc

柏勳的成長不是「放棄規則」。

而是重新理解專業角色的邊界。

```text
相信專業程序
↓
遇到程序無法解釋的異常
↓
開始由自己決定哪些規則可以破
↓
以保護為理由控制資訊
↓
發現自己也在剝奪病人／當事人的選擇
↓
學會完整說明資訊與風險
↓
讓當事人自己決定
```

他的終點應回到真正的 Informed Consent：

> 專業者的責任不是替別人選出最安全的人生。
>
> 而是讓對方理解風險、代價與不確定性之後，仍然保有選擇的權利。

# 與整體故事主題的關係

柏勳與知夏、主角、庭安其實面臨同一個問題：

```text
我知道得比你多
↓
我看得到你看不到的風險
↓
我是不是因此更有資格替你決定？
```

角色的答案必須逐漸走向：

> 知道更多代表更多責任，不代表更多替別人決定人生的權利。

這使柏勳不只是醫療線 NPC，也成為遊戲核心倫理主題的重要一面。
