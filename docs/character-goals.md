# 聽見的城｜人物與沉浸目標（2026-11 改稿用）

> 這一輪改稿的驗收標準。寫手照這份改，讀者照這份驗收。搭配 `docs/story-core.md`（主題、反轉）、`docs/canon/character-bible.md`（人物全貌）、`docs/style.md`（文風）。

## 總目標

**每個人都住在這個鎮上，不是為了故事出場。** 他們今天本來就有自己的事、自己的想法和堅持；主角闖進來，跟他們撞在一起。

## 驗收項目

| # | 目標 | 怎麼算做到 |
| --- | --- | --- |
| G1 | 各有主軸 | 主要角色每次出場，至少有一個跟主線無關、屬於他自己生活的具體細節或行動：今天在忙的事、手上的東西、跟別人的關係。不能只是來給線索的 |
| G2 | 會碰撞 | 角色的理念跟主角的做法衝突時，不會因為一句話就讓步；他照自己的堅持反應，有時候主角是錯的 |
| G3 | 要證據才說得動 | 關鍵的說服點，主角要拿出之前輪迴得到的證據（`know.k_*`：他自己講過的話、只有他知道的事、查得到的紀錄）。沒有證據時，只拿到一部分或被拒絕，而且要讓玩家知道少了什麼 |
| G4 | 感受得到溫暖 | 角色會主動、不張揚地照顧她：一個小動作、一句不看她眼睛的話。是陪伴，不是同情（她討厭被同情） |
| G5 | 關係往前走 | 每段關係有遞進：怎麼認識、怎麼更了解、哪一刻靠近。輪迴後對方又從陌生開始，只有她記得；這種不對稱要寫得細，尤其是她記得、對方卻不記得的小事 |
| G6 | 有一段怎麼救都救不了 | 至少一段絕望：她試了每一種方法，那個人還是出事。用失明的無力感和玩法一起做，例如聽不到、找不到路、讀屏念不出、手杖掉了、時間來不及。要有出口：絕望之後，有人陪著她，或她換一種方式理解問題，章節仍然過得了 |
| G7 | 遊戲性 | 用上新的聲音效果（手機讀屏會念出來、每個地方有回音、緊張時聽得到自己的呼吸），或加入新的互動，讓玩家用耳朵做決定，不只是選文字 |
| G8 | 基本功 | 台灣口語、不說教、沒有 AI 味（`docs/style.md`）；盲人視角正確；輪迴邏輯正確（角色不記得前一輪，`flag` 每輪重設、`know` 跨輪保留）；測試全過 |

## 寫法提醒

- 給證據的寫法：`if: know.k_x` 的選項或台詞，讓有證據的玩家多一條路；沒有證據時，角色的拒絕要合理，並留下 `lead_*` 讓玩家知道下次要找什麼。
- 溫暖不用講出來。用動作寫，而且只有她注意得到。
- 只有她記得的痛：用「她記得、對方不記得」的具體小事（第一次他把手肘伸過來的高度、她念過的那張照片），不要寫成「只有我記得，好痛」。
- 不要新增說教句，也不要把主題講成結論。
- 新增或刪改劇情時，跨章引用要一起檢查（`know.*`、`mem.*`、`seen.*`）。
