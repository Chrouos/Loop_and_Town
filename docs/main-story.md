> 這份文件負責主線推進與每章認知轉折。
>
> Gameplay interaction、Perception、Memory 與 Investigation 規則以 `docs/core-gameplay-spec-v0.1.md` 為準。

人物細節見 `docs/character-bible.md`，人物關係見 `docs/relationship-map.md`。

---

# 主線核心

```text
第七封信
→ 回到灰潮鎮
→ 許若晴在 18:31 死亡
→ 玩家以為是謀殺
→ 改變世界線後死者改變
→ 成功做到無人死亡，午夜仍重置
→ 回頭重建五年前林知夏死亡日
→ 發現只有主角保留跨 Loop 記憶
→ 開始利用對人物的真實經歷與理解調查
→ 發現前六封「信」
→ 發現知夏曾經也是世界線記憶持有者
→ 理解 18:31 是因果收束點
→ 玩家決定什麼才叫做「拯救」
```

主線原則：每一章都推翻上一章一個重要假設，而不是單純增加更多線索。

---

# Memory Canon

```text
Reset 後：
主角保留自己的主觀經歷
Captured Memory / Investigation Wall 持續
其他角色不保留上一輪記憶
其他角色人格、喜好、價值觀與習慣保持完整
```

NPC 不會因為輪迴逐漸產生人格污染或 generic Memory Residue。

輪迴的情感代價集中在記憶持有者：

> 關係真的發生過，但下一輪只有主角承認它存在過。

# Chapter 0｜第七封信

## 玩家相信的事

姊姊林知夏已死五年。
這封昨天才寄出的信不可能存在。

## 發生的事

主角因整理老家回到灰潮鎮。
周予安重新出現在她生活中。
老屋、鐘樓、舊車站與五年前的記憶重新連上。

信件要求主角回來，但留下矛盾警告：

> 這一次，不要來找我。

## 章末問題

到底是誰用林知夏的名字寄信？

---

# Chapter 1｜第一個今天

## 玩家相信的事

這是一樁與姊姊舊案相關的新謀殺。

## 核心事件

```text
17:40 陳柏勳秘密離院
→ 18:05 與許若晴碰面
→ 18:31 許若晴死亡
```

這條時間線刻意建立 False Causality。

玩家會自然懷疑柏勳，但真正重要的是：若晴為什麼今天一定要去車站。

## 章末推翻

午夜後日期沒有前進。
世界重置。
主角保留記憶。

---

# Chapter 2｜活下來的人

## 玩家新的假設

只要阻止若晴到舊車站，就能阻止 18:31。

## 世界線改寫

```text
玩家提前取得若晴信任
→ 知道她準備離開
→ 讓她改變行程
→ 若晴沒有抵達舊車站
→ 柏勳無法完成原本交付
→ 柏勳自行處理封存資料
→ 18:31 柏勳死亡
```

若晴活下來。

20:30，她仍會去咖啡店提出辭職。
玩家第一次親眼看到「活下來的人還有自己的下一件事」。

## 章末推翻

```text
阻止死者出現在現場
≠ 阻止事件
```

詳細因果見 `docs/chapter-02-living-survivor.md`。

---

# Chapter 3｜沒有死者的世界線

玩家開始把 Loop 當作可比較的不同經歷。

經過數輪後，玩家讓所有已知高風險人物都避開 18:31 的危險節點。

18:31 無人死亡。

但是：

```text
23:59 鐘聲響起
→ 00:00 日期再次重置
```

## 章末推翻

```text
死亡 ≠ 輪迴原因
```

這是整個前半段最大的認知轉折。

---

# Chapter 4｜五年前

玩家停止只研究「今天」，轉而重建林知夏死亡當日。

三份互相矛盾的資料被拼起來：

```text
周志遠：未登錄錄音設備
陳柏勳：封存醫療紀錄
葉庭安：研究所實驗紀錄
```

三人五年前都曾隱瞞資料。
不是同一個共謀，而是三個人分別相信自己的隱瞞能避免更大的傷害。

玩家逐漸理解：五年前可能也不只發生過一次。

---

# Chapter 5｜只有我記得

這一章推翻「跨 Loop 有價值的只有文件與物證」。

主角發現自己真正累積的還包括與人物相處過的經驗：

```text
一起吃過什麼
某人緊張時會怎麼說話
誰很難丟掉父親留下的東西
誰在壓力下會反覆整理相機背帶
```

但這些內容**不是系統認證的 Character Insight 答案**。

Canonical flow 是：

```text
真實相處 / Observation
→ Perception
→ 玩家選擇 Capture 某個 Moment
→ 跨 Loop 保留
→ 玩家自己形成對人物的理解
```

人物理解可以成為：

- Investigation Wall 的玩家 Note
- 玩家形成 hypothesis 的背景
- 特定 Narrative Node 接受的 Memory Input
- 很弱的 Memory Resonance 來源

它不能直接：

- 宣告角色正在說謊
- 自動排除嫌疑
- 自動解鎖正確問題
- 將性格傾向當成客觀證據

同時，主角開始承受關係不對稱：

```text
上一輪與予安建立友誼
→ Reset
→ 予安重新依這一輪的經歷認識主角
→ 主角仍記得曾經一起經歷的事情
```

## 章末推翻

不是「其他人終究也會記得」。

而是：

> 可能一直都只會有一個人記得。

這也是知夏當年逐漸把「理解人」變成「安排人」的危險起點。

詳細見 `docs/chapter-05-the-one-who-remembers.md`。

---

# Chapter 6｜前六封信

主角發現自己收到的實體信只是第七個跨世界線訊息實驗。

```text
1. 未寄出的紙條
2. 圖書館借閱卡背面的字
3. 錄音帶中的一句話
4. 醫療資料上的手寫備註
5. 被庭安燒掉、卻再次出現的信
6. 記憶持有者本身
7. 主角收到的實體信
```

第六封不是把記憶塞進予安或其他 NPC。

它的意思是：

> 如果世界每次都重置，那最穩定的載體可能就是「唯一不被重置的人」。

知夏曾用自己的記憶跨越她的 Soft Rewrite；現在主角也正在做同一件事。

第七封真正特殊之處，是它不只讓同一個記憶持有者把資訊帶到下一輪，而是把資訊從五年前的知夏送到了五年後的主角手上。

---

# Chapter 7｜林知夏

玩家終於不再只看到「死去的姊姊」。

知夏曾經歷自己的 Worldline Rewrite。
她一開始也相信存在所有人都能活下來的完美解。

但在反覆嘗試後，她開始做取捨：

```text
救 A → B 死
救 B → C 死
讓主角離開灰潮鎮 → 其他人承擔風險
```

她真正被磨損的不是人格，而是獨自保留了太多不存在世界線的死亡、友誼與選擇。

主角必須接受一件事：

林知夏愛她，但這份愛也曾讓知夏把危險移給別人。

---

# Final｜18:31

最終真相：18:31 是因果收束點，而不是固定死亡時間。

研究所事故讓灰潮鎮在每天 18:31 後開始排除與既定歷史差距過大的狀態。
午夜重置只是修正完成的結果。

因此最終問題不是「抓到兇手」。

而是：

```text
接受不完美的單一世界
vs
繼續輪迴追求可能不存在的完美世界
vs
放棄跨世界線記憶與傳輸，讓所有人真正重新生活
```

所有結局都必須回到同一主題：玩家如何定義「拯救」。
