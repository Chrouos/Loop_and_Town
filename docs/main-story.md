# 主線核心

目前 Canon 主線應讀成：

```text
灰潮鎮地方更新
→ 主角因林家老屋處理需求安排返鄉
→ 同一波更新重新碰觸五年前的研究／城市系統
→ 主角出發前收到知夏名義寄出的「不要回來」
→ 她仍按原定行程返鄉
→ 許若晴在 18:31 死亡
→ 玩家以為是謀殺
→ 改變行程後，18:31 的結果改變
→ 即使沒有已知死者，午夜仍 Hard Reset
→ 玩家回頭重建五年前林知夏死亡日
→ 發現知夏曾經也保留過 Worldline Rewrite 的資訊
→ 主角開始利用跨 Loop 記憶理解人物與因果
→ 逐漸發現研究原本是災害／城市韌性 Digital Twin，而非時間旅行
→ 發現真正問題是 Prediction / Intervention / Reality Write-back 的失控
→ 理解「找到更好結果」與「有權替所有人決定」不是同一件事
→ 最終面對如何停止 Reality Optimization / Rewrite
```

主線原則：每一章應推翻上一章一個重要假設，而不是只增加更多線索。

---

# Memory Canon

```text
Reset 後：
主角保留自己的主觀經歷
Captured Memory / Investigation Wall 持續
其他角色不保留上一輪記憶
其他角色人格、喜好、價值觀與習慣保持一致
```

NPC 不會因為輪迴逐漸產生人格污染或 generic Memory Residue。

輪迴的情感代價集中在記憶持有者：

> 關係真的發生過，但下一輪只有主角承認它存在過。

# Chapter 0｜不要回來

## 玩家相信的事

林知夏已經死了五年。

主角本來只是準備回灰潮鎮處理老屋。

返鄉行程在信出現以前就已經確定。

## 發生的事

```text
舊城更新 / 產權與房屋處理
→ 主角約好仲介
→ 買好返鄉車票
→ 出發前收到信
```

信件：

```text
寄件人：林知夏
郵戳：昨天
內容核心：不要回來
```

信不是召喚。

真正令人不安的是：

> 一個死了五年的人，似乎知道她正在準備回灰潮鎮。

## 章末問題

到底是誰寄信？

為什麼五年前一直阻止她回來的知夏，五年後又以同一句話出現？

# Chapter 1｜第一個今天

詳細見 `docs/first-loop-story.md`。

## 玩家相信的事

今天發生的是一樁與知夏舊案有關的新死亡事件。

柏勳的行動尤其可疑。

## 核心事件

```text
17:40 柏勳秘密離院
→ 18:05 與若晴碰面
→ 18:31 若晴死亡
```

這條時間線刻意建立 False Causality。

真正重要的不只是「誰殺了若晴」，而是：

> 若晴原本為什麼就會去舊車站？

## 章末推翻

```text
23:59 沒有鐘的鐘聲
→ 00:00 Hard Reset
→ 10/3 06:12 返鄉列車
```

主角記得。

信仍存在，但只是因為它在 06:12 checkpoint 前就已經存在。

第一輪不讓信自動增加新文字。

# Chapter 2｜活下來的人

## 玩家新的假設

只要阻止若晴走進已知危險路徑，就能阻止 18:31。

## 世界線改寫

可能形成：

```text
主角提前介入
→ 若晴改變行程
→ 柏勳原本的交付路線改變
→ 其他人物位置與決策連鎖改變
→ 18:31 出現不同 Failure Path
```

其中一條可由柏勳成為死者。

重點不是「系統指定下一個替死鬼」，而是：

> 主角改變一個人的行程，也重排了其他人的因果。

## 章末推翻

```text
阻止第一個死者
≠
阻止 18:31 的根本問題
```

# Chapter 3｜沒有已知死者的世界線

玩家開始把 Loop 當作可以比較的多次經歷。

她試著讓自己已知的高風險人物避開 18:31。

這一輪，主角沒有確認到任何已知死者。

但：

```text
23:59 鐘聲
→ 00:00 Hard Reset
```

## 章末推翻

```text
死亡
≠
Hard Reset trigger
```

這是前半段最重要的認知轉折之一。

詳細見 `docs/chapter-03-no-death-worldline.md`。

# Chapter 4｜五年前

玩家停止只研究「今天」，轉而重建林知夏死亡當日。

可拼起三種不同專業留下的缺口：

```text
周志遠：沒有正式登錄的異常證物
陳柏勳：被封存的醫療異常
葉庭安：研究計畫與資料公開缺口
```

三人不是同一個陰謀集團。

每個人都有自己當時看似合理的隱瞞理由。

玩家逐漸理解：

> 五年前的 18:31 不是單純事故，也不是單純謀殺。

同時開始接觸：

```text
Prediction
→ Intervention
→ Synchronization / Reality Write-back
→ Worldline Rewrite
```

---

# Chapter 5｜只有我記得

主角發現跨 Loop 真正累積的不只是案件資料。

還包括她和每個人真正相處過的經驗。

```text
一起吃過什麼
某人緊張時會怎麼說話
誰一直避開自己的需求
誰在壓力下會反覆碰相機背帶
```

但這些不是系統認證的 Character Insight 答案。

Canonical flow：

```text
真實相處 / Observation
→ Perception
→ optional Capture
→ 玩家形成對人物的理解
```

同時主角承受關係不對稱：

```text
上一輪建立深刻關係
→ Reset
→ NPC 不記得
→ 主角仍記得
```

## 章末推翻

不是：

> 大家最後都會慢慢想起來。

而是：

> 可能一直只有記憶持有者知道那些關係曾經存在。

這也是知夏當年逐漸把「理解人」變成「安排人」的危險起點。

# Chapter 6｜信與跨線資訊：目前只保留 Mystery，不鎖技術答案

舊版曾把故事寫死成：

```text
前六封跨世界線實驗
→ 第七封信完成五年跨線資訊交接
```

目前這一整套**不再是已定案技術 Canon**。

可以保留「第七封信」作為作品名稱、故事意象與未來可用的 Mystery Structure。

但章節設計必須先遵守：

- 開場實體信的核心訊息是「不要回來」
- 它在主角返鄉行程確定後才出現
- 精確投遞機制仍是 TBD
- 是否存在前六次媒介實驗仍是 TBD
- 是否能跨 Hard Reset 動態回覆仍是 TBD

因此 Chapter 6 應在後續信件機制定案後重新細化，而不是反過來用舊 Chapter 6 綁架新的 Canon。

# Chapter 7｜林知夏

玩家終於不再只看到「死去的姊姊」。

目前已確定的高層方向：

- 知夏曾保留五年前 Soft Rewrite 的資訊
- 她原本支持妹妹離開灰潮鎮
- 她後來看過主角因介入／停留而死亡的 Worldline
- 她開始強硬阻止妹妹返鄉
- 她從「讓別人自己選」逐漸滑向「我看過結果，所以我替你選」
- 她後期認知到反覆最佳化世界線本身可能就是問題

但以下仍不能在本章自行硬補：

- 知夏成為 Anchor / Reference 的精確機制
- 她如何主動觸發每一次 Rewrite
- 她死亡與五年前 Loop 停止的完整技術因果
- 主角與知夏之間是否存在同一個 Reference Session

這些必須先完成 Story Canon 設計。

---

# Final｜18:31

最終真相的高層方向已確定：

> 研究系統原本不是時間旅行裝置，而是一套為災害與城市韌性服務的 Digital Twin / Decision Support System。

它從：

```text
Prediction
→ Simulation
→ Intervention
```

走到事故後的：

```text
Reality Write-back / Synchronization
→ Reality 被當成可以反覆修正的結果
```

因此最終問題不是：

> 誰才是正確的死者？

也不是：

> 哪一條 Worldline 才是完美攻略？

而是：

> **一個知道更多結果的人／系統，是否就有資格不停替所有人修正現實？**

Ending C 的高層方向是：

> **停止 Reality Optimization / Write-back，而不是找到一條最完美的排列。**

Ending A / C 的精確 Hard Reset Stop Mechanism 仍需後續定案。

詳細見 `docs/final-1831.md`。
