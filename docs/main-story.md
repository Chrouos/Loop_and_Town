# 主線故事｜灰潮鎮：第七封信

這份文件只負責回答：主線怎麼推進、每章玩家相信什麼、又被什麼推翻。
人物細節見 `docs/character-bible.md`，人物關係見 `docs/relationship-map.md`。

---

# 主線核心

```text
第七封信
→ 回到灰潮鎮
→ 許若晴在 18:31 死亡
→ 玩家以為是謀殺
→ 改變世界線後死者改變
→ 成功做到無人死亡，午夜仍重置
→ 回頭重建五年前林知夏死亡日
→ 發現前六封「信」
→ 發現知夏曾經也是世界線記憶持有者
→ 理解 18:31 是因果收束點
→ 玩家決定什麼才叫做「拯救」
```

主線原則：每一章都要推翻上一章一個重要假設，而不是單純增加更多線索。

---

# Chapter 0｜第七封信

## 玩家相信的事

姊姊林知夏已死五年。
這封昨天才寄出的信不可能存在。

## 發生的事

主角因整理老家回到灰潮鎮。
周予安重新出現在她生活中。
老屋、鐘樓、舊車站與五年前的記憶重新連上。

信件要求主角回來，但留下矛盾警告：

> 這一次，不要來找我。

## 章末問題

到底是誰用林知夏的名字寄信？

---

# Chapter 1｜第一個今天

## 玩家相信的事

這是一樁與姊姊舊案相關的新謀殺。

## 核心事件

```text
17:40 陳柏勳秘密離院
→ 18:05 與許若晴碰面
→ 18:31 許若晴死亡
```

這條時間線刻意建立 False Causality。

玩家會自然懷疑柏勳，但真正重要的是：若晴為什麼今天一定要去車站。

## 章末推翻

午夜後日期沒有前進。
世界重置。
玩家保留記憶。

---

# Chapter 2｜活下來的人

## 玩家新的假設

只要阻止若晴到舊車站，就能阻止 18:31。

## 世界線改寫

```text
玩家提前取得若晴信任
→ 知道她 17:20 準備離開
→ 讓她改變行程
→ 若晴沒有抵達舊車站
→ 柏勳無法完成原本交付
→ 柏勳自行處理封存資料
→ 18:31 柏勳死亡
```

若晴活下來。

20:30，她仍會去咖啡店提出辭職。
玩家第一次親眼看到「活下來的人還有自己的下一件事」。

## 章末推翻

```text
阻止死者出現在現場
≠ 阻止事件
```

詳細因果見 `docs/chapter-02-living-survivor.md`。

---

# Chapter 3｜沒有死者的世界線

玩家開始把 Loop 當實驗。

經過數輪後，玩家讓所有已知高風險人物都避開 18:31 的危險節點。

18:31 無人死亡。

但是：

```text
23:59 鐘聲響起
→ 00:00 日期再次重置
```

## 章末推翻

```text
死亡 ≠ 輪迴原因
```

這是整個前半段最大的認知轉折。

---

# Chapter 4｜五年前

玩家停止只研究「今天」，轉而重建林知夏死亡當日。

三份互相矛盾的資料被拼起來：

```text
周志遠：未登錄錄音設備
陳柏勳：封存醫療紀錄
葉庭安：研究所實驗紀錄
```

三人五年前都曾隱瞞資料。
不是同一個共謀，而是三個人分別相信自己的隱瞞能避免更大的傷害。

玩家逐漸理解：五年前可能也不只發生過一次。

---

# Chapter 5｜記得的人

周予安的 Déjà vu 從模糊感覺變成真正記憶。

他開始記得前一輪才發生過的對話、位置與選擇。

核心問題從：

> 為什麼只有玩家記得？

變成：

> 如果所有人最後都會開始記得，重置還算重置嗎？

予安同時重新面對五年前 17:58 沒接到的電話。

---

# Chapter 6｜前六封信

主角發現自己收到的實體信只是第七個跨世界線訊息載體。

```text
1. 未寄出的紙條
2. 圖書館借閱卡背面的字
3. 錄音帶中的一句話
4. 醫療資料上的手寫備註
5. 被庭安燒掉的信
6. 予安記憶殘留中的一句話
7. 主角收到的實體信
```

七份訊息不是七封普通信，而是知夏測試「資訊能否跨世界線殘留」的七個結果。

---

# Chapter 7｜林知夏

玩家終於不再只看到「死去的姊姊」。

知夏曾經歷自己的 Loop。
她一開始也相信存在所有人都能活下來的完美解。

但在反覆嘗試後，她開始做取捨：

```text
救 A → B 死
救 B → C 死
讓主角離開灰潮鎮 → 其他人承擔風險
```

主角必須接受一件事：

林知夏愛她，但這份愛也曾讓知夏把危險移給別人。

---

# Final｜18:31

最終真相：18:31 是因果收束點，而不是固定死亡時間。

研究所事故讓灰潮鎮在每天 18:31 後開始排除與既定歷史差距過大的狀態。
午夜重置只是修正完成的結果。

因此最終問題不是「抓到兇手」。

而是：

```text
接受不完美的單一世界
vs
繼續輪迴追求可能不存在的完美世界
vs
放棄跨世界線記憶，讓所有人真正重新生活
```

Ending 細節暫不鎖死。
但所有結局都必須回到同一主題：玩家如何定義「拯救」。
