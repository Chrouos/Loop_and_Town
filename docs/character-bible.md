# Character Bible｜灰潮鎮主要人物

這份文件定義角色作為「人」的基準：過去、現在生活、私人目標、恐懼、秘密、與主線的關係。

> Player-facing 人物理解必須遵守 `Attention → Perception → optional Memory Capture → player hypothesis`。
> Author 可以知道角色穩定習慣，但系統不能因此替玩家判定說謊、矛盾或正確推理。

---

# 主角｜林知夏的妹妹

- 公開目的：回灰潮鎮整理老家並賣房
- 真正內在問題：如果五年前沒有離開，姊姊會不會沒死
- 缺點：容易把「查清真相」變成替自己減輕罪惡感
- 成長：從只想救姊姊，變成願意把其他人的人生視為同等重要

在目前 10 月 3 日 Hard Reset 中，她是唯一會自然保留跨 Loop 主觀記憶的人。

這代表她保留的不只是案件資料，也包括上一輪才建立的友誼、共同經歷與對角色的理解。

可被系統保證檢索、放到 Investigation Wall、作為 Memory Input 的 persistent gameplay record，仍以玩家主動 Captured Memory 為準。

```text
愧疚
→ 調查
→ 認識每一個人
→ 開始能預測每一個人
→ 控制世界線
→ 發現理解不等於有權替別人決定
→ 接受沒有完美答案
```

# 林知夏｜死亡時 26

## 表面身份

地方史研究者／圖書館約聘人員。

## 真正人生

- 對妹妹保護慾很強
- 習慣自己扛問題，不相信別人能承受全部真相
- 接觸研究所舊資料後逐漸成為五年前 Soft Rewrite 的特殊記憶持有者
- 一開始相信存在「所有人都活下來」的正解
- 後期開始接受世界線只能做取捨

她真正被累積的不是人格污染，而是太多只有自己記得的死亡、友誼與選擇。

這是 Story-specific exception，不代表一般 NPC 擁有 cross-loop memory residue。

## 關係

- 主角：深愛，但曾用疏遠逼她離開灰潮鎮
- 若晴：像妹妹，支持她攝影與離開小鎮
- 予安：從小認識，常請他修設備
- 庭安：調查搭檔，後來因倫理問題決裂
- 柏勳：第一批相信她的異常記憶不是單純精神問題的人

## 核心矛盾

她既是受害者，也是曾經主動移動風險的人。

# 周予安｜27｜鐘錶店店主

## 日常

父親過世後接下老街鐘錶店。
店裡生意持續衰退，他其實已經找房仲談過出售。

## 私人目標

20:00 原本要和房仲談店面的未來。

## 習慣

- 先幫忙，再問原因
- 面對沉重話題會用實際工作逃避
- 緊張時講話變得過度正式
- 嘴上說想清掉父親留下的雜物，實際上幾乎什麼都捨不得丟
- 喝咖啡不加糖

這些是 Author 端的穩定人物設定。

玩家只有在實際相處、Perceive / Capture 到相關 Moment 後，才有材料形成自己的 Character Insight / hypothesis。

## 五年前

17:58 知夏打給他。
他因為正在和父親爭吵沒有接。
18:31 知夏死亡。

那筆未接來電留了五年。

## 與主角

不是單純戀愛功能。
他是少數知道主角「離開灰潮鎮之後變成什麼人」的人。

更重要的是，他也是最容易讓玩家感受到跨 Loop 關係不對稱的人：

```text
上一輪兩人已經很熟
→ Reset
→ 予安完全不記得上一輪
→ 主角卻知道他的習慣、秘密與私人目標
```

予安不會逐漸想起其他 Loop。

他察覺異常的原因，是主角知道得太多。

## Arc

```text
可靠助手
→ 主角越來越了解他
→ 他開始懷疑主角為什麼知道私事
→ 重新面對五年前未接電話
→ 在不知道其他 Loop 的前提下，仍做出屬於自己的選擇
→ 主角學會不把「我知道你會怎麼選」當成替他決定的理由
```

# 許若晴｜23｜咖啡店員

## 家庭

- 父親早年離家
- 母親長期健康不佳
- 高中後留在灰潮鎮照顧母親

## 真正想做的事

攝影。

她一直在準備外地學校作品集，也收到重新申請的通知。
今天原本就打算辭職。

## 與知夏

高中時若晴常去圖書館躲家庭衝突。
知夏是第一個認真看她作品的人，也是第一個告訴她「妳可以離開這裡」的人。

因此若晴最深的羞愧不是五年前沒救知夏，而是五年後自己仍沒有離開。

## 與予安

年少時有過好感。
現在更像把予安視為「這個小鎮永遠不會消失的安全位置」。
予安則一直把她當妹妹。

## 穩定習慣

若晴真正想把話藏起來時，常會反覆整理相機背帶。

這是 Author 端的人物一致性設定。

玩家若跨 Loop 實際觀察過類似行為，可以自己形成「她緊張時可能會整理背帶」的理解；系統不能直接把當下動作翻譯成「她正在說謊」。

## 今天

```text
08:00 上班
11:30 整理攝影作品集
14:00 收到外地學校通知
16:10 遇見主角
17:20 決定是否去舊車站
18:31 世界線事件
20:30 若存活，提出辭職
```

她不是「第一死者」。
她只是第一輪恰好走進 18:31 節點的人。

# 陳柏勳｜41｜醫師

## 現況

灰潮鎮醫院逐年縮編。
他已收到外地醫院邀請，卻五年來都沒有真正離開。

## 性格

- 克制
- 程序導向
- 不願把推測說成事實
- 習慣用「保護病患」合理化資訊封鎖

Author 端可以把這些特徵當成角色一致性約束。

玩家若多次實際 Perceive / Capture 到柏勳只在有硬證據時下定論，可以把它當成自己的判讀素材，但不能由系統直接推成「他現在說的必然是真的」。

## 五年前

知夏曾向他描述自己記得尚未發生的事。
他一開始只當成壓力與睡眠問題。
直到其中一件預言真的發生。

## 今天

17:40 秘密離院。
真正目的不是殺人，而是把知夏當年留下的封存醫療資料交給若晴。

## 與庭安

研究所事故後，曾協助庭安隱瞞部分醫療資料。
兩人都認為自己是在避免更大傷害。

## Arc

```text
最可疑的人
→ 保護資料的人
→ 發現保護也是一種剝奪選擇
→ 最終願意把真相交給活著的人決定
```

# 葉庭安｜30｜調查記者／前研究助理

## 現況

離開灰潮鎮後成為記者。
這次回鎮表面是採訪，實際上已追查研究所舊案半年。

## 與知夏

五年前是知夏最接近真相的搭檔。
最後卻因倫理觀決裂。

知夏：必須繼續試不同世界線。
庭安：如果每次只是把死亡移給別人，這還叫救人嗎。

## 為什麼說不認識知夏

知夏曾要求她：如果妹妹回來，不要讓她知道自己做過什麼。

庭安不是單純說謊，她是在履行一個死人留下的承諾。

## 今天

19:50 原本打算獨自進研究所取回舊實驗紀錄。
玩家是否在 16:40 拆穿她，會改變這個時間與方式。

## Arc

```text
控制資訊
→ 被迫重新面對知夏
→ 承認自己也是五年前事件的一部分
→ 從替死人保密轉向讓活人選擇
```

# 周志遠｜36｜刑警

## 五年前

知夏死亡當晚第一批到場者之一。

他找到一台停在 18:31 的錄音設備。
錄音裡卻出現了「尚未抵達現場的自己」的聲音。

他沒有把設備登錄進證物清單。

## 為什麼隱瞞

不是包庇兇手。
而是他無法解釋這份證物，也害怕交出去後自己反而成為調查對象。

## 與柏勳

彼此不信任。

```text
志遠：柏勳隱瞞醫療紀錄
柏勳：志遠隱藏關鍵證物
```

兩人其實犯了同一種錯：替別人決定哪些真相可以被知道。

# Character Insight 規則

Character Insight 不是獨立的 Player-facing 解鎖系統。

它比較接近：

> 主角透過多次真實相處與觀察累積的人物理解，再由玩家自己形成 hypothesis。

Canonical flow：

```text
角色行為 / Dialogue
→ Player Attention
→ Perception
→ optional Memory Capture
→ Memory Library / Investigation Wall
→ 玩家自己的 Note / hypothesis
→ 可能採取不同問法或行動
```

可以：

- 成為玩家判斷下一步的素材
- 讓玩家自己懷疑某個假設是否符合角色習慣
- 在劇本明確設計的 Narrative Node 中作為 Memory Input
- 形成很弱的 Memory Resonance

不可以：

- 系統自動排除假設
- 系統自動解鎖「正確問法」
- 當成客觀證據
- 直接顯示「說謊率」
- 自動標記矛盾、嫌疑或正確因果
- 取代角色本人當下的選擇

Author 可以使用 Character Insight metadata 維持角色一致性，但不能把 Author Truth 直接投影成 Player Knowledge。

核心倫理：

> 我很了解你，不代表我有權替你做決定。

# 角色設計檢查表

任何主要角色新增事件前，都要先回答：

1. 他今天本來要做什麼
2. 他現在最想得到什麼
3. 他最怕失去什麼
4. 這件事和主線無關時，他仍然會不會做
5. 玩家介入後，改變的是他的行動，還是只是替劇情按下一個 Trigger
6. Player 是否真的 Perceive 過形成判斷所需的素材

如果第 4 題答案是否，代表這個角色仍然只是劇情工具。
