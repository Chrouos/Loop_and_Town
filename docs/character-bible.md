# Character Bible｜灰潮鎮主要人物

這份文件定義角色作為「人」的基準：過去、現在生活、私人目標、恐懼、秘密、與主線的關係。

> Player-facing 人物理解必須遵守 `Attention → Perception → optional Memory Capture → player hypothesis`。
> Author 可以知道角色穩定習慣，但系統不能因此替玩家判定說謊、矛盾或正確推理。

# 主角｜林知夏的妹妹

## 成長背景

主角從小就很聰明，成績也一直不錯。

她很早就知道自己不想一輩子留在灰潮鎮。

不是討厭家人，也不是單純想逃離，而是她一直覺得：

> 灰潮鎮太小了。
> 我想看看外面的世界到底有多大。

她喜歡都市提供的選擇、陌生感與可能性。

高中時她便把「去都市念大學」當成明確目標，最後也真的考上外地大學，在大學階段正式離開灰潮鎮。

## 與知夏

知夏一直支持妹妹離開。

她會幫主角找學校資料、準備升學，也從來沒有要求主角為了家人留在灰潮鎮。

因此，主角後來最難理解的事情是：

> 為什麼一直支持我離開的姊姊，在我真正要走之前突然變了？

主角離開前不久，知夏開始出現反常的控制行為：

- 不希望主角提前回家
- 干涉某些搭車時間與返鄉安排
- 要求她到了都市後暫時不要回灰潮鎮
- 說出與過去支持態度完全相反的話

兩人因此爆發人生中最嚴重的一次爭吵。

主角帶著怒氣離開灰潮鎮去念大學。

兩人沒有真正把那次爭吵說開，之後知夏死亡。

所以主角真正留下的遺憾不是：

> 我不應該離開。

而是：

> 為什麼我們最後一次好好說話，是那麼久以前？

## 真相

知夏並不是突然反對妹妹去都市。

她是在五年前的 Soft Rewrite 中看過一條主角留在灰潮鎮、最後於 18:31 死亡的世界線。

因此她把原本的：

> 我希望妳能出去看看世界。

逐漸扭曲成：

> 妳一定要離開，而且不能回來。

這是知夏後期最重要的性格轉變之一：

```text
支持別人的選擇
→ 知道太多結果
→ 相信自己知道什麼才對別人最好
→ 開始替別人做選擇
```

## 現在

- 公開目的：回灰潮鎮整理老家並賣房
- 真正內在問題：不是「當初該不該離開」，而是沒能和知夏把最後那場爭吵說開
- 缺點：容易把「知道結果」誤認為「有資格替別人決定」
- 成長：從只想修正自己與知夏的遺憾，逐漸願意把其他人的人生與選擇權視為同等重要

在目前 10 月 3 日 Hard Reset 中，她是唯一會自然保留跨 Loop 主觀記憶的人。

這代表她保留的不只是案件資料，也包括上一輪才建立的友誼、共同經歷與對角色的理解。

可被系統保證檢索、放到 Investigation Wall、作為 Memory Input 的 persistent gameplay record，仍以玩家主動 Captured Memory 為準。

```text
遺憾
→ 調查
→ 認識每一個人
→ 開始能預測每一個人
→ 控制世界線
→ 發現理解不等於有權替別人決定
→ 接受沒有完美答案
```

# 林知夏｜死亡時 26

## 表面身份

地方史研究者／圖書館約聘人員。

## 真正人生

- 對妹妹保護慾很強
- 原本真心支持妹妹離開灰潮鎮、去都市生活
- 習慣自己扛問題，不相信別人能承受全部真相
- 接觸研究所舊資料後逐漸成為五年前 Soft Rewrite 的特殊記憶持有者
- 一開始相信存在「所有人都活下來」的正解
- 後期開始接受世界線只能做取捨

她真正被累積的不是人格污染，而是太多只有自己記得的死亡、友誼與選擇。

這是 Story-specific exception，不代表一般 NPC 擁有 cross-loop memory residue。

## 與主角

知夏不是因為傳統家庭觀念而阻止妹妹離開。

相反，她一直是最支持妹妹去都市的人。

真正的轉折發生在她看過「主角留在灰潮鎮並於 18:31 死亡」的世界線之後。

她開始利用自己對妹妹的了解，刻意說出最能把妹妹推遠的話。

因此主角記憶中的「最後一次大吵」，其實同時具有兩個版本：

```text
主角理解：
姊姊突然變了，我們最後沒有和好

知夏理解：
只要她恨我、離開這裡，她至少還活著
```

這不代表知夏的做法是正確的。

它反而是她從「保護」跨到「替別人決定」的第一個重要警訊。

## 關係

- 主角：深愛；原本支持她離開，後來因死亡世界線而故意把她推遠
- 若晴：像妹妹，支持她攝影與離開小鎮
- 予安：從小認識，也是少數知道予安其實曾想離開灰潮鎮的人
- 庭安：調查搭檔，後來因倫理問題決裂
- 柏勳：第一批相信她的異常記憶不是單純精神問題的人

## 核心矛盾

她既是受害者，也是曾經主動移動風險的人。

她最初相信自己是在替別人增加選擇，最後卻逐漸變成替別人選擇。

# 周予安｜27｜鐘錶店店主

一句話定位：

> 一個一直以為自己只是暫時留下，最後才發現很多年已經過去的人。

## 家庭

予安家經營灰潮鎮老街的鐘錶店。

父親是手藝很好的老派鐘錶師，個性強硬、不擅長道歉，也一直把「兒子將來接店」視為理所當然。

父子不是感情不好。

而是很愛對方，卻幾乎不會直接談自己的需要。

父親常嫌予安修得慢、做得不夠好，但其他客人稱讚予安時，又會理所當然地說：

> 我教的。

## 原本也想離開

予安高中畢業時曾考上外地的機械相關科系，也曾認真準備離開灰潮鎮。

但家裡開始發生變化：

```text
母親長期生病
→ 家中照顧與店務壓力增加
→ 予安決定先延後離開
→ 母親過世
→ 父親健康狀況變差
→ 再等等
→ 再一年
→ 最後一直沒有離開
```

所以他並不是從小立志繼承鐘錶店。

他只是一次又一次做出當下最合理的選擇，最後才發現那些選擇已經變成自己的人生。

## 現在

父親已經過世，鐘錶店完全由予安接手。

店裡生意持續衰退，他其實已經找房仲談過出售。

20:00 原本要和房仲談店面的未來。

但他始終沒有真正決定要不要賣。

他最大的問題不是「捨不得店」，而是：

> 如果現在離開，是不是代表以前那些留下都沒有意義？

## 習慣

- 先幫忙，再問原因
- 面對沉重話題會用實際工作逃避
- 緊張時講話變得過度正式
- 嘴上說想清掉父親留下的雜物，實際上幾乎什麼都捨不得丟
- 喝咖啡不加糖
- 很少直接回答「你自己想要什麼」

這些是 Author 端的穩定人物設定。

玩家只有在實際相處、Perceive / Capture 到相關 Moment 後，才有材料形成自己的 Character Insight / hypothesis。

## 與知夏

予安與知夏本身就是朋友，不只是「妹妹的朋友」。

小時候常形成：

```text
知夏 ↔ 予安
   \     /
    主角
```

知夏也是少數知道予安其實曾想離開灰潮鎮的人。

她曾經提醒他：

> 你不是只有留下這個選項。

這句話在知夏後來逐漸替別人決定人生之後，會形成反差。

## 五年前的 17:58

知夏死亡當天，予安正在和父親爭吵。

爭吵的核心不是鐘錶，而是父親再一次理所當然地談到「這間店以後就是你的」。

予安第一次真正把壓抑很久的話說出來：

> 我從來沒說我要這間店。

就在這段時間，知夏於 17:58 打電話給他。

他看到來電，但當下情緒很差，只想著晚一點再回。

18:31，知夏死亡。

從此沒有「晚一點」。

因此這筆未接來電和他人生另一件事綁在一起：

```text
第一次想替自己的人生說話
→ 同時錯過朋友最後一通電話
→ 開始把「替自己選擇」和「自私」混在一起
```

這也解釋他後來為什麼更加習慣先處理別人的需要。

## 與主角

兩人從小認識。

知夏年紀較大時，主角更像跟在兩人旁邊的小孩；長大之後，主角和予安才逐漸形成真正屬於兩人的朋友關係。

兩人曾經互相喜歡過，但從未正式交往。

那不是強烈的青春戀愛，而比較像：

> 如果再多一點時間，也許會發生什麼。

主角準備去都市念大學前，予安知道她終於要完成一直以來的目標。

他支持她，卻也羨慕她真的做到了。

予安曾說：

> 妳出去之後大概就不想回來了。

主角當時把這句話理解成酸她，回了一句：

> 那不是很好嗎？

之後主角和知夏大吵。

予安原本答應送她去車站，主角卻只傳了一句：

> 不用了。

予安最後仍然去了。

但只看到火車離站。

主角一直不知道這件事。

所以五年後主角再次搭火車回灰潮鎮時，予安真的站在出口接她，對他而言也有另一層意義：

> 五年前沒有接到的人，這一次終於接到了。

他不會把這句話說出口。

## 跨 Loop 關係不對稱

予安是最容易讓玩家感受到跨 Loop 關係成本的人：

```text
Loop A
主角與予安建立很深的信任與共同經歷
↓ Reset
Loop B
主角全部記得
予安只認識這一輪的主角
```

予安不會逐漸想起其他 Loop。

他察覺異常的原因，是主角知道得太多。

因此主角最大的倫理考驗之一是：

> 我知道上一輪的你會怎麼選，不代表這一輪的你已經做出同樣選擇。

## Arc

予安的終點不是固定的「離開灰潮鎮」。

他最後可以賣店、不賣店、改成工作室、離開一陣子再回來。

真正必須完成的是：

```text
總是先幫別人
→ 把自己的需要一直延後
→ 面對五年前未接電話與父親留下的店
→ 發現替自己選擇不等於自私
→ 第一次真正回答「我想要什麼」
```

核心：

> 留下或離開都不是答案。
> 重點是這一次由他自己決定。

# 許若晴｜23｜咖啡店員

## 家庭

- 父親早年離家
- 母親長期健康不佳
- 高中後留在灰潮鎮照顧母親

## 真正想做的事

攝影。

她一直在準備外地學校作品集，也收到重新申請的通知。
今天原本就打算辭職。

## 與知夏

高中時若晴常去圖書館躲家庭衝突。
知夏是第一個認真看她作品的人，也是第一個告訴她「妳可以離開這裡」的人。

因此若晴最深的羞愧不是五年前沒救知夏，而是五年後自己仍沒有離開。

## 與予安

年少時有過好感。
現在更像把予安視為「這個小鎮永遠不會消失的安全位置」。
予安則一直把她當妹妹。

## 穩定習慣

若晴真正想把話藏起來時，常會反覆整理相機背帶。

這是 Author 端的人物一致性設定。

玩家若跨 Loop 實際觀察過類似行為，可以自己形成「她緊張時可能會整理背帶」的理解；系統不能直接把當下動作翻譯成「她正在說謊」。

## 今天

```text
08:00 上班
11:30 整理攝影作品集
14:00 收到外地學校通知
16:10 遇見主角
17:20 決定是否去舊車站
18:31 世界線事件
20:30 若存活，提出辭職
```

她不是「第一死者」。
她只是第一輪恰好走進 18:31 節點的人。

# 陳柏勳｜41｜醫師

## 現況

灰潮鎮醫院逐年縮編。
他已收到外地醫院邀請，卻五年來都沒有真正離開。

## 性格

- 克制
- 程序導向
- 不願把推測說成事實
- 習慣用「保護病患」合理化資訊封鎖

Author 端可以把這些特徵當成角色一致性約束。

玩家若多次實際 Perceive / Capture 到柏勳只在有硬證據時下定論，可以把它當成自己的判讀素材，但不能由系統直接推成「他現在說的必然是真的」。

## 五年前

知夏曾向他描述自己記得尚未發生的事。
他一開始只當成壓力與睡眠問題。
直到其中一件預言真的發生。

## 今天

17:40 秘密離院。
真正目的不是殺人，而是把知夏當年留下的封存醫療資料交給若晴。

## 與庭安

研究所事故後，曾協助庭安隱瞞部分醫療資料。
兩人都認為自己是在避免更大傷害。

## Arc

```text
最可疑的人
→ 保護資料的人
→ 發現保護也是一種剝奪選擇
→ 最終願意把真相交給活著的人決定
```

# Character Insight 規則

Character Insight 不是獨立的 Player-facing 解鎖系統。

它比較接近：

> 主角透過多次真實相處與觀察累積的人物理解，再由玩家自己形成 hypothesis。

Canonical flow：

```text
角色行為 / Dialogue
→ Player Attention
→ Perception
→ optional Memory Capture
→ Memory Library / Investigation Wall
→ 玩家自己的 Note / hypothesis
→ 可能採取不同問法或行動
```

可以：

- 成為玩家判斷下一步的素材
- 讓玩家自己懷疑某個假設是否符合角色習慣
- 在劇本明確設計的 Narrative Node 中作為 Memory Input
- 形成很弱的 Memory Resonance

不可以：

- 系統自動排除假設
- 系統自動解鎖「正確問法」
- 當成客觀證據
- 直接顯示「說謊率」
- 自動標記矛盾、嫌疑或正確因果
- 取代角色本人當下的選擇

Author 可以使用 Character Insight metadata 維持角色一致性，但不能把 Author Truth 直接投影成 Player Knowledge。

核心倫理：

> 我很了解你，不代表我有權替你做決定。

# 角色設計檢查表

任何主要角色新增事件前，都要先回答：

1. 他今天本來要做什麼
2. 他現在最想得到什麼
3. 他最怕失去什麼
4. 這件事和主線無關時，他仍然會不會做
5. 玩家介入後，改變的是他的行動，還是只是替劇情按下一個 Trigger
6. Player 是否真的 Perceive 過形成判斷所需的素材

如果第 4 題答案是否，代表這個角色仍然只是劇情工具。
