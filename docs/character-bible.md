# Character Bible｜灰潮鎮主要人物

這份文件定義角色作為「人」的基準：過去、現在生活、私人目標、恐懼、秘密、與主線的關係。

> Player-facing 人物理解必須遵守 `Attention → Perception → optional Memory Capture → player hypothesis`。
> Author 可以知道角色穩定習慣，但系統不能因此替玩家判定說謊、矛盾或正確推理。

# 主角｜林知夏的妹妹

## 成長背景

主角從小就很聰明，成績也一直不錯。

她很早就知道自己不想一輩子留在灰潮鎮。

不是討厭家人，也不是單純想逃離，而是她一直覺得：

> 灰潮鎮太小了。
> 我想看看外面的世界到底有多大。

她喜歡都市提供的選擇、陌生感與可能性。

高中時她便把「去都市念大學」當成明確目標，最後也真的考上外地大學，在大學階段正式離開灰潮鎮。

## 與知夏

知夏一直支持妹妹離開。

她會幫主角找學校資料、準備升學，也從來沒有要求主角為了家人留在灰潮鎮。

因此，主角後來最難理解的事情是：

> 為什麼一直支持我離開的姊姊，在我真正要走之前突然變了？

主角離開前不久，知夏開始出現反常的控制行為：

- 不希望主角提前回家
- 干涉某些搭車時間與返鄉安排
- 要求她到了都市後暫時不要回灰潮鎮
- 說出與過去支持態度完全相反的話

兩人因此爆發人生中最嚴重的一次爭吵。

主角帶著怒氣離開灰潮鎮去念大學。

兩人沒有真正把那次爭吵說開，之後知夏死亡。

所以主角真正留下的遺憾不是：

> 我不應該離開。

而是：

> 為什麼我們最後一次好好說話，是那麼久以前？

## 真相

知夏並不是突然反對妹妹去都市。

她是在五年前的 Soft Rewrite 中看過一條主角留在灰潮鎮、最後於 18:31 死亡的世界線。

因此她把原本的：

> 我希望妳能出去看看世界。

逐漸扭曲成：

> 妳一定要離開，而且不能回來。

這是知夏後期最重要的性格轉變之一：

```text
支持別人的選擇
→ 知道太多結果
→ 相信自己知道什麼才對別人最好
→ 開始替別人做選擇
```

## 現在

- 公開目的：回灰潮鎮整理老家並賣房
- 真正內在問題：不是「當初該不該離開」，而是沒能和知夏把最後那場爭吵說開
- 缺點：容易把「知道結果」誤認為「有資格替別人決定」
- 成長：從只想修正自己與知夏的遺憾，逐漸願意把其他人的人生與選擇權視為同等重要

在目前 10 月 3 日 Hard Reset 中，她是唯一會自然保留跨 Loop 主觀記憶的人。

這代表她保留的不只是案件資料，也包括上一輪才建立的友誼、共同經歷與對角色的理解。

可被系統保證檢索、放到 Investigation Wall、作為 Memory Input 的 persistent gameplay record，仍以玩家主動 Captured Memory 為準。

```text
遺憾
→ 調查
→ 認識每一個人
→ 開始能預測每一個人
→ 控制世界線
→ 發現理解不等於有權替別人決定
→ 接受沒有完美答案
```

# 林知夏｜死亡時 26

## 表面身份

地方史研究者／圖書館約聘人員。

## 真正人生

- 對妹妹保護慾很強
- 原本真心支持妹妹離開灰潮鎮、去都市生活
- 習慣自己扛問題，不相信別人能承受全部真相
- 接觸研究所舊資料後逐漸成為五年前 Soft Rewrite 的特殊記憶持有者
- 一開始相信存在「所有人都活下來」的正解
- 後期開始接受世界線只能做取捨

她真正被累積的不是人格污染，而是太多只有自己記得的死亡、友誼與選擇。

這是 Story-specific exception，不代表一般 NPC 擁有 cross-loop memory residue。

## 與主角

知夏不是因為傳統家庭觀念而阻止妹妹離開。

相反，她一直是最支持妹妹去都市的人。

真正的轉折發生在她看過「主角留在灰潮鎮並於 18:31 死亡」的世界線之後。

她開始利用自己對妹妹的了解，刻意說出最能把妹妹推遠的話。

因此主角記憶中的「最後一次大吵」，其實同時具有兩個版本：

```text
主角理解：
姊姊突然變了，我們最後沒有和好

知夏理解：
只要她恨我、離開這裡，她至少還活著
```

這不代表知夏的做法是正確的。

它反而是她從「保護」跨到「替別人決定」的第一個重要警訊。

## 關係

- 主角：深愛；原本支持她離開，後來因死亡世界線而故意把她推遠
- 若晴：像妹妹；支持她認真看待攝影，也提醒她不要先替自己決定「只能留下」
- 予安：從小認識，也是少數知道予安其實曾想離開灰潮鎮的人
- 庭安：調查搭檔，後來因倫理問題決裂
- 柏勳：第一批相信她的異常記憶不是單純精神問題的人

## 核心矛盾

她既是受害者，也是曾經主動移動風險的人。

她最初相信自己是在替別人增加選擇，最後卻逐漸變成替別人選擇。

# 周予安｜27｜鐘錶店店主

一句話定位：

> 一個一直以為自己只是暫時留下，最後才發現很多年已經過去的人。

## 家庭

予安家經營灰潮鎮老街的鐘錶店。

父親是手藝很好的老派鐘錶師，個性強硬、不擅長道歉，也一直把「兒子將來接店」視為理所當然。

父子不是感情不好。

而是很愛對方，卻幾乎不會直接談自己的需要。

父親常嫌予安修得慢、做得不夠好，但其他客人稱讚予安時，又會理所當然地說：

> 我教的。

## 原本也想離開

予安高中畢業時曾考上外地的機械相關科系，也曾認真準備離開灰潮鎮。

但家裡開始發生變化：

```text
母親長期生病
→ 家中照顧與店務壓力增加
→ 予安決定先延後離開
→ 母親過世
→ 父親健康狀況變差
→ 再等等
→ 再一年
→ 最後一直沒有離開
```

所以他並不是從小立志繼承鐘錶店。

他只是一次又一次做出當下最合理的選擇，最後才發現那些選擇已經變成自己的人生。

## 現在

父親已經過世，鐘錶店完全由予安接手。

店裡生意持續衰退，他其實已經找房仲談過出售。

20:00 原本要和房仲談店面的未來。

但他始終沒有真正決定要不要賣。

他最大的問題不是「捨不得店」，而是：

> 如果現在離開，是不是代表以前那些留下都沒有意義？

## 習慣

- 先幫忙，再問原因
- 面對沉重話題會用實際工作逃避
- 緊張時講話變得過度正式
- 嘴上說想清掉父親留下的雜物，實際上幾乎什麼都捨不得丟
- 喝咖啡不加糖
- 很少直接回答「你自己想要什麼」

這些是 Author 端的穩定人物設定。

玩家只有在實際相處、Perceive / Capture 到相關 Moment 後，才有材料形成自己的 Character Insight / hypothesis。

## 與知夏

予安與知夏本身就是朋友，不只是「妹妹的朋友」。

小時候常形成：

```text
知夏 ↔ 予安
   \     /
    主角
```

知夏也是少數知道予安其實曾想離開灰潮鎮的人。

她曾經提醒他：

> 你不是只有留下這個選項。

這句話在知夏後來逐漸替別人決定人生之後，會形成反差。

## 五年前的 17:58

知夏死亡當天，予安正在和父親爭吵。

爭吵的核心不是鐘錶，而是父親再一次理所當然地談到「這間店以後就是你的」。

予安第一次真正把壓抑很久的話說出來：

> 我從來沒說我要這間店。

就在這段時間，知夏於 17:58 打電話給他。

他看到來電，但當下情緒很差，只想著晚一點再回。

18:31，知夏死亡。

從此沒有「晚一點」。

因此這筆未接來電和他人生另一件事綁在一起：

```text
第一次想替自己的人生說話
→ 同時錯過朋友最後一通電話
→ 開始把「替自己選擇」和「自私」混在一起
```

這也解釋他後來為什麼更加習慣先處理別人的需要。

## 與主角

兩人從小認識。

知夏年紀較大時，主角更像跟在兩人旁邊的小孩；長大之後，主角和予安才逐漸形成真正屬於兩人的朋友關係。

兩人曾經互相喜歡過，但從未正式交往。

那不是強烈的青春戀愛，而比較像：

> 如果再多一點時間，也許會發生什麼。

主角準備去都市念大學前，予安知道她終於要完成一直以來的目標。

他支持她，卻也羨慕她真的做到了。

予安曾說：

> 妳出去之後大概就不想回來了。

主角當時把這句話理解成酸她，回了一句：

> 那不是很好嗎？

之後主角和知夏大吵。

予安原本答應送她去車站，主角卻只傳了一句：

> 不用了。

予安最後仍然去了。

但只看到火車離站。

主角一直不知道這件事。

所以五年後主角再次搭火車回灰潮鎮時，予安真的站在出口接她，對他而言也有另一層意義：

> 五年前沒有接到的人，這一次終於接到了。

他不會把這句話說出口。

## 跨 Loop 關係不對稱

予安是最容易讓玩家感受到跨 Loop 關係成本的人：

```text
Loop A
主角與予安建立很深的信任與共同經歷
↓ Reset
Loop B
主角全部記得
予安只認識這一輪的主角
```

予安不會逐漸想起其他 Loop。

他察覺異常的原因，是主角知道得太多。

因此主角最大的倫理考驗之一是：

> 我知道上一輪的你會怎麼選，不代表這一輪的你已經做出同樣選擇。

## Arc

予安的終點不是固定的「離開灰潮鎮」。

他最後可以賣店、不賣店、改成工作室、離開一陣子再回來。

真正必須完成的是：

```text
總是先幫別人
→ 把自己的需要一直延後
→ 面對五年前未接電話與父親留下的店
→ 發現替自己選擇不等於自私
→ 第一次真正回答「我想要什麼」
```

核心：

> 留下或離開都不是答案。
> 重點是這一次由他自己決定。

# 許若晴｜23｜咖啡店員／攝影

一句話定位：

> 她真正想要的不是離開灰潮鎮，而是有一天可以確定「留下或離開」都是自己做的選擇。

## 對灰潮鎮的感情

若晴其實喜歡灰潮鎮。

她喜歡清晨還沒開門的老街、固定時間經過的人、海邊的天氣，以及只有長住的人才知道的小地方。

她不像主角那樣從小就覺得小鎮太小。

她真正困惑的是：

> 如果我留下，是因為我真的喜歡這裡，還是因為我其實從來沒有選擇？

這讓若晴和主角、予安形成三種不同狀態：

```text
主角：想走，而且真的走了
予安：曾想走，但一次次延後
若晴：喜歡這裡，卻不知道留下是不是自己的選擇
```

## 家庭

若晴的母親有長期慢性疾病，但不是完全失能。

平常可以自己吃飯、出門與處理基本生活，只是固定需要回診、藥物管理，偶爾急性發作時需要陪伴。

因此若晴不是被母親「綁住」。

母親甚至常叫她：

> 妳有自己的事情就去做。

問題反而因此更難。

母親越不要求她留下，若晴越容易覺得：

> 如果我真的走了，是不是很自私？

父親很多年前離開灰潮鎮，後來在都市重新組成家庭。

他沒有完全消失，仍會匯生活費、打電話，也曾表示若晴若想去都市可以提供協助。

若晴最難接受的是父親偶爾說：

> 妳不用一直顧妳媽。

因為對若晴而言：

> 最沒有資格把這件事說得那麼簡單的人，就是你。

這條家庭線不是「壞父親 vs 可憐母親」，而是家庭照護在現實中自然落到「最方便留下的那個人」身上的問題。

## 攝影

若晴不是單純喜歡拍漂亮照片。

她特別喜歡拍「正在改變、快要消失，或已經失去原本功能的東西」：

- 準備關門的老店
- 拆除前的舊招牌
- 改建中的車站
- 空掉的教室
- 新建築後面的老平房
- 被封起來的舊路
- 固定坐在同一位置、卻逐年變老的人

她的作品集暫定主題為：

> 《退潮以後》

她想拍的不是「一個正在死亡的小鎮」，而是：

> 東西消失以後，人還留下了什麼？

這也讓她面臨另一個倫理問題。

外地評審或媒體可能很喜歡她照片裡的：

> 沒落小鎮的詩意。

但對若晴來說，那些不是抽象美學。

某張「漂亮的關店照片」，可能就是她認識多年的店主真的失去生意。

因此她也會開始問：

> 我是在記錄這些人的生活，還是把別人的生活變成自己的作品？

這和主角後來把人物逐漸視為 Schedule / Condition / Event Variant 的危險形成鏡像。

## 與知夏

高中時若晴常去圖書館。

不是因為特別愛看書，而是那裡是一個沒有人會追問她家庭狀況的地方。

知夏很早就發現她會拍照。

知夏第一次真正影響她，不是只說「拍得很好」，而是問：

> 妳為什麼都拍快要沒有的東西？

那是第一次有人不是只看照片好不好看，而是真的在看若晴想拍什麼。

知夏支持她認真學攝影，但不把「離開灰潮鎮」當成唯一正確答案。

她真正對若晴說的是：

> 不要先替自己決定「我只能留在這裡」。

五年前，若晴曾拿到一次外地攝影課程的錄取。

她最後沒有去，也沒有告訴知夏。

因為她知道知夏一定會問：

> 那妳自己想不想去？

而若晴當時不想回答。

知夏死後，這成為她真正的遺憾：

> 我一直沒有真正回答她問我的問題。

## 與周予安

若晴高中時偶爾會待在鐘錶店。

不是因為鐘錶，也不一定是為了找予安。

鐘錶店對她來說只是：

> 一個可以待著，而且不需要解釋自己為什麼待在這裡的地方。

予安不太會追問她是不是又和家人發生什麼事。

通常只是告訴她：

> 後面有椅子。

或：

> 冰箱有茶。

若晴年少時確實對予安有過好感。

現在則更接近一種長期的安全感。

她把予安和鐘錶店都視為「灰潮鎮裡不會突然消失的東西」。

因此當她後來知道予安其實正在考慮賣店，會真正受到衝擊。

這也是她第一次意識到：

> 自己是不是也把別人當成了不會改變的背景？

## 與主角

主角離開灰潮鎮時，若晴還很年輕，兩人以前並不熟。

若晴認識的是：

> 知夏姊那個很會讀書、後來真的去了都市的妹妹。

主角認識的是：

> 姊姊以前照顧過、會拍照的女孩。

兩人的真正關係是在遊戲現在進行式裡建立。

若晴某種程度上羨慕過主角「真的走了」，但她也會提醒主角不要把自己的答案套在她身上。

她可以在某條關係較深的路線明確說：

> 妳一直問我為什麼不走。
> 可是妳有沒有想過，我可能真的喜歡這裡？

這句話是主角理解「離開並不是所有人的正解」的重要 Moment。

## 性格缺點

若晴不是單純膽小，也不是沒有行動力。

她真正的缺點是：

> 很擅長讓「責任」替自己回答。

```text
媽媽最近需要我
所以留下

咖啡店缺人
所以先不辭

作品還沒整理好
所以先不投稿

鎮上需要有人記錄
所以現在不能走
```

每一個理由都可能是真的。

但全部加起來，也可能讓她永遠不用回答：

> 我自己到底想怎樣？

## 第一輪與案件

若晴不是因為主角回來才突然擁有一條案件支線。

她本來就在調查、確認知夏留下的一部分資料。

她去舊車站拿的資料，可以成為證明五年前研究事故並非單純意外的一部分。

因此第一輪她不是「被安排去死的第一死者」，而是一個原本就在做自己選擇的人，只是恰好走進了 18:31 的危險節點。

## 穩定習慣

若晴真正想把話藏起來或需要替自己找理由時，常會反覆整理相機背帶。

這是 Author 端的人物一致性設定。

玩家若跨 Loop 實際觀察過類似行為，可以自己形成「她緊張時可能會整理背帶」的理解；系統不能直接把當下動作翻譯成「她正在說謊」。

```text
14:00 收到外地攝影相關通知
16:10 遇見主角

```

## Arc

若晴的終點不是固定的「離開灰潮鎮」。

真正的角色進展是：

```text
有很多合理的留下理由
→ 主角嘗試利用 Loop 幫她排除障礙
→ 若晴仍然無法因此自動得到答案
→ 主角發現障礙不是決定
→ 若晴承認自己既怕離開，也怕留下不是自己的選擇
→ 第一次不讓責任替自己回答
→ 自己做出決定
```

她最後可以去外地學習，也可以在未來回到灰潮鎮。

故事不需要替她決定最終居住地。

核心是：

> 照顧家人、喜歡故鄉、追求自己的人生，可以同時都是真的。
> 問題在於誰替她決定哪一個最重要。

# Character Insight 規則

Character Insight 不是獨立的 Player-facing 解鎖系統。

它比較接近：

> 主角透過多次真實相處與觀察累積的人物理解，再由玩家自己形成 hypothesis。

Canonical flow：

```text
角色行為 / Dialogue
→ Player Attention
→ Perception
→ optional Memory Capture
→ Memory Library / Investigation Wall
→ 玩家自己的 Note / hypothesis
→ 可能採取不同問法或行動
```

可以：

- 成為玩家判斷下一步的素材
- 讓玩家自己懷疑某個假設是否符合角色習慣
- 在劇本明確設計的 Narrative Node 中作為 Memory Input
- 形成很弱的 Memory Resonance

不可以：

- 系統自動排除假設
- 系統自動解鎖「正確問法」
- 當成客觀證據
- 直接顯示「說謊率」
- 自動標記矛盾、嫌疑或正確因果
- 取代角色本人當下的選擇

Author 可以使用 Character Insight metadata 維持角色一致性，但不能把 Author Truth 直接投影成 Player Knowledge。

核心倫理：

> 我很了解你，不代表我有權替你做決定。

# 角色設計檢查表

任何主要角色新增事件前，都要先回答：

1. 他今天本來要做什麼
2. 他現在最想得到什麼
3. 他最怕失去什麼
4. 這件事和主線無關時，他仍然會不會做
5. 玩家介入後，改變的是他的行動，還是只是替劇情按下一個 Trigger
6. Player 是否真的 Perceive 過形成判斷所需的素材

如果第 4 題答案是否，代表這個角色仍然只是劇情工具。
