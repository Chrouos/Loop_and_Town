# Chapter 7｜林知夏

> Status：Story structure active；Anchor / Reference / warning-letter transport / five-years-ago Loop stop mechanism remain TBD。
>
> 本章負責回答「林知夏變成了什麼樣的人」，不是提前把尚未定案的時空機制全部解釋完。

這一章的功能不是把知夏洗白，也不是把她變成反派。

真正要讓玩家看見的是：

> 她曾經和現在的主角一樣，相信只要再多試一次，就能找到所有人都活下來的結果。

後來真正改變她的，不是某種人格污染。

而是：

> 她看過太多結果，於是開始相信「知道更多」等於「有資格替別人決定」。

> 開場信的核心訊息是「不要回來」。

# 08:30｜庭安終於把知夏最後一批筆記交出來

葉庭安帶主角去看五年前沒有正式公開的一批知夏資料。

它可以包含：

- 工作筆記
- 被撕下又另行保存的頁面
- 地方資料與研究輸出的對照
- 不同版本的時間表
- 對 18:31 的反覆註記

庭安一直沒有公開，不是因為她想保護知夏的名聲。

而是因為內容若脫離背景，看起來像：

> 一份知夏在計算誰可以犧牲的死亡名單。

真正內容更接近：

```text
Variant 14
若晴：存活
柏勳：死亡

Variant 19
柏勳：存活
志遠：重傷

Variant 23
主角：仍在灰潮鎮
18:31 後失聯
```

這些編號到底是知夏自己的記錄方式、研究 Simulation ID，還是後來對 Rewrite 的人工整理，可以後續細化。

重要的是玩家第一次看到：

> 知夏不是只看過一次異常結果。

---

# 筆記的變化比結果本身重要

早期的知夏仍然把人當人。

例如：

```text
若晴今天本來要去上課
她不應該因為我們的系統失去這件事

予安 17:40 可能在店裡
先問他，不要直接改他的行程
```

後來逐漸變成：

```text
Ruoqing 17:40–18:10 unavailable
Yuan route B preferred
Bo-xun deviation +12m
```

也就是：

```text
認識一個人
→ 記得他的選擇
→ 預測他的選擇
→ 把他的選擇視為可調整變數
```

這是知夏最重要的墜落。

# 09:20｜主角第一次看到自己的死亡紀錄

主角翻到其中一頁。

可能只寫：

```text
主角
18:31
死亡
```

具體死因此時不一定完整。

因為「主角到底在最初哪條 Worldline 怎麼死」仍需要和 18:31 Cascade Failure 一起定案。

目前可以固定的高層事實：

> **知夏確實看過／經歷過主角因留在或介入灰潮鎮 18:31 因果而死亡的 Worldline。**

這件事是知夏對妹妹態度突然改變的直接原因。

---

# 10:40｜那場爭吵不是知夏改變了人生觀

主角一直記得：

知夏原本最支持她離開灰潮鎮。

會幫她查外地學校、準備資料，也從沒要求她為家庭留下。

但在主角真正離開前，知夏突然開始：

- 阻止她提前返鄉
- 干涉搭車時間
- 要求她去了都市就不要回來
- 故意說出最容易讓她生氣的話

兩人最後爆發嚴重爭吵。

主角一直理解成：

> 姊姊變了。

現在才知道：

```text
知夏看見妹妹死亡
↓
無法接受再發生
↓
開始相信「讓她離開」是唯一安全答案
↓
不再把完整資訊交給妹妹
↓
利用自己對妹妹的了解，把她推走
```

知夏的理由是愛。

但這仍然是：

> **替妹妹決定。**

所以庭安可以非常清楚地告訴主角：

> 「她是想救妳。」
>
> 「這不代表她有權用任何方法決定妳的人生。」

---

# 12:10｜知夏不是一開始就想控制世界線

她最早做的干預應該都很小，而且看起來非常合理。

例如：

```text
知道某個路口會出事故
→ 提醒人晚五分鐘出門

知道老人會跌倒
→ 提前去扶他

知道某次設備故障
→ 提前叫人避開
```

第一次成功時，任何人都可能覺得：

> 既然我知道，當然應該阻止。

問題發生在後面。

她逐漸發現：

```text
改 A
→ B 改變
→ C 被捲入
→ 原本的死亡消失
→ 新的傷害在其他地方發生
```

她開始以為答案只是：

> 還知道得不夠多。

所以她繼續收集更多資訊、控制更多人的 Schedule。

---

# 13:40｜庭安與知夏的倫理決裂

兩人的衝突不是「要不要救人」。

兩個人都想降低傷害。

真正差異是：

> 一個知道更多結果的人，可以替其他人決定到什麼程度？

可以保留一段舊錄音或庭安記憶中的對話：

庭安：

> 「妳現在不是只在提醒他們。」

知夏：

> 「如果我把全部告訴他們，結果只會更亂。」

庭安：

> 「所以妳就替他們決定？」

知夏：

> 「我看過結果。」

庭安：

> 「看過結果，不代表那個選擇就是妳的。」

這句話後來也會回到主角身上。

---

# 14:30｜研究系統與知夏其實逐漸在做同一件事

玩家此時應開始看見鏡像：

```text
研究系統
看見不理想結果
→ 修改變數
→ 再模擬 / 再干預
→ 繼續最佳化

知夏
看見不理想結果
→ 改變人的行程
→ 再看結果
→ 繼續最佳化

主角
經歷不理想 Worldline
→ 利用下一輪調整人物
→ 再看結果
→ 繼續最佳化
```

真正危險的不是某個角色變壞。

而是三者都逐漸接受了同一個前提：

> **只要下一次可能更好，就應該再修正一次。**

---

# 15:00｜知夏後期真正開始懷疑 Loop

知夏後期的轉折不應只是：

> 我試累了。

也不能只是：

> 死太多人，所以我心冷了。

更接近：

> **她開始懷疑「反覆最佳化」本身就是無法收斂的原因。**

她可能在筆記中留下不同時期的句子：

```text
再試一次。

如果先讓 A 離開？

為什麼每次只是換一個地方出問題？

我是不是一直在問錯問題？
```

以及後期一條非常重要、但不直接解釋技術答案的註記：

> 不要再找「最好的一天」。

這會成為 Final 的思想伏筆。

---

# 15:40｜「如果她回來」不是邀請

知夏留下的資料中可以存在：

> 如果她有一天還是回來，不要讓她變成我。

這句話必須正確理解。

它不是：

```text
知夏計畫五年後把妹妹叫回來
```

而是：

```text
知夏一直希望妹妹不要回來
但她知道自己無法永久控制妹妹的人生
所以留下「如果她仍然回來」的 contingency
```

這和開場信的：

> 不要回來。

完全一致，而不是互相矛盾。

---

# 16:20｜主角第一次真正理解開場那封信

到這裡，玩家才有足夠背景重新理解：

> **不要回來。**

第一輪它像威脅、惡作劇或不可能的死人信。

現在它更像知夏五年前一直重複的同一個選擇：

> 她仍然想把妹妹排除在自己看過的危險因果之外。

但「這封信到底怎麼在五年後寄出」仍然沒有答案。

這個 Mystery 必須保留。

本章不准用即時紙上回覆直接解掉它。

---

# 17:58｜五年前那通沒有接到的電話

本章可以重新回到予安五年前錯過的 17:58 來電。

但此處只使用**已確定的歷史事件**：

```text
17:58
知夏打給予安
↓
予安正在和父親爭吵
↓
看見來電但決定晚點再回
↓
18:31 知夏死亡
```

目前不再加入：

> 五年後電話突然接到另一條 Worldline 的主角。

這種跨線傳輸若未來要用，必須等 transmission mechanism 定案。

---

# 18:31｜這一次大家在同一輪知道更多

在後期某輪，若晴、予安、柏勳、庭安、志遠可以第一次在**同一輪**知道足夠多的真相。

這不代表他們跨 Loop 記住了。

而是主角在這一輪真正把資訊攤開。

18:31 到來。

可能仍出現：

- 電力異常
- 控制設備反應
- 不存在的鐘聲
- 基礎設施狀態錯亂

但 Chapter 7 的重點不再是：

> 「大家站著不動，就能讓世界做出選擇。」

時間永遠繼續。

真正的變化是：

> 主角第一次不再把其他人只當成自己需要安排到安全位置的 Variables。

她開始把自己知道的風險、未知與代價交給當輪真正會承受它的人。

---

# Chapter 7 結尾

Chapter 7 不直接給 Ending 答案。

它應完成三個認知：

```text
1. 知夏不是因為邪惡才開始控制別人
2. 知道更多結果，確實會讓「替別人決定」變得非常誘人
3. 知夏最後真正懷疑的是：也許不該再找一條更完美的 Worldline
```

主角最後面對的問題因此從：

> 我要怎麼把所有人移到安全的位置？

變成：

> **為什麼我們一直接受「現實必須被最佳化」這個前提？**

故事進入 Final。
