# 聽見的城｜劇情核心

> 2026-11-04 整理。寫新場景、改台詞之前先讀這份：它說明這部戲在講什麼、反轉怎麼排、每一章要讓玩家感覺到什麼。
> 細節以 `docs/story.md`（總綱與知識表）、`docs/canon/character-bible.md`（人物）、`docs/canon/story-canon-mechanism.md`（機制）為準。

## 一句話

**愛怎麼一步步變成管理。** 知道結果的人，以保護為理由，把別人「知道」和「選擇」的權利拿走。主角是盲人，最討厭被人代為決定，卻在輪迴裡變成替每個人做決定的人。

作品的立場：

- 不反科技。預測可以留著，撤掉的是「替人改寫現實」的權力。
- 不反救人。只是**告訴人不等於命令人，救了人也不等於拿到授權**。
- 對知夏有同情，但不替她開脫；對予安也一樣，拆信不會因為出於好意就沒事。
- 尊重別人的選擇，不保證得到最好的結果，但那仍然值得做。

結尾那句「下一分鐘會發生什麼，我不知道」，是整部戲的收束：前七章她一直想知道更多、算得更準，最後不知道，反而是自由。

## 社會議題

寫的時候用**行為**呈現，不要讓角色發表看法。

- **身障者被代為決定**：仲介在要簽名的地方貼黃色標籤，「妳摸到就簽」，主角問上面寫什麼，予安說他沒講。結局她要求把估價單寄成讀屏能念的檔案，每一頁讀完才簽。
- **家庭照護落在最方便留下的人身上**：若晴的媽媽「說她自己搭公車。……她每次都這樣講。」予安的爸爸「這間店，從我小學就說好是我的」。
- **小鎮外流，以及「留下是不是自己的選擇」**：若晴喜歡這裡，卻不知道留下是不是自己選的。她最後報名，週末回來，「這是我自己排的」。
- **演算法治理與防災最佳化**：研究所原本是「讓下一次災害少死一點人」。後來知夏用英文寫名字、寫 Route B preferred，人變成變數。
- **專業保密與隱匿**：陳醫生只念知夏自己的話，別的病人不念名字；周警官藏了五年的錄音機，最後用自己的名字登錄。
- **研究的知情同意**：接駁車阿伯說「我那一個鐘頭，誰准妳們拿去用的？」；柏勳最後把紀錄交給死者家屬，要不要知道由他們決定。
- **拍照的同意**：第一章「下次拍之前先叫我一聲」，結局若晴先問「我可以拍一張嗎？」才按快門。

## 心理機制與主角弧線

| 機制 | 在哪裡 |
| --- | --- |
| 反事實思考 | 第一章沒去的路線，坐在桌邊算那三十九分鐘 |
| 無力感、創傷後過度警覺 | 第一章握著若晴的手；之後每次有貨車倒車，肩膀就縮起來 |
| 倖存者罪惡感 | 第二章柏勳在正門打了兩通電話，都沒有人接 |
| 控制錯覺 | 第三章「我像在下棋」；若晴答應了，還是自己去 |
| 道德麻木 | 第四章「想到若晴，我先想起的是那個金屬扣，然後才是她的名字」；手機一直在口袋裡 |
| 預期性哀傷、模糊的失落 | 第五章「好久不見」；「那妳記得就好」 |
| 家長式父愛主義（paternalism）對上自主 | 知夏對妹妹，主角對每個人，予安拆信 |
| 照顧者倦怠、去人格化 | 知夏後期的筆記：英文名字、時間、路線 |

主角弧線：

```text
第一章　討厭被同情、被代為決定
第二章　救人的方法是「叫她不要去」，失敗；改成聽她講照片
第三章　把所有人推到安全的格子，有人答應了還是去了
第四章　為了查五年前，讓一個人去死；同時理解姊姊為什麼說狠話
第五章　被她記得、別人卻不記得的關係刺痛；學會先問為什麼
第六章　發現自己最熟的人，也有五年沒讓她摸到的事
第七章　分得出「告訴」和「叫」；看見姊姊是怎麼不再問的
最終章　不再要求世界為了她的遺憾重來
```

## 每章早晨的心境

每章都會重複的兩個早晨 beat：車上的咳嗽／橘子皮、月台上予安那句「比我想的早」，拿來當心境的溫度計。每章寫法要不一樣，不要再用「讓它們照原樣過去」。

| 章 | 心境 | 早晨怎麼寫 |
| --- | --- | --- |
| 1 | 疏離、疲倦 | 第一次聽到，什麼都還是普通的 |
| 2 | 慌（第一輪）→ 累 → 麻 | 驚醒、一直按報時；重來後手指很重、話自己接出口 |
| 3 | 控制 | 拿咳嗽來對時間；第三輪以後格子排不住 |
| 4 | 麻木 | 心裡跟著咳一聲；他還沒講，她已經替他講完 |
| 5 | 只有我記得 | 他不知道自己咳過幾次，我知道 |
| 6 | 懷疑最熟的人 | 不讓予安的話過去，一句一句聽他在哪裡換氣 |
| 7 | 克制 | 等他自己講完，不搶下一句 |
| 終 | 接受 | 從頭聽完，聽見以前沒注意的啞 |

同一章重來時也要有變化：`chloop == 2` 偏累，`chloop >= 3` 偏麻或更極端。

## 寫作守則（補充 `docs/style.md`）

- 「自己決定」這類自主宣言，一章最多一句。其他時候讓角色用自己的口氣、自己的理由做事。
- 「妳跟她好像」「在一個你不會記得的……」「這是我會講的話」「我還沒出聲」這幾種句型已經用過很多次，新場景不要再用。
- 耳鳴、聲音退遠（daze）只留給死訊與真相揭露，小場面用一個具體的身體動作就好。
- 主題不要由角色直接講成結論，改成一個動作、一個物件，或一句只有這個人會講的話。

## 2026-11-04 整合檢查結果

三位讀者（玩家、連貫性編輯、主題評論）讀完全稿後，已修正：

- **電話台詞**：漏寫 `via: phone` 的補上了，否則講電話的人會被當成站在旁邊。
- **場景事實**：舊站正門已封，工人改成叫人從側門缺口出去。老屋只有一層，「樓下冰箱」改成廚房。老家是鑰匙卡住，門也推不動。
- **時間、天氣、物件**：若晴的報名期限統一為「今晚」。10/4 天氣預報統一為「清晨起有陣雨」。錄音帶台詞前後一致。錶背摸讀的格子位置修正。鉛筆字在信紙背面是凸的。行李箱和六封信的位置統一。
- **輪迴邏輯**：
  - 主角「上一次」「之前」的心聲，改成只講那一輪確實發生過的事。
  - 第六章誠實打電話的路線，不再出現「把所有人放回安全的格子」。
  - 第四章改用已知線索判斷她記得什麼，不再看是第幾輪。
- **盲人視角**：寫到看得見的細節（發白、低頭、他看完）都改成聽得到、摸得到的。
- **文件**：story.md、character-bible、機制文件、第六章文件與劇本對齊。
