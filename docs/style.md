# 聽見的城｜文風守則

> 適用 `story/*.yaml` 的所有文字。參考：[speak-human-tw](https://github.com/Raymondhou0917/speak-human-tw)（去 AI 味、台灣用語）、[i-have-adhd-zh-tw](https://github.com/panda850819/i-have-adhd-zh-tw)（先講重點、短而完整的句子）。
> 一句話：**旁白要具體、有文學性；對話要像台灣人真的會講的話。**

## 1. 旁白（`narr`、`think`）

旁白是她的感官。寫她摸到、聽到、聞到的東西，寫得越具體越好：「鐵門」比「門」好，「鏽掉的鐵門，推的時候卡在第二格」又更好。

### 要刪掉的 AI 痕跡

| 痕跡 | 例子 | 改法 |
| --- | --- | --- |
| 戲劇短句轟炸：連續三句以上的極短句 | 沒有停電。沒有尖叫。沒有人倒下。 | 併成一句有主詞的話：「燈沒有熄，也沒有人叫。街上的車照常開過去。」最多保留一句短句收尾 |
| 罐頭反應鏡頭：只為了表演情緒的停頓 | 他停了一下。／她沉默了很久。／我愣住了。 | 換成聽得到的具體變化：「背帶扣的聲音停了。」「電扇轉過來又轉過去，他還沒開口。」停頓本身就是事件時才保留 |
| 金句公式 | 記住一個人，不代表有權替他決定。／燈熄的時候，所有人都跟我一樣了。 | 一章最多一句。其他的還原成具體的事：她做了什麼、別人說了什麼 |
| 「不是 A，而是 B」 | 不是因為害怕，而是因為不想。 | 一章最多一次。其他改成直述 |
| 說教深度腔 | 說到底／本質上／真正的問題是 | 刪掉開頭，直接講那件事 |
| 解說導引 | 這意味著……／我終於明白…… | 刪。讓玩家自己明白 |
| 破折號 | 我以為——不。 | 旁白不用破折號。對話只在真的被打斷時用。擬聲字（沙——）不算 |
| 排比三段式 | 冰冷、空曠、陌生。 | 留下最準的那一個 |
| 重複的口頭禪 | 「很久」「一下，又一下」「我沒有回答」在同一章出現五次 | 每章同一個說法最多兩次 |

### 要保留的

- 短 beat 是這個遊戲的呼吸。一個 beat 可以很短，但連續三個以上都很短、都很重的時候，就是轟炸。
- 停頓是聲音事件時就保留：她在聽那段安靜，安靜裡有冰箱、有風、有對方的呼吸。
- 心聲可以不收尾、可以前後矛盾。人想事情本來就這樣。

### 句號在畫面上會變成什麼

腳本照常打句號，畫面不畫出來（`game/src/engine/text.ts`）：

- 行尾的句號拿掉。？！……留著，它們帶語氣。
- 旁白、心聲中間的句號變成換行，一個 beat 裡有幾句就疊幾行。
- 對話、手機中間的句號變成一個全形空格，像字幕。

所以句號就是「同一口氣裡的下一行」。一個 beat 疊到三行以上、每行都很短，就是短句轟炸，改成逗號或拆成兩個 beat。逐字解讀的時候例外（「一、八。冒號。三、一。」），那是她的手指在一格一格摸。

## 2. 對話

每個人講話要像住在台灣小鎮的真人。用自然的語助詞（啦、喔、欸、齁、吧、嘛、蛤），可以講一半、可以答非所問、可以重複。不要每句都很有文學性；文學性留給旁白。

| 角色 | 怎麼講話 | 例子 |
| --- | --- | --- |
| 予安 | 話少，能用動作就不用講。緊張時突然很正式。很少回答「你自己想要什麼」 | 「嗯。」「先吃。冷了就不好吃了。」「請、請扶著我的左手肘。」 |
| 若晴 | 講話快，會自嘲，習慣用「欸」開頭。被問到自己的事就拿工作擋 | 「欸妳不要這樣看我啦，啊不是，妳又看不到。」「我還要顧店，晚點再說。」 |
| 陳醫生 | 慢、精確，先停一下才開口。不把推測說成事實 | 「目前我能確定的只有這些。」「這個我不知道，我不會猜。」 |
| 庭安 | 語速快、問題很多，外地人，不講台語。記者習慣先確認事實 | 「等一下，妳剛剛說幾點？」「這個我可以引用嗎？」 |
| 周警官 | 公事公辦，句子短。偶爾一兩個台語詞，不要多 | 「案子結了。」「歹勢，這我不能給妳看。」 |
| 知夏 | 只在錄音和回憶裡。累，但很溫柔；溫柔裡有不讓人反駁的東西 | 「妳先吃飯，這個等一下再說。」 |
| 主角 | 乾，冷靜，有一點不饒人的幽默。討厭被同情 | 「沒關係，我早就習慣大家看到手杖會停一下。」 |

### 台灣用語

用：機車、便當、超商、垃圾車、鐵捲門、騎樓、阿嬤、掛號、視訊、訊息、資料、品質、影片、軟體、網路。
不用：視頻、質量、信息、數據（指資料時）、軟件、網絡、搞定（可以用「弄好」）。

標點一律全形：，。？！「」……

## 3. 寫之前問自己

1. 這句話拿掉，玩家會少知道什麼？什麼都不少，就刪。
2. 這句話是不是只有這個角色會這樣講？
3. 這段有沒有至少一個只有這個場景才有的具體細節？
