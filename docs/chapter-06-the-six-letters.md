# Chapter 6｜前六封信

> Status：Provisional story structure。
>
> 「前六封／第七封」可以保留作為故事意象與調查結構，但目前**不能**把它寫成已證實的七階段跨世界線傳輸技術。
> 警告信的投遞方式、是否存在 Watchdog、是否存在真正的跨線媒介實驗序列，全部仍是 TBD。

這一章真正要處理的是：

> **當 Reality 被 Rewrite，什麼資訊可能留下？**

而不是提前宣布：

> 知夏已經發明了一套能跨五年傳訊的裝置。

---

# 開場｜玩家發現「信」可能不是七封郵件

主角重新整理五年前留下的異常媒介：

```text
手寫紙條
公共借閱紀錄
錄音
醫療 / 警方紀錄
被毀掉後仍出現矛盾版本的文件
知夏自己的記憶紀錄
開場收到的實體警告信
```

其中一些東西可能被知夏自己用「第幾個」標記過。

但玩家此時不能直接確定：

```text
1～7
=
一套按順序成功的跨線傳輸實驗
```

也可能只是知夏整理不同資訊載體的方法。

「前六封信」因此更像主角暫時給這組 Mystery 的名字。

---

# 第一類｜私人紙本

知夏的私人紙張可能在不同版本資料中留下矛盾。

例如：

```text
同一本筆記
頁碼一致
內容卻有細微差異
```

第一個問題是：

> Worldline Rewrite 改的是事件，還是連記錄事件的物件也一起改？

答案目前不是「紙可以安全跨線」。

而是：

> **不同媒介受到 Rewrite 的方式可能不同。**

---

# 第二類｜第三方／公共紀錄

圖書館借閱紀錄、地方報紙、行政表單等資料有一個特點：

> 它們不完全由知夏本人控制。

玩家可以發現：

```text
私人筆記版本 A
公共紀錄版本 B
```

兩者偶爾無法完全對上。

這給知夏一個很自然的研究方向：

> 如果我自己的東西會跟著結果改變，那別人的系統會不會留下不同痕跡？

這仍然只是 Investigation，不是跨線傳輸證明。

---

# 第三類｜聲音與時間戳

志遠保留的錄音器可以成為最強的媒介異常之一。

它可能出現：

```text
內容似乎合理
但時間不合理
```

或：

```text
聲音存在
但說話者在該時間不應該在現場
```

這讓玩家開始理解：

> Worldline 異常不只會留下「另一個結果」，還可能破壞資訊的時間順序。

但仍然不要直接定義成：

> 聲音天然可以穿越世界線。

---

# 第四類｜別人記錄的知夏

柏勳的醫療紀錄、志遠的案件資料、庭安的研究紀錄都具有同一個價值：

> 它們不是知夏自己寫給未來的訊息。

所以玩家可以比較：

```text
知夏怎麼描述自己
vs
別人當時怎麼描述知夏
```

例如：

```text
知夏：
「這件事已經發生過。」

柏勳紀錄：
「個案堅稱記得尚未發生事件。」
```

這讓玩家能看見同一個異常，在不同人的世界觀裡長什麼樣。

---

# 第五類｜被刪除／破壞後仍存在的矛盾

舊版曾直接寫成：

> 庭安把一封信燒掉，信卻在下一條 Worldline 自動重新出現。

目前這個物理機制不鎖死。

可以保留的 Mystery 是：

> 庭安明明記得自己處理掉某份資料，後來卻又看見內容高度相似、來源卻不同的版本。

可能解釋包括：

- 另一份備份
- Rewrite 後的不同物件歷史
- 研究 Snapshot 重建
- 庭安自己的記憶與當前世界資料不一致

在 Anchor / Rewrite mechanics 定案以前，不宣布是哪一種。

---

# 第六類｜記憶持有者本身

這一類是目前最確定的。

主角每一次 Hard Reset 後仍然記得自己實際經歷的上一輪。

```text
Loop A
主角 Perceive X
↓
00:00 Reset
↓
Loop B
主角仍主觀記得 X
```

這不代表所有細節都會自動變成系統 Memory Card。

Player-facing persistence 仍遵守：

```text
Perception
→ optional Capture
→ Persistent Memory
```

但從故事角度而言，主角本人確實是一個特殊資訊載體。

知夏五年前也曾經有類似現象。

因此 Chapter 6 可以提出：

> 也許最穩定的「媒介」從來不是紙，而是那個沒有完全被 Rewrite 的觀測者。

注意：

> 這裡只在描述功能。
>
> 為什麼知夏／主角能做到，仍屬 Anchor / Observer / Reference TBD。

---

# 「第七封」為什麼仍然重要？

開場那封實體信仍然和前六類不同。

因為：

```text
知夏死亡：五年前
信件郵戳：昨天
主角收到：返鄉前
```

也就是它跨越的不是單純：

```text
Loop A → Loop B
```

而是一個五年的時間斷層。

因此玩家很自然會懷疑：

> 它是不是和五年前那些資訊異常屬於同一種現象？

但 Chapter 6 的答案應該是：

> **不知道。**

這反而比直接宣布「第七封就是完成型傳輸裝置」更有 Mystery 力量。

---

# 17:40｜主角開始懷疑自己把不同現象硬湊成同一個答案

這裡可以做一次很重要的自我修正。

主角在 Investigation Wall 排出：

```text
紙本差異
公共紀錄差異
錄音時間錯位
知夏異常記憶
五年後警告信
```

她可能很想畫一條線：

```text
全部都是同一個跨世界線通訊技術
```

但庭安或志遠可以提醒：

> 「妳有證據證明它們是同一件事嗎？」

這對整個遊戲也很重要。

玩家不能因為 Pattern 很漂亮，就自動得到 Truth。

---

# 18:03｜不完整的時間記錄

如果要保留五年前 `18:03` 的異常通話紀錄，可以將它定位成：

> 尚未解釋的 Transmission Evidence Candidate。

例如：

```text
電信紀錄：知夏撥出
知夏筆記：18:03 收到
```

兩者矛盾。

但本章不直接回答：

- 誰打給誰
- 是否跨 Worldline
- 是否和開場信相同機制

它只讓「資訊方向」本身變成 Mystery。

---

# 18:31｜這一輪信不會自動長字

舊版曾寫：

```text
18:31
→ 開場信內側自動出現新句子
→ 證明它是仍在工作的跨線交接裝置
```

此設定目前撤回。

本輪 18:31 到來時，信可以完全沒有任何變化。

反而能讓主角更清楚地意識到：

> 她不能把每個不理解的現象都當成知夏正在隔著世界回答自己。

知夏已經死了。

現在的主角必須靠現存的人、現存的資料和自己真正經歷過的世界線繼續調查。

---

# Chapter 6 章末認知

本章目前只需要推進到：

```text
1. Reality Rewrite 會造成資訊與當前 Reality 不完全一致
2. 不同媒介可能留下不同型態的異常
3. 知夏與主角本身都是特殊的資訊持有者
4. 開場警告信極度異常，但還不能證明它的技術原理
5. 「前六封 → 第七封」目前是玩家 hypothesis，不是 Author-confirmed truth
```

真正問題變成：

> 知夏到底經歷了多少次不同結果？

以及：

> 她最後為什麼從「救人」變成「替人安排」？

這會進入 Chapter 7｜林知夏。

---

# 後續可重新定案的項目

等 Anchor / transmission mechanics 完成後，可以再決定：

- 是否真的存在知夏刻意設計的六次媒介實驗
- 哪些媒介是自然 Residual，哪些是人工測試
- `18:03` 是否為真正跨線通訊
- 開場實體信是否透過 Watchdog / Snapshot / Rewrite / 其他機制送達
- 「第七封信」最終是字面上的第七個實驗，還是只保留作為作品名稱與象徵

在那之前，不讓 Chapter 6 反過來鎖死世界觀。
