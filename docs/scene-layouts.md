# 聽見的城｜場景格局

> 2026-11-06 建立。主角看不見，聲音的方向就是玩家唯一的鏡頭。寫場景、放音效之前，先在這裡找到那個地方的格局，確定她站在哪裡、面向哪裡，再決定每個聲音的 `at` 和 `dist`。

## 怎麼看

- 每張圖都是俯視圖。「我」是主角的位置，箭頭是她面向的方向；`↑` 代表她的正前方（`front`）。
- 方向一律以她為中心：`front` `front-right` `right` `back-right` `back` `back-left` `left` `front-left`，她自己的身體（呼吸、心跳、手上的東西）是 `center`。
- 距離：伸手碰得到、貼著耳朵是 `near`；同一個房間、幾步遠是 `mid`；隔一面牆、街口、山坡下是 `far`。
- 同一個地方如果她坐在不同位置、面向不同方向，就分成「變體」，每個變體各有一份方位表。
- 她的手機一律在 `right, near`（外套右邊口袋、或拿在右手）。

## 寫新場景時

1. 在 YAML 場景的 `- id:` 下一行標註用哪個格局：`# 格局：老街咖啡店／靠窗座（docs/scene-layouts.md）`。
2. 照方位表放 `cast` 和固定聲源（門、櫃台、窗、冰箱……）。
3. 有人走動、坐下、離開、回來，就加 `- move:`，他身上的聲音（腳步、背帶扣、紙、椅子）跟著換方向；走遠用 `to:`。
4. 旁白寫到方位（隔壁桌、背後、窗邊、耳邊、遠處）時，對一下聲音有沒有在那裡。
5. 這裡沒有的新地點，先在這份文件畫一張圖再寫。

## 舊車站

用在：c1_station、c1_1831、c1_locate_success、c1_locate_fail、c2_afternoon、c2_station、c2_station_stay、c2_station_after、c2_goes_station、c2_hall_lost、c3_chess、c3_vigil、c3_vigil_short、c3_1831、c3_1831_ruoqing、c3_1831_fail、f_station、f_gate2、f_gate4、f_epilogue_a

鎮北，研究所那道坡的下面。車站坐北朝南，正門開在南面，面對一條東西向的馬路；馬路對面是一排有騎樓的店。

- **正門**：今年十月起封閉施工，正門前的碎石前庭整片用施工圍欄圍起來。
- **缺口**：圍欄西端轉角有一個缺口。從這裡鑽進前庭，再從正門已經拆掉門板的門洞走進大廳。所以「從側邊的缺口進去」以後，她在大廳裡一定是背對正門、面向北。
- **大廳**：挑高、回音很大。東牆有一排窗（若晴說「去窗戶那邊看」的窗台）；北牆是以前的售票口；西牆北端有一扇**側門**，通往西邊停車的小路（陳醫生第一章、第二章從這裡離開，開車回鎮上；工人也從這裡進出）。
- **東牆機櫃**：今年春天裝的灰色鐵櫃，背對正門、右手邊第二根柱子後面，比人高一點。18:31 跟著時間升起的嗡鳴就從這裡出來；若晴倒在它的牆腳。
- **員工維修通道**：在東牆**外面**。圍欄東端走到底，地面變成往下斜的碎石坡，坡下牆腳有一扇生鏽的鐵門，通道沿著東側往北通到研究所的坡，上方是鐵架（塌下來的就是它）。東牆機櫃拉出來的新備援線也從這一側走，所以通道深處、東牆、對面聽到的嗡鳴，全部都在**東邊**。
- **工地**：東側是空地，施工的車從路口倒車進去（第二章的倒車卡車）。

老街上的小店面，門口到櫃台只有幾步。街門開在臨騎樓那面牆的中間偏左，門上掛一串門鈴。一進門，左手邊是一座玻璃展示櫃，前面擺著予安說的「後面那張椅子」（舊扶手椅，扶手有一道裂縫）。再往裡一步是橫過店面的玻璃櫃台，櫃台左段後面是予安的工作檯，他平常就坐在那裡修錶。三面牆都掛滿鐘；他爸修不好、每天亂響又慢半拍的那座小鐘，掛在進門左手邊的牆角，比展示櫃高一點。冰箱貼著門的左側。工作檯後面掛一條布簾，裡面是後面的小房間。

她在這間店裡永遠面向店裡、背對街門：不管坐在舊扶手椅還是櫃台邊，予安都在正前方，老鐘都在左後方，門鈴都在身後。
