# 核心玩法設計

> 核心概念：玩家不是尋找唯一正確的世界線，而是透過一次次介入世界，理解事件真正的因果。

## 核心循環

```text
觀察世界
→ 建立假設
→ 介入一個事件節點
→ 世界持續自行運行
→ 事件卡被改寫
→ 比較前後世界線
→ 找出因果與不變條件
→ 下一輪
```

遊戲時間與現實世界同步。玩家離線時，小鎮仍會依 NPC 行程、關係、情報與事件條件持續演算。

## 世界線影響

玩家的行動不是單純改變一個結果，而是改變後續整條因果鏈。

```text
救下 A
→ A 沒去車站
→ 醫生沒遇到 A
→ 醫生提早回醫院
→ 記者沒拿到資料
→ B 獨自前往鐘樓
→ B 死亡
```

### 四層影響

1. **立即影響**：阻止 A 出門 → A 留在家裡。
2. **次級影響**：A 沒出現 → B 改變行程。
3. **關係影響**：強行阻止 A → A 對玩家信任下降。
4. **延遲影響**：數小時後，因信任下降而失去關鍵情報，進而改變另一事件。

延遲影響是核心特色之一。玩家當下不一定知道自己的選擇已經改變了未來。

## 卡片系統

### Event Card

代表「目前世界線中的事件狀態」，會被玩家的介入改寫。

例如同一張 `18:31 事件`：

```text
Loop 01：許若晴死亡
Loop 02：陳柏勳死亡
Loop 03：無人死亡
Loop 04：車站爆炸
```

玩家不是只補充卡片細節，而是會看到整張卡片因世界線而改變。

### Truth Card

代表跨輪迴逐漸揭露的真相，例如「姊姊的死亡」。

```text
死亡時間：18:31
死亡地點：舊車站
死因：???
知道輪迴：???
真正目的：???
```

Event Card 會被改寫；Truth Card 則逐步補完整。

## 世界線歷史

每張 Event Card 必須保留歷代版本。

```text
18:31 事件

Loop 01  許若晴死亡
Loop 02  許若晴死亡
Loop 03  陳柏勳死亡
Loop 04  無人死亡
```

玩家可比較不同 Loop，找出：

- 哪些資訊會變。
- 哪些資訊總是不變。
- 哪一個玩家行動造成分歧。

## Invariant

核心推理不是只有「誰是兇手」，而是找出不管世界線怎麼改變都存在的條件。

> 改得動的，通常是結果；改不動的，才可能接近真相。

例如：

```text
可變：死者、目擊者、死因
固定：18:31、鐘聲、某個隱藏事件
```

## Timeline / Worldline Diff

Timeline 用來表示一輪中「發生了什麼」。

Worldline Diff 則比較兩輪的差異：

```text
Loop 07                 Loop 08
17:40 醫生離院          17:40 醫生被攔下
18:05 與若晴碰面        18:05 若晴獨自行動
18:31 若晴死亡       →  18:31 醫生死亡
```

## 放置期間

玩家不在線時世界仍持續運作。

重新登入後顯示 Overnight / Offline Report：

```text
世界線發生 7 項變化
- Event Card 改寫 ×3
- 新事件 ×2
- 人物關係改變 ×1
- 關鍵情報 ×1
```

玩家可以事先指派調查任務，例如跟蹤人物、調監視器、驗屍、查舊案，並於完成時將結果寫入世界狀態。

## 設計原則

- 世界不等待玩家。
- NPC 要有自己的目的與 Schedule，不只是等待觸發的對話點。
- 玩家行動應改變條件，而不是直接選擇劇情 A / B / C。
- 延遲後果不能全部立即揭示。
- 一輪可以失敗，但應留下可推理的新知識。
- 案件解決與輪迴結束是兩件不同的事。
