# Chapter 3｜沒有死者的世界線

這一章的重點不是讓玩家「成功救人」，而是第一次真正發現：

> 死亡只是輪迴的表面現象。

同時，本章必須遵守目前 Core Gameplay：

- 主角記得上一輪，但 NPC 不記得
- 玩家只能使用自己上一輪真正 Perceive / Capture 的資訊
- 世界不因對話、閱讀、Choice 而停止
- 系統不自動整理「誰活了 / 誰死了 / 18:31 是 invariant」成答案卡

---

# 06:12｜第三次醒來

Hard Reset 完成後，主角再次在返鄉列車醒來。

手機顯示：

```text
10 月 3 日
06:12
```

世界狀態回到 canonical checkpoint。

只有她自己記得前兩輪。

但「她知道今天會發生什麼」的精度，必須來自前兩輪真的經歷過的內容。

如果玩家前兩輪 Capture 過：

```text
17:40 左右 柏勳離院
17:45 左右 若晴離開咖啡店
18:31 發生死亡事件
```

這一輪她可以據此提前行動。

如果某個細節上一輪沒看見，就不能因為進入第三輪突然補齊。

---

# 玩家開始做實驗

前兩輪讓主角開始換一種思考方式。

她不再只想找兇手，而是想改變每個人的位置。

```text
若晴不要去車站
柏勳不要去車站
庭安不要進危險區
予安留在自己的生活線
```

她第一次產生一個冷靜甚至有點可怕的想法：

> 如果讓所有人都不要靠近那裡呢？

這一輪不再是救某一個人。

而是試著把 18:31 的已知高風險人物全部移開。

---

# 15:40｜主角說出「不可能知道的事」

玩家提前找若晴。

主角直接說：

> 「妳今天傍晚不要去舊車站。」

若晴停下手上的動作。

「……妳怎麼知道我要去？」

對主角來說，這是前一輪已知資訊。

對若晴來說，卻像監視、操控，甚至威脅。

這一章要讓玩家理解：

> **跨 Loop 的知識不是免費說服力。**

如果玩家直接拿上一輪知道的私密資訊壓若晴：

```text
pressure ↑
trust ↓
```

她可能照做，但不是因為相信主角。

---

# 16:30｜予安察覺主角變了

予安陪主角走過商店街。

主角提前避開一台即將轉進來的貨車，甚至在孩子的球滾到馬路前先伸手接住。

予安停下來。

「妳今天很奇怪。」

主角說沒事。

「不是今天。」

「妳像是已經來過這裡很多次了。」

這個 Moment 可以增加予安**當前 Loop** 的疑惑與壓力。

但它不是 NPC Memory Residue 的種子。

Reset 後：

```text
予安不記得這段
主角記得自己曾經聽他這樣說
```

如果玩家 Capture 這句話，它可以成為下一輪可檢索的 Memory。

---

# 17:20｜第一個成功

若晴沒有去車站。

柏勳也被主角提前攔下。

主角說：

> 「你手上的東西今天不能交出去。」

柏勳：「妳知道那是什麼？」

主角：「不知道。」

柏勳：「那妳憑什麼——」

主角：

> 「因為上一個拿到的人死了。」

柏勳沉默。

然後問：

> 「這是第幾次？」

主角愣住。

柏勳很快改口。

這句話可以讓玩家懷疑柏勳知道得比表面更多。

但系統不要跳出：

```text
[Important Clue]
柏勳知道輪迴
```

玩家若認為值得，可以自己 Capture 柏勳的話。

---

# 18:00｜把每個人移開

這一輪的主角幾乎像在調度棋子。

```text
若晴 → 留在家中
柏勳 → 返回醫院
庭安 → 被留在咖啡店
志遠 → 被要求查另一件舊案
予安 → 留在鐘錶店
```

舊車站附近第一次空了。

主角獨自待在能看見入口的遠處。

18:20。

沒有異常。

18:25。

沒有人靠近。

18:29。

主角開始相信自己做到了。

18:30。

她甚至笑了一下。

---

# 18:31｜沒有已知死者

18:31。

沒有停電。
沒有尖叫。
沒有人在主角眼前倒下。

18:32。

時間正常往前。

主角開始確認其他人的狀態。

若晴接電話。

柏勳也接了。

予安傳來訊息：

> 「所以我現在可以出門了嗎？」

重要：

「所有人都活著」不是系統自動核發的 Success Card。

主角只能知道自己真正確認到的範圍。

如果某個人她根本沒確認，就只能形成：

> 至少我現在知道的人都還活著。

---

# 19:10｜活著之後的晚上

沒有死亡後，人物自己的生活線繼續。

若晴去咖啡店談辭職。

店長問：

「妳想好了？」

若晴：「還沒有。」

「那幹嘛現在辭？」

若晴笑：

> 「因為如果等到想好，我可能又會多待一年。」

玩家可能：

- 在現場看到
- 只聽若晴之後提到
- 完全錯過

這三種情況的 Player Knowledge 不應一樣。

---

# 20:00｜予安的房仲

主角回到鐘錶店。

門口站著房仲。

前幾輪裡，她一直把予安叫去幫忙，從沒問過他原本要做什麼。

予安把一只停走的掛鐘拿下來。

> 「我爸死掉以後，這裡每樣東西都有人跟我說不能動。」

> 「有時候我不知道我是在顧店，還是在替所有人保存一個他們比較喜歡的過去。」

這句話和主角追逐知夏形成主題對照。

它也可以成為玩家自願 Capture 的普通人物 Memory，而不是系統標記的角色 Insight。

---

# 21:30｜平靜開始變得奇怪

沒有死亡之後，玩家自然會期待「輪迴解除」。

但世界照常繼續。

22:40，主角重新看知夏留下的筆記。

其中一句：

> 不要把「沒有人死」當成成功。

如果主角此時注意到並 Capture，它才成為可檢索的 Persistent Memory。

---

# 23:10｜柏勳來找主角

柏勳主動來到老家。

他問：

「18:31 怎麼了？」

主角沒有回答。

柏勳放下一張五年前的病歷影本。

病歷上的名字不是知夏。

死亡時間：18:31。

日期：知夏死亡前十二天。

主角問：

「這是誰？」

柏勳：

> 「一個本來不應該死的人。」

稍後他又問：

「今天真的沒有人死嗎？」

主角：

> 「至少我知道的人都活著。」

柏勳沉默。

> 「那不一定是一回事。」

這一段給玩家新的 Perception opportunities，但仍不應自動生成「18:31 Truth Card」。

---

# 23:59｜鐘聲再次響起

所有主角目前知道的人都還活著。

23:59。

第一聲鐘響。

鐘樓明明沒有鐘。

第二聲。
第三聲。

主角衝出門。

街上的人沒有反應。

只有主角清楚聽見十二聲鐘響完。

這是一個適合 Capture 的 Sound / Composite Moment，但遊戲仍不主動提示。

---

# 00:00｜Hard Reset

第十二聲落下。

00:00 到達時，世界不等待主角理解發生了什麼。

```text
23:59 鐘聲
→ 00:00 Hard Reset boundary
→ 世界狀態回到 canonical checkpoint
→ 10 月 3 日 06:12
```

下一個可呈現畫面是：

```text
返鄉列車
手機：10 月 3 日 06:12
主角醒來
```

不是「主角仍站在午夜原地，只是日期沒前進」。

NPC Relationship、NPC previous-loop memory 與世界狀態已 Reset。

主角保留自己的主觀經歷；玩家主動 Captured 的 Memory / Investigation Wall 持續存在。

她因此知道：

> 沒有已知死者，輪迴還是發生了。

但這個理解應該由玩家經歷形成，不是 UI 自動比對答案卡。

---

# Captured Memory 不會被新 Worldline 覆蓋

舊設計：

```text
重新打開「若晴死亡」Event Card
→ 卡片被新世界線覆蓋
```

已廢止。

正確模型：

```text
Loop 01 Memory：若晴在 18:31 死亡
Loop 02 Memory：柏勳在 18:31 死亡
Loop 03 Memory：18:31 沒有已知死者（依主角實際確認程度）
```

它們可以同時存在於 Memory Library。

玩家可以在 Investigation Wall 自己排列、連線與寫 Note：

```text
[Loop 01 · 18:31 若晴]
        │
[Loop 02 · 18:31 柏勳]
        │
[Loop 03 · 18:31 沒有已知死者]

Note：「死亡不是 Reset 條件？」
```

系統不自動標註這個推論正確。

---

# 本章對 Loop 設計的意義

Chapter 3 應讓玩家開始理解兩件事：

1. 世界線可以被大幅改寫
2. Reset 不等於某一個角色死亡

同時也增加主角的倫理壓力：

```text
我知道每個人可能怎麼走
→ 我可以更有效地操控他們
→ 但我有沒有權利？
```

這個主題後續和知夏形成鏡像。

---

# 對 Event Graph 的需求

Author Graph 可以記錄完整 truth：

```text
all dangerous routes cleared
→ 18:31 no-known-death variant
→ evening personal-life events proceed
→ 23:59 bell
→ 00:00 reset
→ 06:12 canonical checkpoint
```

但 Player-facing knowledge 必須另外經過：

```text
World Event
→ Attention / Perception
→ optional Capture
```

### 予安規則

這章**不能**再作為 `Memory Residue` 的前置種子。

```text
予安察覺主角奇怪
→ current-loop relationship / pressure effect
→ Reset
→ 予安不記得
```

只有主角記得這段互動。

---

# Chapter 3 ending question

玩家離開這章時，最重要的不是收到一張答案卡，而是自己開始問：

> 如果沒有人死，為什麼世界還是重來？
