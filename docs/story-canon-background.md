# Story Canon｜灰潮鎮背景、社會議題與核心反轉

> Status：Confirmed story direction。
>
> 本文件定義灰潮鎮的社會背景、研究設施原始目的、故事核心議題與主要反轉。
> 具體事故設備、研究模型名稱、18:31 的技術鏈路仍可在 Event Graph / chapter authoring 階段細化，但不得推翻本文件的核心因果方向。

---

# 一句話定位

灰潮鎮不是一個「大家都想逃走的詛咒小鎮」。

它是一個正在慢慢衰退的地方，曾經為了繼續活下去，接受了一個看似能帶來未來的研究計畫；五年後，所有人仍在承受當時那些合理選擇累積起來的結果。

---

# 灰潮鎮原本發生了什麼

灰潮鎮長期面臨典型地方衰退問題：

```text
人口外流
→ 商店倒閉
→ 青年工作機會減少
→ 醫院與公共服務縮編
→ 地方財政惡化
→ 更多人離開
```

因此當研究設施提出進駐時，對地方來說並不是單純的「危險實驗」。

它曾經代表真正的機會：

- 新的就業機會
- 青年返鄉可能
- 醫院與基礎設施補助
- 車站與公共設備更新
- 學術與地方合作
- 地方財政與產業轉型

當年的選擇並不愚蠢。

很多人甚至有充分理由支持它。

---

# 社會議題一｜地方發展不是單純的正邪選擇

故事不能把研究所寫成「邪惡企業進駐純樸小鎮」。

真正的問題是：

> 當一個地方正在衰退，它願意用多少未知風險交換一個可能的未來？

研究計畫確實替灰潮鎮帶來過好處。

如果當年沒有研究所，灰潮鎮甚至可能更早失去部分工作、醫療與公共資源。

所以玩家後來知道研究事故真相時，不能得到一個簡單答案：

```text
研究所 = 壞
居民 = 受害者
```

更接近：

```text
所有人都做了當下看起來合理的選擇
→ 每個人只承擔其中一小部分
→ 最後累積成沒有人能單獨控制的結果
```

---

# 社會議題二｜合理的小隱瞞如何累積成巨大真相缺口

灰潮鎮的秘密不是由一個大型陰謀維持。

而是很多人都曾經只隱瞞「一點點」。

例如：

```text
柏勳
→ 不公開無法解釋的醫療異常
→ 理由：病患隱私、醫院存續、避免恐慌

志遠
→ 沒有登錄無法建立證據鏈的異常錄音
→ 理由：證據本身可能讓整起案件失去可信度

庭安
→ 沒有公開所有研究資料
→ 理由：部分內容無法證實，也可能傷害仍活著的人

知夏
→ 不把全部真相告訴妹妹
→ 理由：她已看過妹妹因介入而死亡的世界線

居民
→ 不希望外界持續把灰潮鎮當成「事故小鎮」
→ 理由：地方名聲直接影響觀光、工作與生活
```

每一個理由單獨看都有道理。

真正危險的是：

> 所有合理的小隱瞞加起來，最後讓任何人都看不到完整因果。

這也是遊戲推理結構的重要來源。

---

# 社會議題三｜照護責任不是「想走就走」

許若晴的家庭線不能被簡化成：

> 生病的母親阻止女兒追夢。

真正要討論的是地方照護結構。

在灰潮鎮：

- 醫療資源縮編
- 大眾運輸有限
- 長照與陪診資源不足
- 家庭收入有限
- 主要照護工作容易落到「最方便留下來的人」身上

若晴的母親不一定要求她留下，甚至可能希望她離開。

但結構本身會讓若晴不斷覺得：

> 現在走，好像就是把責任丟給別人。

所以「離開」不是單純勇敢，「留下」也不是單純犧牲。

---

# 社會議題四｜保存過去是否也可能傷害未來

灰潮鎮有很多被要求保存的東西：

```text
老街
鐘錶店
舊車站
鐘樓
研究設施遺跡
地方記憶
```

大家常說：

> 這是灰潮鎮的記憶，不能消失。

但保存也有成本。

可能變成：

```text
不能拆
→ 不能改建
→ 必須維護
→ 下一代被期待接手
→ 最後沒有人真正知道自己為什麼還在維持它
```

周予安的鐘錶店就是這個議題最直接的人物版本。

這也和 Loop 形成主題鏡像：

> 不讓過去消失，不一定等於珍惜過去。
>
> 有時也可能代表不允許未來開始。

---

# 核心反轉｜研究所原本不是在研究時間旅行

玩家前期看到的現象會自然讓人以為：

```text
世界線
未來錄音
時間錯位
跨線資訊
18:31
```

代表研究所曾經進行時間旅行實驗。

這是錯誤但合理的推論。

研究設施原始目的不是時間旅行。

它原本研究的是：

> **災害預測、城市系統模擬與決策干預。**

核心問題原本非常現實：

```text
如果我們能提前知道一個決策會導致多少傷亡
是不是就能選擇更好的方案？
```

研究範圍可以涵蓋：

- 颱風與災害疏散
- 地方電網與公共設施故障
- 醫療資源調度
- 交通事故與號誌系統
- 人流與公共安全
- 多個決策互相影響後的風險傳播

灰潮鎮因為人口規模較小、系統邊界相對清楚、長期資料完整，因此成為適合的實驗場域。

---

# 從「預測」走向「干預」

研究一開始只是：

```text
收集資料
→ 建模
→ 預測可能結果
```

但當模型越來越準，研究開始進入下一步：

```text
如果預測到事故
→ 提前改變一個變數
→ 再觀察結果是否變好
```

也就是從 Prediction 進入 Intervention。

這本身仍不是超自然研究。

真正的事故發生在某次同步實驗之後：

```text
預測
→ 模擬
→ 現實干預
→ 系統同步異常
→ 模擬結果與現實狀態開始互相污染
```

從此「可能發生的結果」不再只是模型中的可能性。

部分資訊、狀態與因果開始留下不應存在於當前世界線的痕跡。

這才是 Worldline Rewrite / Residual Information 的起點。

---

# 18:31 的真正意義

18:31 不是神秘力量隨機選中的時間。

它是五年前重大同步事故發生時的 **Causal Convergence / Synchronization Point**。

在那個時間附近，數個原本獨立的城市系統與研究流程同時進入關鍵狀態，例如：

```text
地方電力 / 備援系統
交通與車站相關設備
醫療系統狀態
研究設施同步程序
人員位置與決策
```

具體設備與事故鏈仍可後續細化。

目前 Canon 只固定：

> 18:31 是多個系統與人類決策第一次被同步綁成同一個因果節點的時間。

後來世界線每次被大幅改寫時，因果都會重新在這個節點附近收束。

因此：

```text
18:31 ≠ 必須有人死
18:31 ≠ Reset 本身
18:31 = Causal Convergence
```

午夜 Hard Reset 則是後續世界修正完成的結果。

---

# 最重要的反轉｜問題不是「時間」，而是「最佳化」

故事前半玩家會問：

> 誰殺了若晴？

後來變成：

> 為什麼所有事件都指向 18:31？

再後來變成：

> 研究所到底做了什麼時間實驗？

真正答案則是：

> 他們原本只是在試圖找到「更好的結果」。

這件事逐漸變成整個故事的核心。

研究系統在尋找傷亡更少的結果。

知夏在尋找所有人都能活下來的世界線。

主角也逐漸利用 Loop 尋找更好的今天。

三者其實在做同一件事：

```text
看見不滿意的結果
→ 修改一個變數
→ 再試一次
→ 結果仍不完美
→ 再修改
```

---

# 故事真正想討論的問題

遊戲表面上是：

> 要怎麼改變世界線，救下所有人？

但真正核心不是「離開灰潮鎮還是留下灰潮鎮」。

而是：

> **只要我們能再修正一次，就一定應該修正嗎？**

以及：

> **知道更多結果的人，是否就有資格替別人決定哪個人生比較好？**

這個問題應同時反映在：

```text
地方政策
研究倫理
醫療決策
家庭照護
保存地方記憶
知夏操控世界線
主角利用 Loop
```

因此故事最後不能只回答「哪條世界線最好」。

真正的收束應該回到：

> 人能不能接受一個不完美、不可逆，而且不再由單一知道最多的人替所有人決定的未來？

---

# 角色對灰潮鎮的立場不能相同

避免所有角色都落入「想逃離小鎮」的單一背景。

目前方向：

```text
主角
→ 從小就真的想看都市與更大的世界
→ 她離開本身不是錯

予安
→ 曾想離開，但一次次延後
→ 核心是自己從未真正做出選擇

若晴
→ 對外面的世界有渴望，但也真心喜歡灰潮鎮
→ 家庭照護與自己的恐懼同時存在

柏勳
→ 相信小地方的醫療需要有人留下
→ 同時可能把責任當成不處理自己人生的理由

庭安
→ 原本就是外來者
→ 她的問題不是留下或離開，而是外人有沒有資格決定地方真相如何被公開

志遠
→ 把灰潮鎮視為自己的家
→ 沒有離開的願望

知夏
→ 想保護人，也想保住這個地方
→ 最後因為太相信自己知道更好的結果，把人逐漸當成可調整的變數
```

不同立場共同構成灰潮鎮，而不是把小鎮本身寫成反派。

---

# 對後續 Story Authoring 的限制

後續章節與人物設計需遵守：

1. 不把灰潮鎮簡化成「所有人都想逃走」的地方。
2. 不把研究設施簡化成純粹邪惡組織。
3. 不用單一幕後黑手解釋所有隱瞞。
4. 每個隱瞞都應有當事人在當時能理解的理由。
5. 研究核心是 Prediction → Intervention → Reality Contamination，不是起初就研究 Time Travel。
6. 18:31 是 Causal Convergence，不是死亡必發點。
7. 人物的「留下 / 離開」只能是各自人生的一部分，不是唯一主題。
8. 最終衝突必須回到「最佳化他人人生的權力」與「接受不可逆未來」。
9. 社會議題應透過人物生活與選擇呈現，不要變成說教式背景資料。
10. Core Gameplay 的 World Never Waits / Perception Boundary / Asymmetric Loop Persistence 仍然優先。
